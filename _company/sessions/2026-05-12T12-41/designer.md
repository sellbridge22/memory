### 1. ✨ 브랜드 디자인 가이드 (Report Level)

#### A. 컬러 팔레트 (Color Palette)
| 용도 | 색상 이름 | HEX 코드 | 사용 목적 및 의미 | 적용 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** | Deep Navy (배경/권위) | `#1A237E` | 리포트의 기본 배경 또는 섹션 구분선. 학술적 신뢰감 부여. | 제목 박스, 주요 Divider 라인 |
| **Secondary** | Cool Gray (데이터) | `#90A4AE` | 일반 데이터 플롯, 보조 텍스트, 중립적 분석 영역. | 축 레이블, 비경고성 통계 수치 |
| **Accent - Warning** | Critical Red (위기/손실) | `#D32F2F` | **가장 중요한 경고 지점.** 임계치 초과, 급격한 하락, Temporal Loss 강조. | CD Bar의 위험 구간, 가장 낮은 AAR 수치 |
| **Accent - Solution** | Electric Cyan (회복/잠재력) | `#00BCD4` | 문제 해결 가능성, Flow State 도달 지점, 긍정적 변화 추이. | 목표 범위, 개선된 그래프 라인 |
| **Background** | Off-White (본문) | `#FAFAFA` | 본문 내용의 가독성을 최상으로 유지. | 모든 텍스트 및 데이터 표면 |

#### B. 타이포그래피 (Typography System)
*   **Headings (제목):** Spoqa Han Sans Neo Bold / Inter Bold (굵고 간결한 산세리프).
    *   적용 목적: 강력한 시선 집중, 섹션의 중요도 강조.
*   **Body Text (본문):** Noto Sans KR Regular (가독성이 높은 시스템 기본 폰트).
    *   적용 목적: 학술 용어 및 상세 설명에 사용되어 긴 호흡으로 읽기 편안하게 함.
*   **Data/Code:** Source Code Pro Mono (모노스페이스).
    *   적용 목적: 그래프의 축 레이블, 수치 데이터 블록(`[Timecode]`), 시스템 코드를 표현하여 전문성 극대화.

### 2. 🎨 Mockup 상세 명세 (Section별)

#### Mockup A: 진단 리포트 표지 및 요약 페이지 (Critical Summary)
*   **레이아웃 목표:** 첫 스캔만으로도 '위기'를 느끼게 한다.
*   **구조 요소:** [A1] 메인 헤드라인, [A2] 경고 시스템 위젯, [A3] 핵심 지표 3줄 요약 박스.

| 영역 | 세부 명세 및 애니메이션/상호작용 (Editor/Dev 참고) |
| :--- | :--- |
| **[A1] 메인 헤드라인** | *텍스트:* "당신의 부족함이 아닙니다. 당신의 시스템에 결함이 있습니다."<br>*스타일:* 48pt, Deep Navy 컬러, Bold.<br>*효과:* 페이지 로딩 시, 글자 하나하나가 **타이핑(Typing)** 애니메이션으로 등장하며 긴장감 조성. |
| **[A2] 경고 시스템 위젯** | *위치:* 표지 중앙 하단 (Mockup에 배치 필수).<br>*요소:* 붉은색의 깜빡이는 `🔴 ALARM: TEMPORAL LOSS DETECTED` 배너.<br>*애니메이션:* 초당 1회, 빨간색과 주황색 사이를 왕복하는 **깜빡임(Blinking)** 효과 필수. |
| **[A3] 핵심 지표 요약 박스** | *레이아웃:* 그리드 기반의 3개 컬럼 배치.<br>*각 요소:* [지표명] (24pt, Spoqa Bold) / [수치] (**-17%**) (60pt, Critical Red).<br>*효과:* 수치를 마우스 오버(Hover) 시, 해당 지표의 원인 설명이 팝업되는 **Tooltip** 기능 추가. |

#### Mockup B: 인지 자원 배분율 진단 (AAR Decline Graph)
*   **레이아웃 목표:** 시간이 지나면서 '결함'이 축적되는 과정을 드라마틱하게 보여준다.
*   **구조 요소:** 꺾은선 그래프 (Line Chart), 기준점(Baseline) 비교 라인.

| 영역 | 세부 명세 및 애니메이션/상호작용 (Editor/Dev 참고) |
| :--- | :--- |
| **[B1] 메인 차트 라인** | *색상:* 시간이 지남에 따라 Deep Navy → Critical Red로 변화하는 Gradient Line.<br>*애니메이션:* 시간(X축)이 흐름에 따라 데이터 포인트를 따라가며 **선형적으로 그려지는(Draw-on)** 효과 필수. |
| **[B2] 기준점 라인** | *색상:* Electric Cyan (최적화된 상태).<br>*배치:* 차트의 상단에 평행하게 유지되는 가상의 이상적 곡선. 이 선과 실제 그래프가 벌어지는 간격이 핵심 위기 시퀀스임. |
| **[B3] 설명 박스** | *위치:* 그래프 하단, 캡션 형태.<br>*내용:* "Context Shift 발생 지점마다 인지 부하가 가중되어 예상되는 이상적 흐름(Cyan) 대비 실제 감소폭(Red)을 확인하십시오." (학술 용어 사용으로 권위 강화) |

#### Mockup C: Context Drain Bar & CWG 통합 모듈
*   **레이아웃 목표:** 가장 기술적이고 시네마틱한 느낌을 주며, 임계치 도달의 물리적 공포를 유발한다. (이전 CD/CWG 사양서 기반)
*   **구조 요소:** 게이지(Gauge) 형태, 에너지 바(Bar).

| 영역 | 세부 명세 및 애니메이션/상호작용 (Editor/Dev 참고) |
| :--- | :--- |
| **[C1] CD Bar (문맥적 에너지)** | *형태:* 가로 폭의 진척도 막대. 좌측(0%)에서 우측(100%)으로 흐름.<br>*색상 변화:* 🟢 (초기) → 🟡 (주의, 50~70%) → **🔴 (위험, 70% 이상)** 순서로 색상이 급격히 변해야 함. <br>*애니메이션:* 게이지가 채워지는 속도 자체가 가속도를 가지며, Red Zone 진입 시 노이즈 필터 효과(Noise Filter Overlay)를 추가하여 불안감 극대화. |
| **[C2] Critical Warning Gauge (CWG)** | *형태:* 원형 바늘 형태의 게이지.<br>*축:* 0% ~ 150%.<br>*위험 구역 표시:* Red Zone을 붉은색으로 명확히 채우고, 이 구간에 진입할 때마다 **미세한 떨림(Subtle Vibration)** 효과를 추가하여 긴장감을 조성. |
