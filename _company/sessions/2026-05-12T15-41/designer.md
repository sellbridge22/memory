## Ⅰ. 핵심 모션 에셋 상세 사양서 및 사용 원칙

| 에셋 명 | 기능/목표 | 애니메이션 로직 (AE 기준) | 트랜지션 타이밍 & 트리거 | 권장 색상 팔레트 (HEX Code) |
| :--- | :--- | :--- | :--- | :--- |
| **CWG Decay Bar** (Contextual Workload Gauge) | 시스템 과부하 직관적 시각화. 사용자에게 '지속적인 관리 필요성'을 인지시킴. | 1. 초기: 녹색(70%) → 2. 경고: 주황(30~60%) → 3. 임계점: **붉은색(Red Zone, <30%)**으로의 선형/급격 하락 애니메이션 (Curve Interpolation 필수). | **Trigger:** 사용자의 인지적 노력이 정체되거나 데이터 흐름이 끊길 때 (`T+1:15`). 급격한 감정 고조와 연동. | Primary: `#E63946` (Deep Red), Warning: `#FFC300` (Amber) |
| **CD Bar Glitch Effect** (Cognitive Deficit Bar) | '구조적 결함'을 전문 용어로 폭로하며 불안감 증폭. 시각적/기술적 실패 경험 제공. | 1. 노이즈 레이어 추가(VHS Grain). 2. 데이터 블록 단위의 수평/수직 글리치 (Offset Shift, Chromatic Aberration) 효과가 주기적으로 발생하며 화면을 가림. | **Trigger:** '문제점' 또는 '결함 지표'를 언급할 때 (`T+0:45`). 임팩트 구간에서 2~3회 반복 배치. | Accent: `#A8DADC` (Pale Blue), Failure: `#1D3557` (Deep Slate) |
| **System Decay Curve** (위기 고조 곡선) | 시간이 지남에 따라 성능이 하락하는 구조적 공포를 추상화. 시청자의 시간적 압박감 극대화. | 1. 곡선의 시작점(Start)은 부드러운 파란색 계열로, 최종 목표점(End/Red Zone)으로 갈수록 급격하게 수렴하며 위협적인 사운드와 동기화되어야 함. | **Trigger:** 미니 모듈 진단 과정의 도입부부터 끝까지, 지속적으로 배경에 깔리며 '흐름'을 주도함. | Gradient: `#457B9D` (Blue) $\to$ `#E63946` (Red) |

## Ⅱ. 콘텐츠 흐름 기반 디자인 시스템 가이드라인 (Fixed-Grid Layout)

모든 홍보물 및 교육 콘텐츠는 다음의 **3단계 감정적 서사 구조**를 따르며, 자산 배치는 반드시 시간 코드(Timecode)에 맞춰야 합니다.

| 단계 | 목표 감정 / 스토리 역할 | 핵심 애니메이션 사용처 | 시각적/디자인 지침 (Writer & Editor 참고) | CTA 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **Phase 1: 문제 인식 (The Threat)** | 불안감 유발, '나만 아는' 위기 고조. 전문 학술 용어 노출. | **System Decay Curve** (배경), CD Bar Glitch Effect (주요 증거 제시 시) | 배경은 다크 그레이/네이비 계열 유지. 텍스트는 과학적 그래프 형태로 배치(Y축, X축 명시). 정보의 *양*을 늘려 혼란 유발. | **[Hook]** "당신의 문제는 의지 부족이 아닙니다." (문제 제기) |
| **Phase 2: 진단 및 결함 폭로 (Diagnosis)** | 문제 심화, 자가 진단을 통해 '구조적 결함'을 확정적으로 공포시킴. | **CWG Decay Bar** (하락 그래프), CD Bar Glitch Effect (결론 도출 시) | 레이아웃은 Fixed-Grid를 유지하며, 데이터 지표(PFC Overload Index 등)를 전면에 배치하여 '과학적 증거'처럼 보이게 한다. 인터랙티브 요소 필수. | **[Transition]** "이 결함을 스스로 해결할 수 있습니까?" (Need 극대화) |
| **Phase 3: 솔루션 제시 (The Protocol)** | 위기감 해소와 동시에, '우리가 가진 시스템만이 유일한 생존책'임을 확신시킴. | System Decay Curve가 안정화되는 애니메이션으로 전환. 모든 에셋의 색상이 녹색/청록 계열로 전환되며 신뢰감을 부여함. | 템플릿은 깔끔하고 명료하게 정리하되, '프로토콜'이라는 전문 용어를 반복 사용한다. 상품 구매는 **시스템 업그레이드**처럼 느껴지게 디자인. | **[Final CTA]** "Standard Protocol을 통해 시스템을 복구하십시오." (구매 유도) |

## Ⅲ. 표준화된 콘텐츠 썸네일/포스트 템플릿 브리프 (3종)

장기 목표 달성을 위해, 모든 홍보 콘텐츠에 공통 적용될 썸네일/포스트 템플릿의 최종 디자인 시스템을 확정합니다.

**🎨 기본 설정:**
*   **Primary Font:** Pretendard Bold (제목), Noto Sans KR Regular (본문)
*   **Color Palette:** `#1D3557` (배경/권위), `#E63946` (긴급성), `#A8DADC` (데이터/희망)

| 템플릿 컨셉 | 사용 목적 | 레이아웃 및 구성 요소 | 필수 디자인 지침 (Editor 참고) |
| :--- | :--- | :--- | :--- |
| **1. [🚨 경고] 구조적 결함 포스터** (Short-form/Teaser) | Mini-Module 홍보, 위기감 극대화. | 텍스트를 화면에 '글리치(Glitch)' 효과와 함께 오버레이. 배경은 시스템 오류가 난 듯한 어두운 질감. 중앙 상단에 **CD Bar**의 일부만 배치하여 단서 제공. | 이미지 전체에 VHS 노이즈 필터 적용 필수. 텍스트는 짧고 자극적일 것 (예: "당신의 $X$ 지표, 이미 위험"). |
| **2. [📊 진단] 데이터 리포트 썸네일** (YouTube Thumbnail) | 유입된 시청자의 '문제 인식' 강화. 전문성을 가장 중요시함. | 좌측 상단에 가짜 측정 그래프(Context Drain Bar)를 배치하고, 중앙에 큰 헤드라인을 배치. 배경은 어둡고 미니멀하게 처리하여 데이터가 돋보이게 함. | **반드시** 구체적인 수치 (예: "PFC Index 62%!")를 넣어 학술적 권위를 부여해야 함. 글리치 효과는 텍스트에만 부분적으로 적용. |
| **3. [💡 솔루션] 프로토콜 소개 카드** (Instagram Carousel/Post) | Standard Protocol의 존재 이유와 가치를 설명할 때 사용. | 레이아웃을 'Before $\to$ After' 구조로 분할. Before는 어둡고 복잡하게, After는 청록색 계열의 깔끔하고 정리된 UI 요소들로 표현. | 텍스트가 아닌 **다이어그램**과 **시스템 흐름도(Flowchart)** 형태로 솔루션을 보여주어 '학습'이 아닌 '구조적 개선'처럼 느껴지게 해야 함. |
