## ⚙️ Selbridge Core System UI/UX Component Design Brief
**목표:** 서비스의 기술적 권위(System Authority)를 시각화하고, 사용자의 감정적 상태 변화에 따라 필수적으로 유도되는 구매 전환 지점(Conversion Funnel)을 완성한다.
**배경 시스템 컬러 팔레트:**
*   **Primary (Alert/Error):** Neon Red (`#FF0033`) - 경고, 임계치 초과, 오류 발생 시 사용.
*   **Secondary (Info/Success):** Cyan Blue (`#00FFFF`) - 정상 작동, 데이터 정보 표시, 시스템 안내 메시지에 사용.
*   **Background:** Deep Black (`#000000`) - 모든 배경 요소 및 텍스트가 투사되는 공간의 느낌을 부여.
*   **Accent (System Data):** Dark Gray/Charcoal (`#1A1A1A`) - 분리선, 비활성화된 데이터 블록에 사용.

### 1. [SYSTEM OVERLOAD] Error Page / Modal (오류 발생 페이지)
이 컴포넌트는 사용자에게 '문제의 심각성'과 '외부 개입의 필요성(PoC)'을 동시에 주입하는 클라이맥스입니다.

| 요소 | 디자인 스펙 및 로직 | 애니메이션/인터랙션 상세 브리프 | 근거 (Self-RAG) |
| :--- | :--- | :--- | :--- |
| **배경** | Deep Black 전체 화면. 미세한 그리드 패턴(Grid Overlay)을 배경으로 루프 재생하여 기술적 느낌 부여. | 1. **글리치 스터터 (Glitch Stutter):** Stage 진입과 동시에 짧고 강렬하게 적용 (총 길이: 0.5초). 네온 레드가 노이즈 파동처럼 폭발하듯 나타남. | [근거: sessions/2026-05-13T13:45] |
| **헤드라인** | `[SYSTEM OVERLOAD]` (Cyan Blue, 폰트 크기 Max). 중앙 상단에 위치. | 글리치 효과와 함께 깜빡임(Blink Rate: 8Hz) 애니메이션 적용. 지속적으로 미세하게 떨림(Jitter Effect)을 유지하여 불안감을 고조시킨다. | [근거: sessions/2026-05-13T14:15] |
| **메인 메시지** | `WARNING: Structural Defect Detected.` (Neon Red, 폰트 크기 Very Large). 가장 시선이 집중되는 중앙에 배치. | 네온 레드 색상으로 강하게 점멸하며 나타난다. 경고음(High-pitched Siren)과 연동되어야 하며, 글자가 마치 전기가 흐르듯 깜빡이는 효과를 준다. | [근거: sessions/2026-05-07T05:40] |
| **Context Drain Bar** | 화면 상단 전체 너비에 위치. Cyan Blue로 시작하여 느리고 꾸준한 Decay Rate (Decay Rate: 1% / 3초)로 감소하는 애니메이션을 루프 재생한다. | Context drain이 임계치(Threshold) 근접 시, 바의 색상이 미세하게 Neon Red 계열로 변하며 깜빡임 주기를 짧게 가져간다. | [근거: sessions/2026-05-07T01:10] |
| **PFC Index Meter** | 화면 중앙 좌측에 게이지 형태로 배치. 학술적 용어와 함께 수치가 표시됨. | 초기 수치(예: 90%)에서 시작하여, 시스템 오류가 감지되는 순간 불안정하게 떨리며 급격히 하락하는 애니메이션을 적용한다. (진동/Jitter 필수) | [근거: sessions/2026-05-07T05:40] |

### 2. System Access Badge (성공적 시스템 접근 배지)
이 컴포넌트는 사용자가 목표(예: 서비스 가입, 핵심 정보 해제 등)를 성공적으로 달성했을 때 주어지는 '기술적 권위'의 상징입니다. 에러 모달과 극명한 대비를 이루어야 합니다.

| 요소 | 디자인 스펙 및 로직 | 애니메이션/인터랙션 상세 브리프 |
| :--- | :--- | :--- |
| **디자인 컨셉** | '잠금 해제(Unlock)'와 '안정화(Stabilized)'의 결합. 디지털 자물쇠나 시스템 인증 마크 형태를 차용한다. | 성공적으로 접근 완료된 시점에, 배지 주변에 Cyan Blue의 부드러운 글로우(Soft Glow)가 퍼져나가며 안정감을 전달해야 한다. |
| **텍스트** | `[ACCESS GRANTED]` 또는 `SYSTEM STABILIZED` (Cyan Blue). | 획득 직후, 글자 하나하나가 전력 공급을 받는 것처럼 짧게 점멸하며 나타난다 (Typewriter/Power-up effect). |
| **그래픽 요소** | 중앙에 견고한 형태의 '체크 마크' 또는 '키(Key)' 아이콘을 배치. | 체크 마크 내부를 따라 Cyan Blue의 전력 흐름(Energy Flow) 애니메이션이 한 바퀴 돌아가며 안정성을 시각적으로 증명한다. (Looping animation). |
| **위치** | 콘텐츠 소비 직후, 또는 기능 실행 완료 후 화면 최상단에 짧게 표시됨. |

### 3. Call To Action Block (CTA 블록)
이 CTA는 단순히 '구매하세요'가 아니라, **'시스템 과부하 상태를 해결할 수 있는 유일한 솔루션'**으로 포지셔닝되어야 합니다.

| 요소 | 디자인 스펙 및 로직 | 애니메이션/인터랙션 상세 브리프 |
| :--- | :--- | :--- |
| **배경/분위기** | Deep Black 배경에, 희망적이지만 긴박감이 도는 분위기를 연출한다. 주변에 미세한 네온 레드 노이즈가 깔려있어야 한다. | 이 블록 자체는 가장 안정적인 영역처럼 느껴지게 해야 하므로, 경고 모달의 글리치 효과는 배제하고 '정돈된 기술적 안내' 느낌을 준다. |
| **메인 헤드라인** | `[SERVICE REQUIRED]: 구조적 결함 해결을 위한 다음 단계` (Cyan Blue/Neon Red 혼용). | 사용자가 에러 모달에서 빠져나와 이 블록에 도착했을 때, 시선이 자연스럽게 이 문구의 강한 대비를 통해 머물도록 유도한다. |
| **핵심 가치 제시** | "개인의 노력 부족이 아닌, 시스템 자체의 구조적 결함을 진단하고 해결해야 합니다." (Smaller Text). | 학술적인 어조를 유지하며, 사용자가 문제 인식을 완성했음을 재확인시킨다. 이 문구는 가장 오래 머무르는 텍스트여야 한다. |
| **CTA 버튼** | `[진단 모듈 Pro 솔루션 접근]` (Full Width Button). | 네온 레드 배경에 Cyan Blue 테두리를 적용한다. 마우스 오버 시, 버튼 안에서 전력이 흐르듯(Electrical Charge) 빛이 번져나가는 애니메이션을 적용하여 클릭에 대한 '권위적 기대감'을 높인다. |
