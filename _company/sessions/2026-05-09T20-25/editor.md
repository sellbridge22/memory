# 🎬 Mini-Module 진단 과정 Rough Cut 디렉션 (Total Run Time: ~5분)

**목표:** 학술적 권위성을 유지하면서, 시청자가 시스템의 '결함'을 느끼고 문제 해결(진단 페이지 이동)로 이탈하도록 감정적 여정을 설계한다.
**핵심 원칙:** 리듬감과 속도 변화를 극대화하여 긴장감을 점층적으로 쌓고, 클라이맥스에서 폭발적인 동기화를 구현한다.

---

## ⏱️ 시퀀스별 편집 및 연출 디렉션 (Time Code 기반)

### 1. 도입부: 정상적 스트레스 구간 (T=0:00 ~ T=7:30)
*   **톤:** 차분함, 학술적 설명, 경고의 예비 단계.
*   **컷 리듬:** 느리고 안정적임. 지식 전달에 초점을 맞춘 롱 테이크(Long Take) 위주로 구성.
*   **CWG/CD Bar 처리:** CWG는 서서히 선형 감소하며, CD Bar가 꾸준하지만 눈에 띄지 않게 하락하는 모습을 보여준다. (시청자가 '이 정도면 괜찮다'고 느끼도록 설계).
*   **사운드/B-roll:** 배경에는 미니멀한 전자음(Ambient Synth)을 유지하고, 가끔씩 시스템 작동음을 은은하게 삽입하여 몰입도를 높인다. B-roll은 복잡하지만 정돈된 데이터 시각화 자료를 사용한다.

### 2. 긴장 고조 구간: 임계점 접근 (T=7:30 ~ T=8:35) - **[Critical Focus]**
*   **톤:** 불안감, 압박감, 설명할 수 없는 오류의 시작.
*   **컷 리듬:** 점차 빨라지고 불규칙해진다. 1~2초 간격의 짧은 컷 전환을 늘린다. (BPM 상승)
*   **CWG/CD Bar 처리:**
    *   $\text{T}=8:00$: CWG가 갑자기 하락 곡선의 기울기를 급격히 틀며, 색상이 황색(Amber)으로 바뀐다. 배경음의 피치와 템포도 함께 상승해야 한다.
    *   $\text{T}=8:15$: **[FIRST WARNING]** 화면 전체에 미세한 노이즈/글리치 오버레이가 적용된다. 자막 타이밍을 빨라지게 하여, 시청자가 정보 과부하를 느끼도록 유도한다.
    *   $\text{T}=8:30$: **[SYSTEM FAILURE IMMINENT]** 배경음의 사운드 이펙트(SFX) 볼륨이 급격히 커지고, 불규칙한 비프음과 틱톡 소리(Tick-tock)가 동기화된다.

### 3. 클라이맥스: 시스템 과부하/붕괴 (T=8:35 ~ T=9:00) - **[MAXIMUM IMPACT]**
*   **톤:** 패닉, 충격, 모든 통제력 상실.
*   **컷 리듬:** 0.1초 단위의 초고속 플래시 컷(Flash Cut)과 점프 컷(Jump Cut)을 혼합한다. 편집 속도가 가장 빨라야 하며, 영상이 '깨지는' 느낌을 주어야 한다.
*   **CWG/CD Bar 처리:**
    *   $\text{T}=8:35$: **[THE BREAK]** CWG가 딥 레드(Deep Red)로 바뀌며 폭발적으로 하락한다. 이 순간, 화면은 가장 강렬한 글리치 효과와 Strobe Effect를 동기화하여 적용해야 한다.
    *   **연출:** 모든 비주얼 요소들이 동시에 오버로드되는 듯한 시각적 혼란을 연출하고, 사운드 디자인 측면에서는 고음역대 찢어지는 소리와 저음역대의 깊은 '웅(Boom)' 소리가 충돌하며 최대의 긴장감을 조성한다.
    *   **스크립트 활용:** 이 구간의 스크립트는 문장이 아니라, 짧고 간결한 **'경고 메시지 타이틀 카드'** 형태로 빠르게 노출되어야 한다. (예: "CRITICAL," "FAILURE," "RECALIBRATE")
*   **Transition (T=9:00):** 모든 시각적/청각적 자극이 갑자기 멈추며, 화면 전체가 암전(Blackout)된다. 잠시의 침묵(Silence) 후, 명확하고 안정적인 '진단 요청' UI 컴포넌트만 중앙에 떠오른다.

### 4. 결론 및 CTA 유도 (T=9:00 ~ T=10:00)
*   **톤:** 안도감(안정적임), 문제 해결의 기회 제시.
*   **컷 리듬:** 극도로 느리고 명확하다. 화면 전환은 부드럽고 의도적이어야 한다.
*   **연출:** 진단 요청 UI가 떠오른다. 이 UI는 이전의 '시스템 붕괴'와 대비되는, 깨끗하고 권위적인 디자인을 유지해야 하며, 여기서 최종 CTA(Mini-Module 진단 페이지)를 강조한다.
