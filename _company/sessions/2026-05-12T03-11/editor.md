# 🎬 Mini-Module: 시스템 과부하 진단 과정 (Timecode Production Roadmap)
**총 예상 길이:** 6분 30초 ~ 7분 30초
**톤앤매너:** Cinematic Industrial Drama, 고긴장감 (High Stakes), 구조적 불안함 극대화.
**주요 목표:** 시청자가 '지식 부족'이 아닌 '처리 용량의 한계(구조적 결함)'를 느낄 때 최대의 공포감을 조성하고, 해결책(Mini-Module)을 제시하여 유료 콘텐츠로 연결 (Paywall Trigger).

## 🎬 II. Timecode별 세부 편집 디렉션 및 액션 플랜
### [A. 도입부: 정상 상태와 미세 균열 (00:00 ~ 01:25)]
*   **[00:00 - 00:30] 오프닝/인트로:** 학술적이고 차분한 분위기. 셀브릿지 CI 영상 및 타이틀 애니메이션. 배경음악은 앰비언트하고 낮은 주파수의 사운드로 시작.
    *   **자막/타이틀:** 깨끗하고 명료한 '기술 시스템' 느낌의 산세리프체 사용. (애니메이션: 느리고 정확하게 Fade In).
    *   **B-roll:** 깔끔한 백지, 데이터 흐름도, 모션 그래픽으로 추상적인 지식 전달 과정을 시각화.
*   **[00:30 - 01:25] 문제 정의 및 이론적 배경:** '인지 자원' 개념 설명. 아직은 시스템의 문제가 아닌 개인의 노력 부족으로 치부되던 시대상을 다룸.
    *   **시스템 UI 구현:** **CD Bar (Green, Level 1)** 활성화 유지. (Decay Rate: Slow). CD Bar가 화면 하단에 지속적으로 존재하며 '정상' 상태를 보여주어 시청자에게 안도감을 부여함.
    *   **편집 리듬:** 느리고 일정한 컷 전환 (평균 4~6초/컷).

### [B. 위기 고조: 경고와 시스템 이상 감지 (01:25 ~ 03:40)]
*   **[01:25 - 02:30] 패러다임 전환:** "문제는 개인이 아니다." 이 지점에서 내레이션의 톤이 급격히 변하며 긴박감을 조성해야 함.
    *   **B-roll/편집 변화:** 설명 자료(파워포인트 느낌)가 빠르게 슬라이드되고, 데이터 그래프들이 불안정하게 떨리는 모션 그래픽 삽입. (컷 리듬: 가속화, 평균 2~3초/컷).
    *   **시스템 UI 구현:** **CD Bar Transition (Green $\rightarrow$ Yellow)** 발생 시점(01:45경)에 맞춰 강한 글리치 + 떨림 애니메이션을 삽입. CD Bar의 색상과 Decay Rate가 즉각적으로 빨라짐을 보여줘야 함.
    *   **CWG:** 배경으로 은은하게 상승하기 시작하며, 아직 '주의' 수준임을 나타냄.
*   **[02:30 - 03:40] 증거 제시 및 공포감 극대화:** 시스템적 결함에 대한 구체적인 사례나 데이터를 보여주며 불안감을 폭발적으로 끌어올림.
    *   **B-roll/편집 변화:** 복잡한 코드 화면, 경고등 깜빡임(Strobe Effect), 무질서하게 쏟아지는 정보의 시각화 (데이터 아비규환). 빠른 몽타주 기법 사용.
    *   **시스템 UI 구현:** **CD Bar Transition (Yellow $\rightarrow$ Orange)** 발생 지점(03:15경)에 맞춰 글리치/진동을 다시 삽입하고, 사운드 이펙트(SFX) 볼륨 급상승. CWG가 명확히 '위험' 영역 진입.

### [C. 클라이맥스: 시스템 붕괴와 Paywall 트리거 (03:40 ~ 06:15)]
*   **[03:40 - 04:40] 임계점 도달 (The Critical Peak):** 내레이션이 가장 격렬하고 절박하게 변해야 하는 구간. 시청자가 '무엇인가 잘못되었다'는 본능적 공포를 느끼게 해야 함.
    *   **B-roll/편집 변화:** 화면 전체가 노이즈와 아티팩트(Artifact)로 뒤덮임. 흑백과 네온 레드가 지배적인 색감으로 전환. 모든 컷은 극도로 짧고 충격적이어야 함 (평균 1~1.5초/컷).
    *   **시스템 UI 구현:** **CD Bar Transition (Orange $\rightarrow$ Red)** 발생 시점(03:45경)에 맞춰 가장 강력한 글리치 + 진동을 삽입하고, CD Bar의 Decay Rate를 최고 수준으로 설정. **CWG가 Critical State에 도달하며 최대 속도로 급락/급상승 로직**이 작동하는 순간을 명확히 보여줄 것.
    *   **사운드:** 모든 배경음악이 멈추고, 고주파의 날카로운 시스템 경고음(Alarm Tone)만 지속되어야 함.
*   **[04:40 - 06:15] 공백과 침묵 (The Void):** 가장 큰 혼란 이후, 일시적인 정적(Silence). 시각적으로 화면이 깨끗해지며 모든 것이 '멈춘' 것처럼 느껴져야 함. 이 순간에 "현재의 시스템은 과부하 상태이며, 외부 개입 없이는 회복 불가능합니다."라는 문구만 띄워 공백을 채움.

### [D. 해결책 제시 및 CTA (06:15 ~ 끝)]
*   **[06:15 - 07:30] Mini-Module의 등장:** 내레이션이 다시 안정되고 신뢰감 있는 목소리로 돌아옴.
    *   **시각적 전환:** 배경의 노이즈와 글리치가 사라지고, 깨끗한 UI/UX 디자인과 함께 'Mini-Module'이라는 솔루션이 명확하게 제시됨.
    *   **시스템 UI 구현:** CD Bar와 CWG가 안정적인 색상(Green)으로 돌아오며, 이 모듈을 사용함으로써 시스템의 자원이 회복되고 있음을 시각적으로 증명해야 함. (Recovery 애니메이션).
    *   **CTA:** 마지막 30초 동안은 명확한 텍스트 오버레이와 함께 "자세한 진단과 복구는 [셀브릿지 Mini-Module]에서 가능합니다."라는 문구를 반복 노출시키며, 구독/구매 링크를 강하게 유도함.
