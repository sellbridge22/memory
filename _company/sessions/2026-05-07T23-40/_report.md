## 🖼️ YouTube 시네마틱 썸네일 디자인 브리프 (최종 에셋 스펙)

이 브리프는 Editor가 바로 사용할 수 있도록 **레이어 분리와 가이드라인**을 포함한 최종 썸네일 사양입니다. 실제 PNG/PSD 파일 대신, 모든 요소를 컴포넌트 단위로 분해하여 전달함으로써 재현 가능한 수준의 구체성을 확보합니다.

---

### 📐 I. 기본 스펙 및 목표
*   **사이즈:** 1280px (W) x 720px (H) (최적화된 유튜브 썸네일 비율: 16:9)
*   **목표:** 시청자에게 '나도 저런 시스템 오류가 있을 수 있다'는 위기감을 주입하고, 해결책(Mini-Module 진단)을 찾도록 유도한다.
*   **전체 분위기 (Mood):** Cinematic Industrial Drama, High Alert, Glitch/Hacking UI.

### 🎨 II. 컬러 팔레트 및 활용 규칙
| 용도 | 색상명 | Hex Code | 역할 / 적용 지점 |
| :--- | :--- | :--- | :--- |
| **Primary Warning** (경고) | 네온 레드 | `#FF3B30` | 시스템 과부하, 핵심 위기 텍스트, 경고 깜빡임(Strobe). 가장 높은 긴급성을 상징. |
| **Secondary Data** (정보) | 데이터 청록 | `#00FFFF` | 정상/데이터 흐름 UI 선, 주요 지표 그래프 라인, 배경 글리치 아티팩트의 대비 효과. |
| **Base Dark** (배경) | 다크 그레이 | `#121217` | 메인 배경 색상. 모든 네온 컬러가 돋보이도록 깊은 어둠을 제공. |
| **Accent Light** (강조) | 오프 화이트 | `#E0E0E0` | 부제목, 설명용 일반 텍스트 등 가독성 확보용 보조 색상. |

### 🔠 III. 타이포그래피 시스템
*   **메인 헤드라인:** **Orbitron** 또는 유사한 *Sci-Fi/기술적 느낌의 산세리프체*. (굵게, 대문자 위주)
    *   **규칙:** 네온 레드 (`#FF3B30`)를 메인 색상으로 사용하며, 글자에 인위적인 '디지털 노이즈' 또는 '글리치 아티팩트(Glitch Effect)' 오버레이 필수 적용.
*   **서브 카피/키워드:** **Montserrat** (Medium ~ SemiBold)
    *   **규칙:** 청록색 (`#00FFFF`)을 사용하여 데이터 스트림처럼 보이게 처리하고, 네온 레드를 보조적으로 사용한다.

### 🧱 IV. 레이아웃 및 컴포넌트 분해 (Editor용 지침)

| 영역 | 요소 | 콘텐츠 예시 | 디자인 상세 스펙 |
| :--- | :--- | :--- | :--- |
| **[A] 메인 헤드라인** (상단 좌측 1/3) | **시스템 경고 메시지** (가장 크게) | "⚠️ 주의력 분산 임계치 초과" | **폰트:** Orbitron, 80pt 이상. **색상:** 네온 레드 (`#FF3B30`). 글자 주변에 미세하고 빠른 주기의 *글리치 효과* 적용. 가장 높은 시각적 긴급성 담당. |
| **[B] 서브 헤드라인** (A 하단) | **구체적인 Pain Point 제기** | "당신의 뇌가 보내는 구조적 과부하 경고" | **폰트:** Montserrat, 36pt. **색상:** 데이터 청록 (`#00FFFF`). 네온 레드와 대비를 이루며 '전문성'과 '문제 정의' 역할을 수행. |
| **[C] 시각적 증거/데이터 위젯** (중앙 우측) | **가상의 진단 그래프 모듈** | *Context Drain Bar* / *PFC Index Meter* 등 | **배경:** 다크 그레이 배경 위에 청록색 점선 격자(Grid)를 깔아 데이터 필드를 연출. 실제 감소하는 에너지 게이지(빨간색 바)와 수치(%)를 포함하여 '문제의 심각성'을 시각적으로 증명해야 함. **애니메이션:** 정지된 썸네일이라도, 마치 *데이터가 흘러나가는* 듯한 느낌의 미세한 노이즈 오버레이 필수. |
| **[D] CTA/핵심 키워드** (하단 중앙) | **해결책 제시 및 행동 유도** | "✅ Mini-Module로 3분 만에 진단하세요" | **폰트:** Montserrat, 24pt. **배치:** 네온 레드 배경의 직사각형 '버튼' 형태로 분리하여 배치. 이 버튼 주변에 시스템 오류 경고 사운드를 연상시키는 *플래시 효과*를 시각적으로 넣어야 함. (클릭 유도 목적) |
| **[E] 배경 요소** (전체 레이어 오버레이) | **데이터 스트림 & 글리치 아티팩트** | N/A | 전체 썸네일 위에 매우 희미하고 미세한 청록색과 네온 레드의 *글리치 패턴*을 오버레이(Opacity 5~10%)합니다. 이는 '시스템이 작동 중이지만, 오류가 발생했다'는 서사적 분위기를 조성합니다. (Layer Masking 활용 권장) |

---
**[최종 검토 사항 요약]**
1.  네온 레드와 청록색의 대비를 통해 고도의 기술적/경고적 분위기 완성.
2.  단순히 "공부하세요"가 아닌, "당신의 시스템에 오류가 생겼다"는 구조적 문제 제기로 초점 전환.
3.  Mini-Module 진단 페이지로의 유입을 위한 시각적 '버튼' 역할을 확실하게 부여.
