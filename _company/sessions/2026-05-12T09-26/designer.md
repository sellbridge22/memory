## 🖼️ Mini-Module 비주얼 스타일 가이드 & 모션 레퍼런스 키트

요청하신 대로, Editor가 완성한 '최종 제작 작동 매뉴얼'을 기준으로 가장 효과적으로 사용되어야 할 모든 비주얼 자산의 최종 레퍼런스를 제공합니다. 이 문서는 단순한 색상 코드가 아닌, **모션 그래픽 디자이너가 즉시 참고할 수 있는 애니메이션 지침서** 역할을 합니다.

### 🎨 I. 브랜드 시스템 재점검 (Palette & Typography)

| 구분 | 요소 | 컬러 코드 / 명칭 | 사용 목적 및 특징 |
| :--- | :--- | :--- | :--- |
| **메인 배경색** | `#1A1A1C` (Deep Charcoal) | 어둡고 깊은 차콜 그레이. 모든 데이터와 경고 메시지를 부각시키는 무대 장치 역할. |
| **기본 텍스트/UI** | `Electric Cyan` / `#00FFFF` | 디지털, 정보의 흐름, 정상 작동 상태(Normal State). 기술적이고 시원한 느낌 부여. |
| **경고 (Warning)** | `Amber Yellow` / `#FFC300` | 주의, 시스템 감지 필요(Monitoring Zone). 임계점 직전의 불안정함 표현. |
| **위험 (Critical)** | `Neon Red` / `#FF072A` | 즉각적 위협, 구조적 결함 도달(Crisis Point). 가장 강한 시각적 충격과 긴급함을 유발. |
| **보조색** | `System Gray` / `#666666` | 데이터 흐름 연결선, 배경의 부가 정보 등 주역을 방해하지 않는 보조 역할. |

#### 🔠 타이포그래피 가이드라인 (Typography)
*   **폰트 계열:** **Monospace Sans-Serif** (예: Source Code Pro, Roboto Mono 유사체).
*   **적용 원칙:** 모든 데이터 표시(수치, 게이지 등)와 경고 문구는 Monospace를 사용해 *시스템 출력물* 같은 권위적인 느낌을 극대화합니다. 일반 텍스트 자막은 가독성이 좋은 Sans-Serif 계열로 병행하여 대비 효과를 주되, 시스템 관련 수치는 무조건 Monospace를 적용합니다.

### ✨ II. 핵심 비주얼 애셋 레퍼런스 (Visual Asset Specs)

#### 1. Context Drain Bar (CD Bar: 집중력 고갈 막대)
*   **기능:** 시청자가 인지하는 '에너지 코어'의 상대적 잔량 시각화.
*   **모션 컨셉 스케치:**
    *   **[0:00 ~ 1:30] (Green/Yellow):** 막대가 왼쪽에서 오른쪽으로 부드럽게 채워지는 애니메이션을 사용하되, 표면 전체에 미세한 **'노이즈 필터(Noise Filter)'**를 깔아 완벽하지 않은 느낌을 유지합니다.
    *   **[1:30 ~ 2:30] (Yellow/Orange):** 막대 채움 속도가 현저히 느려지면서, 색상 변화와 동시에 **'글리치 효과(Glitch Effect)'**가 주기적으로 발생합니다. 마치 데이터 전송에 오류가 생긴 것처럼 짧게 화면이 깨지는 듯한 시각적 혼란을 줍니다.
    *   **[2:30 ~ 끝] (Red):** 막대의 색상이 네온 레드로 폭발하듯 변하면서, 표면의 노이즈 필터 강도가 **최대치(Intensity Value: 9/10)**에 도달합니다. 이와 동시에 수직 방향으로 빨간색 '스캔 라인'이 빠르게 지나가며 시청자의 눈을 압박하는 느낌을 연출합니다.

#### 2. Critical Warning Gauge (CWG: 위기 경보 게이지)
*   **기능:** 현재 상태의 구조적 결함을 수치적으로 보여주는 원형/반원형 계측기 형태.
*   **모션 컨셉 스케치:**
    *   **[0:00 ~ 1:30] (Stable):** 바늘(Pointer)이 느리고 일정한 속도로 움직이며, 주변의 배경색은 차분한 Cyan 톤을 유지합니다. 게이지 외곽선에는 약하게 깜빡이는 **'시스템 활성(System Active)'** 애니메이션을 적용합니다.
    *   **[1:30 ~ 2:30] (Warning):** 바늘 움직임이 빨라지기 시작하며, 경고 구역에 진입할 때마다 게이지 전체가 미세하게 **'진동(Vibration)'**하는 효과를 추가합니다.
    *   **[2:30 ~ 끝] (Critical Alert):**
        1.  바늘이 빨간색 임계치 영역으로 돌입하는 순간, 게이지 주변에 강력한 네온 레드 색상의 **'광원 폭발(Light Burst)'** 효과를 삽입합니다.
        2.  게이지 바깥 테두리에 반복적이고 불규칙적인 '경보 깜빡임(Strobe Flashing)'을 적용하여 시각적 피로도와 긴장감을 동시에 최고조로 끌어올립니다.

### 🚀 III. 최종 실행 지침 요약 (Editor Check List)
1.  **전환 효과:** 모든 주요 전환점은 부드러운 페이드(Fade)를 사용하지 않고, **날카로운 사운드를 동반한 하드 컷(Hard Cut)**을 기본으로 합니다.
2.  **정보 계층 구조:** 배경 정보는 `System Gray`로 처리하고, 핵심 메시지/위기 수치는 무조건 **Monospace + Neon Red (Critical) / Cyan (Normal)** 조합으로 시각화합니다.
3.  **편집 속도 조절:** 위기 고조 지점(2:30 이후), 컷 전환 사이사이에 의도적으로 0.1초~0.3초의 **'시각적 공백(Visual Void)'**을 삽입하여, 청자가 방금 본 데이터에 압도당하는 느낌을 최대화합니다.
