### 📊 Flowchart: 시스템 상태 변화 및 위기 관리 흐름 (State Machine Diagram)

| 단계 | 트리거/상태 조건 | 주요 애니메이션 컴포넌트 | 성공 케이스 (Success Path) - 기대 동작 | 실패 케이스 (Failure Path) - 예상 오류 및 처리 |
| :--- | :--- | :--- | :--- | :--- |
| **S0** | **정상 상태 (Baseline)**: 학습 시작, 데이터 흐름 안정적. | CD Bar: Green/Blue 톤 (70% 이상). CWG: 낮은 임계치 유지. | UI가 부드럽게 작동하며 정보의 흐름을 시각화함. 모든 애니메이션이 최소 지연 시간(latency) 내에 반응해야 함. | **[F-S1] 초기 로딩 오류:** CD Bar나 HUD 요소 중 하나라도 렌더링 실패. → *처리:* 즉시 해당 모듈을 비활성화하고, 사용자에게 "데이터 연결 불가" 메시지 표시 후 재시도 버튼 제공. |
| **S1** | **경고 고조 (Warning)**: 집중력 하락 감지 (70% $\to$ 40%). 시간 경과 시뮬레이션 게이지 감소. | CD Bar: Yellow/Amber 톤으로 색상 변화 및 맥동(Pulse) 효과 추가. CWG: 옐로우 구간 진입. | 1. **시각적 경고:** `rgba(255, 193, 7, 0.8)` 계열의 부드러운 깜빡임(Subtle Flicker)이 발생하며 집중력 저하를 안내. <br>2. **개입 유도:** '잠시 쉬어가세요' 또는 '다른 관점으로 보세요' 등 Recovery CTA가 자연스럽게 오버레이됨. | **[F-S2] 애니메이션 루프 오류:** 경고 깜빡임이 멈추거나, 색상 변화가 급격히 끊기는 현상 발생. → *처리:* `setInterval` 함수를 이용해 최소한의 플리커링(최소 1Hz)을 강제 유지해야 함. |
| **S2** | **위기 임계점 (Critical Threshold)**: 집중력 급락 및 데이터 역류 감지 (40% $\to$ 15%). | CD Bar: Red/Black 톤으로 변색, 깜빡임 주파수 증가. CWG: 레드 영역 진입, 최대치에 도달하며 떨림 효과(Shake) 적용. | 1. **시스템 경고 발령:** 화면 전체에 `#F44336` (Critical Red) 글리치 및 플리커링 오버레이 발생. <br>2. **강제 중단/페이월 트리거:** 콘텐츠 흐름을 강제로 끊고, '지식 컨텍스트 소실 임계점 도달' 경고와 함께 Paywall 모듈(유료 결제 유도)이 팝업됨. | **[F-S3] 시스템 과부하 오류:** 플리커링 효과가 너무 빠르거나 (Hz 초과), 여러 애니메이션이 동시에 충돌하여 화면이 깨지는 현상 발생. → *처리:* 가장 중요한 정보(Paywall CTA, 임계치 숫자)는 항상 최우선으로 렌더링되고, 배경 글리치 효과의 강도를 낮춰서 시각적 혼란을 최소화해야 함. |
| **S3** | **회복/재활성화 (Recovery)**: 유료 결제 또는 필수 Mini-Module 사용 시작. | CD Bar: Blue/Cyan 톤으로 점진적 회복. CWG: 정상 레벨로 하강 및 안정화. | 시스템이 'Flow State'에 돌입했음을 알리는 부드러운 인터페이스 전환(Transition)과 함께, 다음 학습 사이클을 안내하는 동기 부여 메시지 노출. | **[F-S4] 상태 복귀 오류:** 회복 단계 진입 시 애니메이션이 갑자기 멈추거나, 이전 위기 상황의 잔상 효과가 남아있음. → *처리:* 모든 HUD 요소는 'Clean Slate' 기준으로 초기화되는 명확한 트랜지션(예: 화면 전체에 와이프 효과)을 거쳐야 함. |

### ✅ QA 검증 체크리스트 (Checklist for Developer)

| 항목 | 테스트 내용 | 기대 결과/성공 기준 | 비고 (필수 파라미터) |
| :--- | :--- | :--- | :--- |
| **색상 코드** | 경고 레벨별 색상 전환 정확도 | Green $\to$ Amber $\to$ Red의 3단계 계단식 변화 확인. | *Green:* `#4CAF50`, *Amber:* `#FFC107`, *Red:* `#F44336` (Critical) |
| **깜빡임 효과** | 경고 고조 단계 및 임계점 깜빡임 주파수 | 1Hz $\to$ 2Hz $\to$ 5Hz로 점진적 증가 확인. | CSS `animation-duration`을 활용하여 정확히 제어. |
| **사운드 연동** | 위기 감지 시 사운드/햅틱 피드백 트리거 | 임계점 진입(S2)과 동시에 저주파 경고음을 필수적으로 재생해야 함. | API 호출 구조 명세 필요 (Sound Play, Haptic Vibrate). |
| **애니메이션 속도** | 상태 변화 간의 전환 속도 (Transition Time) | S1 $\to$ S2로 넘어갈 때 0.5초 이상의 체감적 '속도 저하' 느낌을 주어야 함. | 급격한 변화보다는 점진적인 악화가 서사적으로 유리함. |
| **반응성** | 사용자 입력에 대한 시스템 반응 지연 시간 | 사용자가 무언가를 할 때, 애니메이션의 반응은 100ms 이내여야 하며, 그보다 느리면 '시스템 오류'로 간주됨. | 최소 지연 시간을 엄격하게 준수할 것. |
