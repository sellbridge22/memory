## 🚨 시스템 과부하 경고 UI 비주얼 에셋 세트 제작 브리프 v1.2
**(Mini-Module 인터랙션 및 콘텐츠 활용용)**

본 산출물은 Mini-Module의 핵심적인 '시스템 위기 고조' 서사를 시각적으로 완성하기 위한, 즉시 개발에 투입 가능한 3가지 경고 컴포넌트 세트를 제공합니다. 모든 에셋은 **네온 레드(#FF3B30)**와 **청록색(#00FFFF)**의 대비를 통해 시스템적인 긴장감을 유도하는 것을 목표로 합니다.

---

### 1. 크리티컬 알림 배너 (Critical Alert Banner)
**[사용 목적]**: 사용자의 주의를 즉각적으로 요구하며, 핵심 데이터 임계치 돌파 직전에 삽입되는 강제 인터럽션 경고. (가장 빈번하게 사용될 컴포넌트)

| 요소 | 사양 (Specification) | 디테일 / 애니메이션 행동 (Behavior) |
| :--- | :--- | :--- |
| **위치** | 화면 상단 중앙 또는 주요 데이터 패널 상부 고정. | 다른 UI 요소를 일시적으로 덮는 오버레이 형태로 구현. |
| **색상 팔레트** | 배경: 투명(Semi-Transparent Black). 경고 영역: 네온 레드(#FF3B30)로 채워진 텍스트/테두리. 보조: 청록색(#00FFFF) (정상 대비). | **Strobe Effect**: 경고 문구가 초당 1~2회 짧게 번쩍임(Flash). |
| **타이포그래피** | **폰트:** Orbitron 또는 고딕 계열의 기술적 느낌을 주는 폰트. <br>**스타일:** 대문자, 글리치 효과 적용된 산세리프. | **헤드라인 (경고 메시지):** `[!] CRITICAL WARNING` (글리치 효과 필수). <br>**서브 카피:** 간결한 시스템 코드를 연상시키는 폰트 크기 유지. |
| **레이아웃/구조** | [🚨 경고 아이콘] + [위험 레벨: DFI 임계값 초과] + (추가 정보) | 배너 좌우에 데이터 흐름을 상징하는 미세한 노이즈 오버레이를 유지하여 '시스템의 오류' 느낌 강조. |
| **Trigger** | 특정 지표(예: 결정 피로도 지수 DFI)가 90% 이상으로 도달했을 때, 또는 사용자가 무시할 수 없는 중요한 행동을 해야 할 때 발동. |

---

### 2. 데이터 임계치 돌파 아티팩트 오버레이 (Data Threshold Breach Artifact Overlay)
**[사용 목적]**: 특정 지표(Metric)가 위험 구간에 진입했음을 시각적으로 증명하며, 마치 시스템이 과부하를 감지하고 데이터를 '오염'시키는 듯한 효과.

| 요소 | 사양 (Specification) | 디테일 / 애니메이션 행동 (Behavior) |
| :--- | :--- | :--- |
| **위치** | 데이터 그래프나 게이지 주변에 국소적으로 적용되는 오버레이 필터. | 마치 영상의 특정 프레임이 깨지거나, 전력 노이즈가 지나가는 듯한 느낌. |
| **색상 팔레트** | 기본: 네온 레드(#FF3B30)를 주축으로 하는 스파크/노이즈 효과. 청록색(#00FFFF)은 정상 구간의 경계선 역할. | **Glitch Effect**: 지표 수치 주변에 픽셀 단위의 미세한 떨림(Jitter)과 색상 분리(Chromatic Aberration)를 적용하여 데이터 신뢰성에 의문을 제기. |
| **타이포그래피** | 아티팩트 자체는 텍스트가 아니므로, 주위 수치 옆에 작은 'ERROR' 또는 'OVERLOAD' 같은 경고 토큰을 배치한다. | 글리치된 작은 코드를 배경처럼 흐르게 하여 전문성 부여. (예: `[E-123]`) |
| **레이아웃/구조** | 1) 노이즈 패턴의 격자 무늬(Grid Pattern). 2) 데이터 수치를 둘러싼 빛 번짐(Bloom) 효과와 Red Spectrum Spill. | 임계치 돌파 순간, 해당 영역 전체에 일시적인 '흑백 노이즈 + 떨림'을 적용하고 네온 레드가 폭발적으로 스며 나오게 연출한다. |
| **Trigger** | 핵심 데이터 지표가 안전 범위를 벗어나는 경계선(Threshold)을 통과하는 순간. |

### 3. 시스템 강제 종료 화면 (System Forced Shutdown Screen)
**[사용 목적]**: Mini-Module 이용 과정의 끝점 또는 심각한 과부하로 인해 사용자가 잠시 '시스템 정지' 상태에 빠지는 극적인 순간 연출. (최종 CTA 유도 장치)

| 요소 | 사양 (Specification) | 디테일 / 애니메이션 행동 (Behavior) |
| :--- | :--- | :--- |
| **위치** | 화면 전체를 덮는 Full-Screen 오버레이. Mini-Module의 최종 단계에서 발동. | 모든 인터랙션을 일시적으로 마비시키는 효과. |
| **색상 팔레트** | 주 배경: 어두운 블랙/짙은 그레이(Deep Black). 핵심 경고 색상: 네온 레드(#FF3B30)가 점진적으로 화면을 덮으며 사라지는 느낌. | **Decay Effect**: 모든 빛과 데이터 흐름이 서서히 에너지를 잃고 꺼져가는 듯한 연출 (Slow Dimming + Red Flicker). |
| **타이포그래피** | *SYSTEM SHUTDOWN IMMINENT*와 같은 대형 헤드라인. 그리고 그 아래에 미세하고 '작동 중인' 것처럼 보이는 로그(Log) 텍스트를 배치한다. | 로그는 `[STATUS: FAIL]`, `[CODE: DFI_EXCEEDED]` 등 짧은 시스템 코드가 반복적으로, 그러나 점점 느리게 출력되도록 한다. |
| **레이아웃/구조** | 화면 중앙에 '시스템 재부팅 필요'라는 메시지와 함께, 유일하게 청록색으로 깜빡이는 CTA 버튼을 배치하여 시선을 집중시킨다. | 주변 UI 요소가 마치 전원 차단된 것처럼 모두 비활성화되고, 네온 레드의 경고만이 남아 마지막 충격을 준다. |
| **Trigger** | 콘텐츠의 논리적 흐름이 끝나거나, 사용자의 '과부하 상태'를 최고조로 끌어올려 다음 단계(Mini-Module 진단)로 강제 유도할 때. |
