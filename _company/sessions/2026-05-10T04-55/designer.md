### Ⅱ. 타이포그래피 계층 구조 (Typography Hierarchy)

전체적인 분위기는 **테크니컬하고 정밀하며(Technical), 높은 가독성**을 유지해야 합니다.

*   **Primary Font (제목/강조):** **Montserrat Black** (또는 유사한 Geometric Sans-Serif)
    *   *용도:* H1, H2 등 임팩트가 필요한 제목 및 시스템 경고 문구. 강력하고 구조적인 느낌 부여.
    *   *규칙:* 대문자(ALL CAPS) 사용을 기본으로 하여 '시스템 메시지' 같은 톤앤매너를 강화합니다.

*   **Secondary Font (본문/설명):** **Pretendard** (또는 Noto Sans KR)
    *   *용도:* 본문 내용, 데이터 설명, 인터페이스 내의 모든 일반적인 텍스트. 높은 가독성 확보가 목표입니다.
    *   *규칙:* 적절한 행간(Line-height: 1.6)과 단락 구분을 통해 긴 글을 읽어도 피로도가 누적되지 않도록 설계합니다.

| 계층 | 용도 | Font (Weight) | Size (Mobile 기준) | Color Code |
| :--- | :--- | :--- | :--- | :--- |
| **H1** | 핵심 메시지, 영상 제목 | Montserrat Black | 32px - 48px | Primary Blue / Critical Red (상황별) |
| **H2** | 섹션 구분, 부제 | Montserrat SemiBold | 24px - 30px | Primary Blue |
| **Body Large** | 강조된 문단/결론 | Pretendard Regular | 18px - 20px | #333333 (짙은 회색) |
| **Body Standard** | 일반 본문 내용 | Pretendard Regular | 16px | #555555 (중간 회색) |
| **Caption/Label** | 게이지 라벨, 축 이름 | Pretendard Medium | 12px - 14px | System Gray |

### Ⅲ. 로고 타입 및 워드마크 사용 가이드

**[셀브릿지 (Selbridge)]**는 지식과 시스템 간의 연결을 의미합니다.

1.  **로고 마크(Symbol):** 두 개의 노드가 끊어지지 않고 연결되는 추상적인 다리/연결 고리 형태를 활용합니다.
2.  **워드마크:** `Selbridge` (Montserrat Bold, 30px)
3.  **최적 로고 조합 (Lockup):** [Symbol] + Selbridge (가장 많이 사용).

*   **필수 규정:**
    *   **Clear Space:** 로고 주변에는 최소한의 여백을 확보해야 합니다. 이 간격은 워드마크 알파벳 'S' 높이의 1/2 이상이어야 합니다.
    *   **최소 크기:** 웹 환경에서 명도 대비를 유지하는 최소 사이즈는 가로 30px, 세로 45px입니다.
    *   **금지 사항:** 로고 색상을 무분별하게 변경하거나, 늘이거나(Stretching), 회전시키는 행위는 금지됩니다.

### Ⅳ. 데이터 시각화 컴포넌트 표준 원칙 (Data Visualization Components)

모든 차트와 게이지는 '시스템적 상태'를 보여주는 인터페이스여야 합니다.

1.  **Context Drain Bar (CD Bar):**
    *   **기능:** 현재 인지 자원 보유량 시각화.
    *   **표준:** 전체 바의 70% 이상은 Primary Blue, 30~50%는 Warning Yellow, 50% 미만은 Critical Red로 채워집니다. 색상 경계면은 부드러운 **글리치(Glitch) 또는 노이즈 오버레이 효과**를 적용하여 '시스템적 변화'임을 강조합니다.
    *   **애니메이션:** 자원이 감소할 때, 바의 끝부분에서부터 색상이 위아래로 깜빡이는 **플리커링 패턴(3~5Hz)**을 필수적으로 구현합니다.

2.  **Critical Warning Gauge (CWG):**
    *   **기능:** 시스템 과부하 임계점 측정 및 위험 수준 표시.
    *   **표준:** 게이지는 0%부터 100%까지의 시각적 범위 내에서 작동하며, 위험도가 올라갈수록 색상이 Blue → Yellow → Red로 **지수 함수적으로(Exponentially)** 전환되어야 합니다.
    *   **시그널:** 임계점에 도달하면 게이지 주변에 붉은색 노이즈 필터와 함께 `SYSTEM OVERLOAD` 문구가 깜빡이는 애니메이션을 삽입합니다.

3.  **차트 (Bar/Line Charts):**
    *   데이터 라인은 시스템의 '경과 시간' 대비 '지표 변화(Decay Rate)'를 보여주어야 합니다.
    *   축 레이블은 일반적인 용어 대신 `PFC Overload Index`, `Context Switching Cost`와 같은 학술적 용어를 사용하여 권위를 확보합니다.

### Ⅴ. 아이콘 세트 제작 가이드라인 (Iconography Set)

아이콘은 복잡한 개념을 직관적으로 전달하는 **미니멀하고 기술적인 UI 요소**여야 합니다.

*   **스타일:** 라인 아트(Line Art) 기반의 모노라인 스타일을 채택합니다.
*   **두께:** 모든 아이콘의 선 굵기(Stroke Weight)는 통일하여 일관성을 유지합니다 (예: 2px).
*   **상태 변화 로직:**
    *   **비활성 상태:** Primary Blue 또는 System Gray로 처리된 얇은 아웃라인.
    *   **활성/강조 상태:** Critical Red 또는 Warning Yellow가 적용되며, 내부를 채우는(Filled) 방식으로 전환됩니다.

| 카테고리 | 아이콘 설명 (Conceptual Icon) | 활용 예시 |
| :--- | :--- | :--- |
| **Time/Cycle** | 🔄 재활성화 순환 화살표 | 학습 사이클, 주기적 반복 개념 강조. |
| **Data/Metric** | 📊 그래프와 데이터 포인트 조합 | 측정 가능성, 정량적 증거 제시. |
| **System/Process** | 🔌 전원 플러그 또는 노드 연결선 | 시스템 과부하, 구조적 문제임을 지적. |
| **Focus/Cognition** | ✨ 집중하는 눈 또는 파동 패턴 | 인지 자원, 주의력 고갈 상태 시각화. |
