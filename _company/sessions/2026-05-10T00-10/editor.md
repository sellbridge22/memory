## 📽️ Mini-Module 진단 과정 - Shot-by-Shot 스토리보드 (PoC 버전)

이 스토리보드는 최종 스크립트를 기반으로, 시청자의 인지 자원(Attention/Cognitive Resource) 고갈과 시스템적 결함이라는 핵심 테마를 극대화하여 몰입도를 설계했습니다. 특히 **[위기 고조 구간]**은 기술 사양서에 명시된 모든 애니메이션 효과와 오디오 이펙트를 시간 코드 기반으로 통합했습니다.

*(목표: 시청자에게 평온하지만 근본적인 의문을 제시하며 몰입 유도)*

| Timecode | Shot Description / 구성 | B-roll Type / 비주얼 요소 | 자막/타이틀 스타일 | 오디오 효과 및 리듬 |
| :--- | :--- | :--- | :--- | :--- |
| **[0:00 - 0:05]** | **OPENING:** 블랙 화면. 잔잔한 노이즈(VHS Grain)와 함께 시스템 부팅 사운드가 들린다. 천천히 데이터 플로우 다이어그램이 펼쳐지며 주요 용어들이 학술적으로 제시된다. | *B-roll:* 추상적인 회로 기판, 빛나는 데이터 스트림 (딥 차콜 배경). | **[자막]:** 흰색/옅은 청록색, 세리프 계열의 권위 있는 폰트. 핵심 키워드 강조 시 '글로우' 효과 적용. | *SFX:* 낮은 주파수의 앰비언트 드론(Low Hum Drone) 시작. *Music:* 미니멀한 피아노 또는 신디사이저 사운드로 배경 조성. |
| **[0:06 - 0:15]** | **문제 제기:** 인지 자원 그래프(CWG/CD Bar의 초기 버전)가 안정적으로 그려진다. 내레이션은 '개인적 실패' 대신 '시스템 스트레스'임을 강조하며 시각 자료로 뒷받침한다. | *B-roll:* 가상의 시스템 모니터링 인터페이스 화면 (정상 작동 상태). 데이터 그래프 애니메이션이 핵심. | **[자막]:** 학술 보고서 스타일의 명료한 폰트. 주요 수치(%)는 네온 청록색으로 강조. | *SFX:* 'Ping' 하는 측정음, 정밀하고 안정적인 전자 사운드. *Music:* 드론과 함께 미세하게 긴장감을 올리는 하이패스 필터가 추가됨. |
| **[0:16 - 0:25]** | **Mini-Module 소개:** 해결책으로서 Mini-Module을 제시하는 화면 전환. 깔끔하고 기능적인 UI로 시각적 안정감을 부여한다. (화면 분할 효과 사용) | *B-roll:* 깨끗한 인터페이스의 Mockup. 사용자 경험(UX) 측면에서 간결함 강조. | **[타이틀]:** Mini-Module 로고와 명확한 기능 설명. 톤은 신뢰감 있는 블루 계열 유지. | *SFX:* 'Whirring' 사운드 (기계가 작동하는 소리). 배경음악의 볼륨이 살짝 상승하며 기대감을 조성한다. |

### 🎬 Part 2: 위기 고조 및 시스템 오류 경험 (Crisis Peak)
*(목표: 시각적 충격을 극대화하여 '문제 인지'를 강제하고 공포심 유발)*

| Timecode | Shot Description / 구성 | B-roll Type / 비주얼 요소 | 자막/타이틀 스타일 | 오디오 효과 및 리듬 |
| :--- | :--- | :--- | :--- | :--- |
| **[0:26 - 0:35]** | **경고 발동 (Trigger):** 시스템 경고 메시지(WARNING)가 갑자기 전면을 가로막는다. CWG와 CD Bar의 변화 폭이 급격히 시작된다. | *B-roll:* 화면 전체에 **붉은색 필터 오버레이** 적용. `Glitch Overlay` 효과 (랜덤한 색상 번짐, 픽셀 깨짐)가 주기적으로 발생한다. | **[경고문]:** 네온 레드 (#FF0000). 크고 불안정한 고딕체. "CRITICAL ALERT: SYSTEM OVERLOAD DETECTED". | *SFX:* 날카로운 '삐-' 하는 경고음(High-Pitch Alarm)이 지속적으로 울린다. 저음의 **펄스 노이즈**가 깔리며 긴장감 최고조로 상승한다. (BPM 급격 증가) |
| **[0:36 - 0:45]** | **임계점 도달 (Tipping Point):** CWG와 CD Bar가 지수적으로 하락하며 임계값(Threshold)에 근접한다. 화면 전체가 불안정하게 플리커링하고, 데이터 값이 폭주하는 애니메이션이 펼쳐진다. | *B-roll:* **지수 감쇠 패턴의 애니메이션**. 배경은 딥 차콜에서 강한 레드톤으로 변화. `데이터 손실(Data Loss)`를 시각화하는 노이즈와 번짐 효과 필수. | **[경고문]:** 깜빡이는 (Flickering) 네온 레드를 사용하며, 문장이 끊어지고 왜곡되는 듯한 '글리치' 타이핑 효과 적용. "RESOURCE DEPLETION IMMINENT". | *SFX:* 경고음의 주파수가 불안정하게 변조(Pitch Bend). 짧은 순간 **침묵 (Silence)** 후 폭발적인 노이즈와 함께 다시 알람 사운드가 터져 나온다. (사운드 극대화 포인트) |
| **[0:46 - 0:55]** | **결함의 인식:** 시청자가 자신의 상태가 시스템적 결함임을 깨닫는 순간을 연출한다. 화면이 잠시 정지(Freeze Frame)되고, '진단 필요'라는 메시지가 클로즈업된다. | *B-roll:* 멈춘 듯한 카메라 움직임(Slow Motion). 배경에만 미세하게 **디지털 노이즈**가 흐르는 효과 (VHS Noise 유지). | **[자막]:** 진지하고 직설적인 어조의 흰색/레드 조합. "문제는 당신에게 있지 않습니다. 시스템 자체에 있습니다." | *SFX:* 모든 소리가 급격히 줄어들며, 낮은 주파수의 '웅-' 하는 공허한 울림(Drone)만 남는다. **극도의 침묵**이 위기감을 최고로 끌어올린다. |

| :--- | :--- | :--- | :--- | :--- |
| **[0:56 - 1:05]** | **해결책 제시:** Mini-Module의 작동 원리를 학술적으로 설명하며, 시스템을 안정화시키는 과정을 시각화한다. CWG가 서서히 회복되는 애니메이션이 핵심. | *B-roll:* 클린하고 구조적인 Mockup UI를 통해 데이터가 정렬되고 흐름이 복원되는 모습. 청록색/딥 차콜 톤으로 전환. | **[자막]:** 학술적이고 명료한 폰트 재사용. (Swipe Up/Clickable Link 애니메이션) | *B-roll:* 깔끔한 웹/앱 인터페이스의 Mockup. 포커싱된 CTA 버튼이 가장 큰 비중을 차지. | **[CTA]:** 크고 눈에 띄는 빨간색 또는 브론즈 색상. "지금, 당신의 시스템 상태를 진단하세요." (클릭 유도 문구) | *SFX:* 마지막으로 짧지만 강력한 'System Ready' 사운드와 함께 배경 음악이 페이드 아웃되며 마무리된다. **(가장 중요한 사운드 마킹)** |
