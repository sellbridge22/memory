## 🚀 유튜브 설명란 상단 CTA 카피라이팅 (Mini-Module 진단 유도)

다음 3가지 버전은 학술적 권위성('Cinematic Industrial Drama')과 '손실 회피 심리(Loss Aversion)'를 극대화하여, 시청자가 방치될 경우의 시스템적 위험을 경고하고 Mini-Module 진단 페이지로 이동하도록 설계되었습니다. 설명란 상단에 배치되어 즉각적인 액션이 유도되도록 구성했습니다.

### 🔴 버전 1: [진단/위기 직시형] - (가장 강력한 긴급성 부여)
**핵심 메시지:** '지금 모르는 손실'을 측정해야 합니다.
**적합 상황:** 영상 내용에서 위기감을 최고조로 끌어올렸을 때 사용.

```markdown
🚨 [경고: 시스템 임계점 도달 위험] 🚨

당신의 현재 집중력 수준은 데이터를 통해 정확히 진단되어야 합니다. 이 영상이 보여준 경고는 '느낌'이 아닌, 과학적 데이터 기반의 문제입니다. **지금 방치할 경우 발생하는 인지적 손실(Cognitive Loss)을 수치화하고 싶으신가요?**

👉 [🔥 Mini-Module 진단 과정 시작하기] (클릭 시 Mini-Module 페이지로 이동)
⚠️ *무료 진단 테스트를 통해, 당신의 'Context Drain Rate'와 부족한 핵심 능력을 즉시 측정하세요.*
```

### 🔵 버전 2: [기회비용/미래 손실 강조형] - (장기적 관점의 압박감 부여)
**핵심 메시지:** 시간을 낭비할수록, 돌이킬 수 없는 기회를 놓칩니다.
**적합 상황:** 영상 내용에서 '최적화된 방법'을 제시하며 동기를 부여할 때 사용.

```markdown
⏳ [시간 대비 효율성 측정] 🚀

단순히 열심히 하는 것만으로는 충분하지 않습니다. 당신의 시간은 자원이며, 비효율적인 학습 패턴으로 소모되는 매 순간이 '측정 가능한 손실'입니다. **잃어버린 시간을 데이터로 회수할 준비가 되셨나요?**

✨ [Mini-Module: 나만의 최적화 경로 찾기] (클릭 시 Mini-Module 페이지로 이동)
🔬 *전문가가 설계한 진단 툴을 통해, 당신의 잠재력과 현재 간극(Gap)을 정확히 파악하세요.*
```

### ⚫ 버전 3: [권위/시스템 교정형] - (학술적 깊이와 전문성 강조)
**핵심 메시지:** 일반적인 조언은 부족합니다. 시스템 자체의 재설정이 필요합니다.
**적합 상황:** 영상 전체가 학술적인 내용이나 복잡한 원리 설명에 초점을 맞췄을 때 사용.

```markdown
🔬 [Self-Diagnosis Required] ⚙️

지금 제시된 내용은 '개인적인 조언'이 아닙니다. 이는 **당신의 인지 시스템 자체의 근본적인 결함(Systemic Defect)을 진단하고 교정하기 위한 프로토콜**입니다. 추상적 개념에 머물지 마세요. 수치화가 필요합니다.

📊 [Mini-Module: 핵심 기능 재설정 및 측정] (클릭 시 Mini-Module 페이지로 이동)
🔗 *최첨단 진단 프레임워크를 경험하고, 당신의 학습 시스템을 임계점(Critical Point) 위로 끌어올리세요.*
```
