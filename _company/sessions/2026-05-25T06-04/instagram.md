# 🎥 3개 고강도 릴스 콘텐츠 기획안 (Reels Content Strategy)

## ✨ [핵심 전략]
1.  **프레이밍(Framing):** 모든 문제는 '사용자 부주의'가 아닌, '데이터 처리/시스템 설계 오류(Structural Flaw)'로 포장합니다.
2.  **긴급성(Urgency):** "지금 당장 점검하지 않으면 피해를 볼 수 있다"는 메시지를 지속적으로 주입합니다.
3.  **CTA 강화:** 진단 서비스가 유일하고 권위적인 출구임을 반복 강조합니다.

## 🎬 Reel 1: AI의 '보이지 않는 편향성' (The Blind Spot of Bias)
*   **주제 결함:** 학습 데이터에 내재된 구조적 차별(Bias & Opacity).
*   **타겟 감정:** 전문성, 공정성에 대한 의구심 및 불안감.
*   **Hook 포인트:** 완벽해 보이는 결과물 뒤에 숨겨진 '오류 코드' 제시.

| 구성 요소 | 상세 스크립트/비주얼 브리프 (15-20초) | 사용 기술 용어 (권위 확보) |
| :--- | :--- | :--- |
| **[HOOK] ⚡️ 문제 제기** | **(0-3s)** 네온 레드 글리치와 함께 경고음. "STOP! 이 AI 결과, 정말 믿으십니까?" 화면에 `[AUTH-STRUC: DISPARATE IMPACT DETECTED]` 코드가 플래시된다. | Disparate Impact (차별적 영향), Auth-Struct |
| **[ANXIETY] 🧠 불안감 증폭** | **(4-15s)** AI가 특정 그룹에게 높은 점수를 주는 과정의 데이터 흐름을 복잡한 다이어그램으로 보여준다. "이 시스템은 *무엇*을 학습했는지, 그 경계선이 문제입니다." (데이터 편향성 설명) | Training Data Leakage, Feature Engineering, Black Box Model |
| **[CTA] ✅ 해결책 제시** | **(16-20s)** 복잡한 다이어그램 위에 '진단 필요' 문구가 떠오른다. "당신의 인생을 결정하는 AI의 구조적 결함, 직접 진단하세요." | System Diagnosis, Explainability (설명 가능성) |

## 🎬 Reel 2: 디지털 접근성의 ‘시스템 단절’ (The Exclusion Code)
*   **주제 결함:** 웹 표준 미준수 및 보편적 접근성 결여(WCAG Failure).
*   **타겟 감정:** 소외감, 불편함에서 오는 분노와 위기감.
*   **Hook 포인트:** 아무도 주목하지 않지만, 가장 취약한 사용자 경험을 보여주며 공포 유발.

| 구성 요소 | 상세 스크립트/비주얼 브리프 (15-20초) | 사용 기술 용어 (권위 확보) |
| :--- | :--- | :--- |
| **[HOOK] ⚡️ 문제 제기** | **(0-3s)** 화면 전체에 네온 레드 글리치. `[FATAL ERROR: USER EXCLUSION]` 코드가 깜빡인다. (스크린 리더 사용자가 페이지를 읽는 듯한 음성 효과) | WCAG Non-Compliance, Semantic Failure |
| **[ANXIETY] 🧠 불안감 증폭** | **(4-15s)** 시각장애인용 프로그램이 특정 영역을 '이미지'로만 인식하고 건너뛰는 상황을 재현. "단순한 오류가 아닙니다. 정보 접근 권리 자체가 시스템적으로 차단된 겁니다." | ARIA Attributes, Tab Order Logic, Alternative Text (alt text) 누락 |
| **[CTA] ✅ 해결책 제시** | **(16-20s)** 웹사이트의 '건강 진단' 모달이 뜨며. "당신의 디지털 구조물은 안전합니까? 시스템 레벨의 접근성 감사를 받으세요." | Digital Audit, Structural Integrity Check |

## 🎬 Reel 3: 문서 무결성의 ‘시간적 결함’ (The Temporal Flaw in Signatures)
*   **주제 결함:** 데이터의 진위/출처가 위변조되거나 시간적으로 불일치하는 구조적 취약점. (셀브릿지 서비스와 직결)
*   **타겟 감정:** 돈, 권리 등 금전적 가치에 대한 불안감.
*   **Hook 포인트:** '진짜 서명'과 '가짜 서명'을 대비시켜 의심의 씨앗 심기.

| 구성 요소 | 상세 스크립트/비주얼 브리프 (15-20초) | 사용 기술 용어 (권위 확보) |
| :--- | :--- | :--- |
| **[HOOK] ⚡️ 문제 제기** | **(0-3s)** 서명이 된 문서를 확대하는 듯한 모션. 갑자기 문서의 일부가 네온 레드 글리치와 함께 번지며 '위변조 가능성' 경고를 띄운다. `[AUTH-STRUC: TEMPORAL INCONSISTENCY]` | Non-Repudiation (부인 방지), Data Provenance (데이터 출처) |
| **[ANXIETY] 🧠 불안감 증폭** | **(4-15s)** 시간의 흐름을 나타내는 그래프가 일관되지 않거나, 누가 언제 서명했는지 기록이 불완전한 애니메이션. "누군가 당신의 권리 주장을 '시간적 결함'으로 무력화 시킬 수 있습니다." | Cryptographic Hashing, Timestamping Protocol, Immutable Record |
| **[CTA] ✅ 해결책 제시** | **(16-20s)** 셀브릿지 로고와 함께 명확한 워터마크가 새겨지는 애니메이션. "구조적 결함으로 인해 당신의 권리가 위협받기 전에, 원천적으로 무결성을 확보하십시오." | Certified Integrity, Secure Lifecycle Management |
