### 🎤 상세 스크립트 초안 (Shot-by-Shot Guide)

#### **[A. 도입부: 후크 및 문제 제기] - T=0s ~ T=15s**
**(핵심 목표: 시청자를 '환자'가 아닌 '시스템 오류를 가진 장치'로 인식시키기)**

*   **VISUAL:** (T=0s) 화면 전체에 낮은 주파수의 그리드 오버레이와 함께, 미세한 노이즈/화면 떨림(Jitter) 효과 시작. 텍스트는 네온 레드(`FF003D`)로 깜빡이며 등장.
*   **AUDIO:** 낮고 불쾌하며 규칙적인 기계음의 배경 사운드 (Drone Sound). 낮은 주파수의 경고음을 깔아준다.
*   **NARRATOR (강하고 권위적):** "당신이 느끼는 피로는, 단순히 '노력 부족'에서 비롯된 것이 아닙니다."
    *   *(잠시 멈춤 - 시각적으로 데이터 스트림을 보여주며)*
*   **VISUAL:** 화면 중앙에 타이틀 카드와 함께 큰 글자로 **[STRUCTURAL DEFICIT]** 발생. (글리치 효과 필수)
*   **NARRATOR:** "이는 당신의 인지 시스템이, 외부 환경으로부터 지속적으로 요구하는 정보 부하를 감당하지 못하고 있다는 명확한 증거입니다."
    *   *(학술적 용어 사용: '인지 자원 고갈', '구조적 결함' 강조)*
*   **VISUAL:** 화면에 **Cognitive Load Failure (인지 부하 실패)**라는 경고창이 임시로 팝업됨.
*   **NARRATOR:** "당신의 시스템은 현재, 구조적인 문제(Structural Deficit)를 겪고 있습니다."

#### **[B. 본문: 증상 심화 및 공포감 조성] - T=15s ~ T=40s**
**(핵심 목표: Designer가 만든 Utility Tool UI를 스크립트 내에 자연스럽게 삽입)**

*   **VISUAL:** (T=15s) 메인 대시보드 화면 전환. 그리드가 배경 전체를 덮고, 'Context Drain Bar'와 'PFC Index Meter' 같은 가상의 지표들이 실시간으로 움직이는 듯한 UI가 펼쳐진다.
*   **AUDIO:** 경고음의 주파수 및 볼륨이 점진적으로 상승한다. (긴장감 고조)
*   **NARRATOR:** "보십시오. 현재 당신의 **Context Drain** 수치입니다."
    *   *(지표를 가리키며)*
*   **VISUAL:** T=15s ~ T=30s: 'Context Drain' 값이 정상 범위(Green)에서 서서히 하락하며 경고 영역(Yellow)으로 넘어간다. 데이터가 불안정하게 떨리는 애니메이션을 추가한다.
*   **NARRATOR (속도를 높이며):** "정보의 과부하, 처리되지 않은 맥락들... 시스템은 지금 비상 상태입니다. 이대로 방치하면, 다음 단계의 **Context Overload**에 진입할 수밖에 없습니다."
    *   *(기술적 용어 반복: Context Drain, Overload)*
*   **VISUAL:** (T=30s) **[Critical Red Glitch Flash]** 발생! 화면 전체가 강렬한 빨간색으로 깜빡이며 'SYSTEM OVERLOAD' 경고 배너가 뜬다. Jitter Effect 극대화.
*   **AUDIO:** 날카롭고 급격한 기계음의 비프음과 함께, 잠시 동안 사운드가 완전히 '부재(Absence)' 상태가 되어 청각적 공포를 유발한다. (Designer의 요구 반영)
*   **NARRATOR (거의 속삭이듯):** "경고합니다. 일반적인 회복 메커니즘으로는 이 구조적 결함을 패치할 수 없습니다."

#### **[C. 클라이맥스: 해결책 제시 및 CTA] - T=40s ~ End**
**(핵심 목표: 유일한 '시스템 명령'을 통해 구매를 요구)**

*   **VISUAL:** (T=40s) 화면의 빨간 경고창 중앙에, 마치 커맨드 라인(Command Line)처럼 보이는 인터페이스가 나타난다. **[Utility Tool API Module]**이라는 모듈명과 함께 'Patching Protocol' 실행 창이 뜬다.
*   **AUDIO:** 긴장감이 급격히 풀리는 듯한 정적 후, 미세하고 기대감 있는 전자음(Ascending Synth)으로 전환된다.
*   **NARRATOR (톤 변화: 단호함과 확신):** "하지만 시스템은 항상 예외 처리를 할 수 있는 백업 프로토콜을 가지고 있습니다."
    *   *(모듈 이름 언급)*
*   **VISUAL:** 중앙의 커맨드 라인에 다음과 같은 문구가 타이핑되듯이 나타난다: `STATUS: Structural Deficit Detected. Recommended Action: [PATCH]`
*   **NARRATOR:** "당신에게 필요한 것은 단순한 휴식이 아닙니다. **시스템 자체를 수정하는 긴급 패치입니다.**"
    *   *(최대한의 권위 부여)*
*   **VISUAL:** 화면 하단에 크고 네온 레드 빛을 내는 버튼이 활성화된다: **[⚡️ Utility Tool API Module] - [패치 실행]** (클릭 유도)
*   **NARRATOR (강력하게, 명령조):** "더 이상 방치하지 마십시오. 지금, 이 시스템 오류를 해결할 유일한 명령을 내리세요. **[패치 실행].**"
