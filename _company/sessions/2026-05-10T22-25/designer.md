## 🌐 1. 비주얼 컨셉 및 분위기 (Tone & Mood)

*   **핵심 테마:** **'The Deep Interface' (깊은 인터페이스)**
    *   시청자가 단순히 음악을 듣는 것이 아니라, 마치 고성능 시스템의 내부를 들여다보거나, 인지적 데이터를 분석하는 듯한 몰입감을 느끼게 합니다.
    *   **감정선:** 미스터리 $\rightarrow$ 경고(Alert) $\rightarrow$ 통제된 정보 흐름(Controlled Flow).

## 🎨 2. 핵심 컬러 팔레트 (Color Palette)

| 역할 | 색상 이름 | HEX 코드 | 활용 예시 및 의미 |
| :---: | :---: | :---: | :---: |
| **주 배경색** | Deep Void Black | `#0A0A1E` | 깊은 심연, 집중 상태. 가장 넓은 면적에 적용되어 압도적인 시네마틱 분위기를 조성. |
| **정보 흐름/성공** | Electric Cyan (활성화) | `#00FFFF` | 데이터가 정상적으로 인출되거나 프로세스가 성공했을 때의 신호. '지식'과 '흐름'을 상징. |
| **경고/위기 임계점** | Warning Crimson (임계치) | `#FF416C` | Context Drain Bar가 빨간색으로 변하거나, Critical Threshold에 도달했을 때 사용. 위기의 순간 자극. |
| **주요 텍스트** | System White | `#E0E0FF` | 학술 용어, 제목 등 시각적 가독성이 가장 중요할 때 사용. (순수 흰색보다 약간 어두운 느낌으로 권위 부여). |

## 📐 3. 타이포그래피 시스템 (Typography System)

| 역할 | 서체명/종류 | 특징 및 활용 규칙 |
| :---: | :---: | :---: |
| **메인 제목** | *Agency FB* 또는 유사한 Geometric Sans-Serif (Bold, All Caps) | 기술 문서나 시스템 UI에 사용되는 느낌. 학술적 권위와 긴장감을 동시에 전달하며, 대문자(All Caps) 사용을 원칙으로 합니다. |
| **보조/본문** | *Source Code Pro* 또는 Monospace Font | 데이터 값, 수치, 경고 메시지 등 시스템 로그나 코드처럼 보이게 할 때 활용합니다. 가독성이 높으며 기술적 느낌을 극대화합니다. |

## 🖼️ 4. 배경 비주얼 스타일 (Background Visual Assets)

단순한 색상 변화가 아닌, **정보 구조**를 시각화하는 방식으로 접근해야 합니다.

1.  **Primary Asset: Wireframe Grid Overlay:**
    *   전체 화면에 매우 미묘하게(Opacity 2-5%) 보이는 와이어프레임 그리드(Grid)를 깔아둡니다. 이는 공간의 '구조적 안정성'을 상징하며, 비어 있는 화면이 무겁고 정교한 느낌을 주게 합니다.
    *   **효과:** 배경에 깊이를 부여하고 학술적인 차가움을 더합니다.

2.  **Secondary Asset: Data Flow Lines (정보 흐름):**
    *   음악의 리듬이나 내용 전환 지점에 맞춰, Electric Cyan 계열의 빛나는 '데이터 연결선'이 화면을 가로지르거나 특정 오브젝트(개념어) 사이를 이동하는 애니메이션을 구현합니다.
    *   **규칙:** 이 선들은 직선적이며, 마치 레이저 트래킹이나 전기 회로처럼 보이게 합니다. (Curvy/Organic 느낌 배제).

3.  **Critical Effect: Controlled Glitch Artifacts:**
    *   화면 전체가 갑자기 깨지거나(Glitch), 색상이 불안정하게 번지는 효과는 **시스템적 결함(Systemic Flaw)**을 시각적으로 표현하는 데만 사용합니다.
    *   **사용 타이밍:** 문제 제기 순간 (0:12~0:15)이나, Context Drain Bar가 급락할 때처럼 극적인 전환점에서 짧고 날카롭게 배치하여 경각심을 최고조로 올립니다.

## 💡 5. 플레이리스트 전용 로고/워터마크 컨셉: 'System Status Indicator'

*   **컨셉명:** **[SELBRIDGE // SYSTEM STATUS]**
*   **목적:** 영상 시청 중 화면 구석에 항상 존재하며, 이 콘텐츠가 일반 음악이 아닌 '진단 도구'임을 은연중에 주지시킵니다.
*   **디자인 요소:**
    1.  **좌측 상단 (워터마크):** 작은 텍스트로 `SELBRIDGE | COGNITIVE UTILITY PROTOCOL`을 Monospace Font로 배치합니다. Opacity를 낮춰 배경에 녹아들게 합니다.
    2.  **우측 하단 (상태 표시기):** 직사각형의 미니멀한 바(Bar) 형태로, 3개의 세그먼트(Segmented Bar)로 구성됩니다. 이 막대는 현재 청취자가 어느 단계의 '인지적 흐름'에 있는지 시각적으로 나타냅니다.
        *   *색상 변화:* 평소에는 Electric Cyan으로 안정적인 리듬을 유지하다가, 내용이 고조되면 Warning Crimson으로 점멸합니다.
