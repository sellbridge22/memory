## Ⅰ. 글로벌 디자인 상수 (Global Design Constants)

### A. 컬러 팔레트 (Color Palette)
| 용도 | 명칭 | Hex Code | RGB 값 | 역할 및 사용 원칙 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Alert** | Neon Red | `#FF3B30` | R: 255, G: 59, B: 48 | **[위기/경고]** 핵심 오류 메시지, 경계선(Border), 실패 상태 강조. (가장 높은 시각적 임팩트) |
| **Data Accent** | Data Cyan | `#00FFFF` | R: 0, G: 255, B: 255 | **[정보/정상]** 성공 메시지, 활성화된 요소(Active State), 주요 데이터 포인트. (기술적 신뢰성 부여) |
| **Background** | Deep Black | `#0A0A14` | R: 10, G: 10, B: 20 | 기본 배경색. 모든 컴포넌트의 깊이감을 확보하며, 네온 색상의 대비를 극대화함. |
| **Text Default** | System White | `#EAEAEA` | - | 일반 텍스트 및 레이블. 가독성 최대화. |

### B. 타이포그래피 (Typography)
*   **폰트:** `System Mono`, `Roboto Mono`, 또는 개발자 모드 콘솔 느낌의 Monospace 계열 폰트를 최우선 적용합니다.
*   **Hierarchy:** 모든 텍스트는 기본적으로 작은 자간(letter-spacing: -0.02em)과 약간의 세리프/글리치 효과를 주어 ‘데이터 출력’ 느낌을 강조해야 합니다.

### C. 애니메이션 및 트랜지션 (Animation & Transition Rules)
*   **기본 전환 시간:** 모든 상태 변화(Hover, Focus, State Change)는 `0.2s`의 짧고 날카로운 트랜지션이 필수입니다. (`transition: all 0.2s ease-out;`)
*   **애니메이션 함수:** 단순한 Ease-in/out 대신, 시스템 전원이 켜지는 듯한 느낌을 주는 **디지털적 탄성 (Digital Spring)** 효과를 적용합니다. (예: `cubic-bezier(0.175, 0%, 0.825, 1.125)`)
*   **글리치/오버레이:** 글리치는 애니메이션 요소로 활용하며, 절대 정적 이미지에 사용하지 않습니다. 항상 깜빡임 (`@keyframes flicker`) 또는 미세한 떨림 (`jitter effect`)과 결합해야 합니다.

## Ⅱ. 핵심 컴포넌트별 기술 구현 가이드 (Component Implementation)

### A. 경고 배너 컴포넌트 (Alert Banner Component)
*   **[기본 상태]**: 배경은 `Deep Black`, 테두리(Border)는 `Data Cyan`의 점선(`1px dashed #00FFFF`)을 사용합니다.
*   **[경고 활성화 상태]**: 배너 전체가 **미세한 네온 레드 플리커링 효과**를 가져야 합니다. (CSS: `@keyframes neonRedFlicker { 0%, 100% { box-shadow: 0 0 5px #FF3B30; } 50% { box-shadow: none; } }`).
*   **[닫기 버튼(X)]**: 마우스 오버 시, X 버튼의 크기가 `scale(1.1)`로 커지면서 동시에 네온 레드로 깜빡여야 합니다.

### B. 인터랙티브 데이터 게이지 (Interactive Data Gauge)
*   **구조:** 0%부터 100%까지의 진행률을 보여주는 바 형태를 유지합니다.
*   **[데이터 채움 애니메이션]**: 게이지가 값이 변할 때, 단순히 색이 채워지는 것이 아니라 마치 **디지털 데이터 패킷이 흐르는 듯한 잔상(Trail)** 효과와 함께 팽창해야 합니다. (속도: `0.4s`).
*   **[임계점 감지]**: 수치가 특정 임계점(예: 30% 이하)에 도달하면, 게이지의 끝 부분이 네온 레드로 즉시 하이라이트 되며, 경고 사운드와 함께 시각적 진동 효과를 추가합니다.

### C. 버튼 컴포넌트 (CTA Button Component)
*   **[기본 상태]**: 배경은 투명(Transparent), 테두리는 `Data Cyan`의 1px solid 라인을 유지합니다.
*   **[Hover State]**: 마우스 포인터가 올라오는 순간, 버튼의 배경이 **매우 짧게 (0.1s) 네온 레드로 채워진 후**, 다시 투명하게 돌아오면서 내부 글자가 `Data Cyan`으로 빛나야 합니다. (순간적인 충격 효과).
*   **[클릭/활성화 상태]**: 클릭 순간, 버튼 전체가 **미세한 뎁스(Depth)**를 가지며 마치 시스템이 '처리 중'인 듯한 느낌을 주어야 합니다. (애니메이션: `translateY(-1px)` 후 원래 위치 복귀).

## Ⅲ. UX 디테일 최종 검토 브리프 (Developer Focus Points)

| 기능 | 상세 구현 요구 사항 | 기술적 주의 사항 (Miss Point) |
| :--- | :--- | :--- |
| **로딩 상태** | 일반적인 스피너 사용 금지. '데이터 로드 중' 텍스트와 함께, 배경에 청록색의 **연속된 바(Bar)**들이 지그재그로 움직이며 데이터를 수집하는 듯한 시각 효과를 구현해야 합니다. (이것을 ‘System Processing’이라 명명). | 스피너가 중앙에만 위치하면 안 됩니다. 화면 영역 전체에 걸쳐 데이터 흐름처럼 보이게 배치하여 몰입도를 높여야 합니다. |
| **포커스 상태** | 키보드 탭 이동(Tab Focus) 시, 기본 브라우저 포커스 아웃라인을 무조건 오버라이드해야 합니다. 반드시 `Data Cyan`의 네온 글로우 효과를 가진 사각형으로 대체합니다. | `:focus-visible` pseudo-class를 사용하여 구현하고, 이 효과가 모든 인터랙티브 요소(Input, Button 등)에 일관되게 적용되는지 확인하세요. |
| **오류 처리** | API 호출 실패 시, 단순히 "실패했습니다" 메시지를 띄우면 안 됩니다. 대신, 화면 중앙에 네온 레드 경고창이 뜨며, 마치 시스템 코드가 멈춘 듯한 오류 코드 (`ERROR: DATA STREAM CORRUPTION [CODE 403]`)를 함께 표시해야 합니다. | 이 에러 창은 단순히 오버레이가 아닌, **UI의 일부**처럼 보이도록 설계되어야 하며, 경고창이 나타날 때와 사라질 때 모두 `glitch` 애니메이션을 적용하여 드라마틱함을 유지합니다. |
