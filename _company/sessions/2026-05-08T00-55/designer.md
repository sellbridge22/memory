## 🚨 [FINAL] 시스템 과부하 경고 UI 에셋 패키지 (V1.0)
**목표:** 데이터가 임계점(Threshold)을 넘었을 때, 시청자에게 즉각적인 위기감과 전문적 진단 욕구를 심어준다.

### 💾 공통 디자인 시스템 사양
*   **배경:** Dark Mode (Hex: `#0D1B2A` - 어두운 네이비/블랙 그라데이션)
*   **메인 컬러 (위기):** Neon Red (`#FF3B30`) – 경고, 오류, 과부하 상태.
*   **데이터 컬러 (정상/흐름):** Data Cyan (`#00FFFF`) – 정상 데이터 흐름, 분석 정보.
*   **폰트:** Monospaced Font (예: Space Mono 또는 Roboto Mono) — 기술적이고 해킹된 느낌 강조.
*   **글리치 효과(Glitch Effect):** 모든 텍스트 및 경계선에 미세한 `offset`과 `chromatic aberration`을 적용하며, 과부하 상태에서 빈번하게 노이즈와 스캔라인이 발생한다.

### 1. [Gauge Component] - 인지 부하 게이지 (Cognitive Load Meter)
*   **기능:** 사용자의 현재 집중력 또는 인지 자원 소모율을 실시간으로 보여준다.
*   **디자인 사양:**
    *   **형태:** 반원형(Semi-circular Radial Gauge). 중앙에 'STATUS: [데이터값]%' 표시.
    *   **시각화:** 게이지 바는 0% (Cyan)에서 100% (Red)까지 채워진다.
    *   **애니메이션/상태 변화:**
        1.  **Normal State (0-60%):** Cyan색으로 부드럽게(Ease-in-out) 채워지며, 주변에 Data Flow 패턴의 미세한 빛줄기가 흐른다.
        2.  **Warning State (60-90%):** 게이지 바가 Yellow-Orange 계열로 변하며, 간헐적으로 `[WARNING]` 텍스트와 함께 낮은 주파수의 스캔라인이 지나간다.
        3.  **Critical State (90%+):** 네온 레드(`#FF3B30`) 전체를 점령한다. 게이지 바가 과부하 상태임을 알리며 **빠르게 진동(Rapid Pulsing)**하고, 주변에 강한 글리치 노이즈와 함께 `SYSTEM OVERLOAD` 경고 메시지가 플래시한다.
    *   **핵심 요소:** 게이지 중앙의 '데이터값' 숫자가 초당 3프레임씩 불안정하게 깜빡이며(Flicker), 위기 상황에서 가장 크게 흔들린다.

### 2. [Graph Component] - 핵심 지표 추이 그래프 (Key Metric Trend Graph)
*   **기능:** 특정 인지 지표(예: 주의력 분산 빈도, 작업 주기 이탈률)의 시간 흐름에 따른 급격한 변화를 시각화한다.
*   **디자인 사양:**
    *   **형태:** X축은 '시간/세션', Y축은 '임계치(Threshold)'로 설정된 꺾은선 그래프.
    *   **시각화:** 데이터 추이 선(Line)은 기본적으로 Cyan색이다. 하지만 임계치를 넘어서는 순간, **추이 자체가 네온 레드(`FF3B30`)의 파동 형태**로 변하며 시각적 충격을 준다.
    *   **애니메이션/상태 변화:**
        1.  **Baseline (정상):** Cyan색 선이 부드럽게 움직이며, 데이터 포인트마다 작은 '확인됨' 체크 마크가 찍힌다.
        2.  **Anomaly Detection (이상 감지):** 그래프의 특정 지점(데이터 임계치)에 도달하면, 해당 구간의 배경 전체가 미세하게 붉은색 오버레이로 변하며 `[ANOMALY DETECTED]` 경고 박스가 플래시한다.
        3.  **Overload State:** 데이터 선이 급격히 상승(혹은 하락)하는 지점부터 그래프 자체가 **수평 방향으로 끊기거나 겹쳐지는 (Jitter/Glitch)** 애니메이션을 실행하며, 배경에 `DATA CORRUPTION` 메시지를 짧게 삽입한다.

### 3. [Alert Component] - 시스템 경고 및 CTA 모듈 (Urgency Alert Module)
*   **기능:** 사용자에게 즉각적인 행동(CTA)이나 심각한 상태를 전달하는 최상위 인터럽트 요소.
*   **디자인 사양:**
    *   **형태:** 화면 중앙 상단 또는 하단을 가로지르는, 굵고 직사각형 형태의 '시스템 알림창'.
    *   **시각화:** 배경은 반투명한 블랙/네온 레드 그라데이션을 사용한다. 경계선(Border)이 두껍게 네온 레드로 설정된다.
    *   **애니메이션/상태 변화:**
        1.  **Appear:** 창이 갑자기 화면에 '팝업'되는 것이 아니라, 마치 시스템 콘솔에서 강제로 텍스트가 출력되듯이 **글리치 효과와 함께 빠르게 나타난다 (Typewriter + Glitch).**
        2.  **Content:** 제목은 `[CRITICAL SYSTEM FAILURE]` 등의 대문자 경고 메시지여야 하며, 그 아래에 핵심 진단 키워드(예: '주의력 분산', '인지 과부하')가 Cyan/Red 대비로 강조된다.
        3.  **CTA Integration:** 가장 하단에는 Mini-Module 진단 페이지로의 링크 버튼이 포함되는데, 이 버튼은 일반적인 UI 버튼 형태가 아닌 **`[EXECUTE DIAGNOSIS PROTOCOL]`** 같은 시스템 명령 프롬프트 형태로 디자인되어야 한다. (버튼에 마우스를 올리면 붉게 깜빡임).
