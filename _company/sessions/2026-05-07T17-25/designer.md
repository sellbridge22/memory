## 🚨 Mini-Module Visual System Guide & Thumbnail Concepts V1.5

CEO님의 지시는 현재 디자인의 핵심 구조를 완성하는 데 필수적입니다. 다만, '프레임 단위'와 같은 극도의 개발 레벨의 사양서는 별도의 UX 엔지니어링 스프린트를 통해 진행해야 합니다. 이 단계에서는 **Mini-Module에서 정의된 고유한 시스템 경고 미학(Aesthetic)**을 추출하여, 모든 마케팅 접점(썸네일, 포스트)에 일관되게 적용할 수 있는 **브랜드 비주얼 시스템**과, 이를 활용한 실행 가능한 썸네일 컨셉 3안을 제시하는 것이 가장 가치 높은 다음 스텝입니다.

---

### I. [🎨] 통합 디자인 시스템 (Visual System Specification)

Mini-Module에서 확정된 '구조적 과부하'의 느낌을 모든 콘텐츠에 이식합니다.

#### 1. 컬러 팔레트 및 사용 규칙
| 역할 | 색상명 | HEX Code | 적용 원칙 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **기본 (Base)** | 시스템 배경/암흑 모드 | `#080A14` | 모든 요소의 기본 배경. 낮은 대비를 유지하여 네온 효과 극대화. | Dark Mode 필수 적용 |
| **네트워크 (Primary)** | 안정적 데이터 흐름 | `#3A6BFF` | 일반 정보 전달, 정상 상태 UI 요소(그래프 라인 등). 차분한 신뢰성 부여. | 글리치 발생 전 단계 색상 |
| **경고 (Alert Primary)** | 시스템 경고/위기 감지 | `#FF3B30` | *핵심 컬러*. 과부하, 임계값 초과, CTA 버튼, 주요 알림 메시지에만 사용. | Neon Red 필터 필수 적용 |
| **비활성화 (Inactive)** | 비실행 데이터/미확인 | `#6C757D` | 정보의 중요도가 낮거나, 아직 측정되지 않은 지표 값에 사용. | 글리치 효과를 통해 불안정하게 처리 가능. |

#### 2. 타이포그래피 시스템
*   **메인 폰트 (Headlines/Data):** `IBM Plex Mono`, `Roboto Mono` 등 모노스페이스 계열.
    *   **사용 원칙:** 모든 제목, 데이터 수치, 경고 메시지에는 반드시 모노스페이스를 사용하여 '시스템 코드'의 느낌을 부여합니다. 가독성보다 전문성이 우선입니다.
*   **보조 폰트 (Body/Description):** `Inter` 또는 시스템 기본 산세리프.
    *   **사용 원칙:** 본문 설명, 부가 정보 등은 높은 가독성을 위해 사용하되, 글자 크기는 작게 유지하여 '시스템 로그' 같은 느낌을 부여합니다.

#### 3. 시각 효과 (Visual Effects)
| 효과 | 적용 대상 | 구현 규칙 (Developer Spec) | 목적 |
| :--- | :--- | :--- | :--- |
| **글리치 아티팩트** | 경고 메시지, 중요 데이터 전환 시 | 화면의 특정 텍스트/이미지를 수평 방향으로 1~3프레임 동안 미세하게 왜곡(Pixel Shift)시키고, 네온 레드 색상 필터를 오버레이 한다. (주파수: 불규칙적 플래시 필수). | 시스템 오류 및 데이터 신뢰도 하락 인지 유발. |
| **점진적 과열 효과** | DFI 측정 진행 중 | 경고 메시지나 게이지의 배경색이 `네트워크` → `경고 (FF3B30)`로 색상이 점진적으로, 그리고 주기적인 플래시와 함께 증가한다. | 사용자의 불안감(Anxiety)을 시각적 에너지 레벨로 측정하여 전달. |
| **HUD 오버레이** | 모든 썸네일/영상 배경 | 화면의 네 모서리나 중앙에 데이터 라인, 좌표계 그리드, 작은 시스템 상태 표시기(`[Status: Warning]`)를 배치하여 '실시간 분석 중'이라는 인상을 준다. | 영화적 드라마(Cinematic Drama)와 전문성을 동시에 확보. |

### II. [🖼️] 썸네일 컨셉 3안 (Thumbnail Concept Proposals)

**목표:** 네온 레드/글리치 시스템 경고 미학을 활용하여, '개인의 노력이 아닌 구조적 문제'라는 메시지를 전달하고 Mini-Module 진단 페이지로의 트래픽 유도.

#### 📌 Concept A: [SYSTEM ALERT] — 임계점 도달형 (The Crisis Model)
*   **주제:** 당신이 인식하지 못하는 '시스템 과부하 지표'를 시각적으로 폭발시킴.
*   **레이아웃/구도:** 좌우 분할(Split Screen). 왼쪽은 차분하고 정리된 데이터 그래프(정상 상태), 오른쪽은 글리치 노이즈가 가득한 네온 레드 경고 메시지("CRITICAL ERROR: DFI > 0.8")를 배치.
*   **핵심 시각 요소:** 배경에 모노스페이스로 작은 시스템 코드가 흘러내리는 애니메이션(글리치 효과)을 적용. 중앙에 **"당신의 집중력, 구조적 과부하 상태입니다."** 라는 핵심 문구를 네온 레드와 글리치 효과로 강조.
*   **CTA 유도:** 썸네일 우측 하단 코너에 작은 HUD 위젯으로 Mini-Module 로고를 배치하고, "진단 필요"라는 간결한 경고 메시지 삽입.

#### 📌 Concept B: [DATA LOG] — 비교 분석형 (The Diagnostic Model)
*   **주제:** '평범한 사람' vs '시스템적으로 최적화된 사람'의 데이터 차이 강조.
*   **레이아웃/구도:** 중앙에 두 개의 대조되는 바(Bar) 그래프를 배치. 왼쪽 Bar는 낮은 값(빨간색 경고), 오른쪽 Bar는 높은 값(네트워크 블루).
*   **핵심 시각 요소:** 타이포그래피를 전면에 내세우며, "개인의 의지력 vs 측정 가능한 시스템 자원" 같은 대비되는 문구를 대문자로 강조. 배경에는 복잡한 서버 랙 또는 회로도 이미지를 낮은 채도로 배치하여 전문성을 높임.
*   **CTA 유도:** 그래프 아래에 질문 형태의 카피("당신의 데이터는 어느 쪽에 가깝습니까?")를 던지고, 답변을 위한 Mini-Module 진단 페이지 클릭 유도.

#### 📌 Concept C: [WARNING MANUAL] — 경고 매뉴얼형 (The Utility Tool Model)
*   **주제:** '어떻게' 해야 하는지 알려주는 사용자 친화적 가이드 느낌을 주되, 전문성은 놓치지 않음.
*   **레이아웃/구도:** 마치 오래된 군사 또는 과학 연구 보고서의 페이지를 보는 듯한 Fixed-Grid 레이아웃. 상단에 '프로젝트: 자원 최적화' 같은 코드명을 부여하고, 핵심 내용은 박스형 UI로 구성.
*   **핵심 시각 요소:** 네온 레드 경고등 아이콘(🚨)을 반복적으로 사용하여 위기감을 조성하고, 복잡한 개념은 간단한 3단계 다이어그램으로 요약하여 제시.
*   **CTA 유도:** 페이지 맨 하단에 "자세한 진단 및 매뉴얼 다운로드 (Mini-Module)" 버튼을 명확히 배치하며, 가장 높은 시각적 대비를 제공.
