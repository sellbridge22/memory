## 📄 Mini-Module 스크립트 수정안 (서사적 결핍/손실 강조 버전)

**지시 사항:** Researcher가 제시한 학술적 근거를 바탕으로, 정보를 전달하는 것이 아니라 **'이 정보나 능력이 부족할 때 발생하는 심각한 손실(Loss)'**에 초점을 맞춰 서사적 긴장감을 극대화했습니다. 아래의 3개 섹션은 기존 스크립트 중 '문제 제기(Problem Definition)' 단계에 삽입되어야 합니다.

---

### 🔴 [섹션 1] 디지털 인지 부하 및 피로 누적 (Cognitive Overload)
*(키워드: System Failure, Working Memory Capacity, 과부하)*

**[원래 전달 방식의 문제점]:** "요즘 너무 바빠서 지치신 것 같습니다." (→ 개인의 의지 부족으로 치부됨)
**[수정 방향]:** 뇌가 아니라 **시스템 자체가 과열되어 오작동하고 있음**을 강조. 손실은 '잘못된 판단'과 '기회 상실'로 연결.

| 유형 | 스크립트 (Voice: 학술적 경고, 긴장감 고조) | 연출 지시 (Director's Note) |
| :--- | :--- | :--- |
| **서사적 전환 문구 (Hook)** | "잠깐 멈추세요. 지금 당신이 느끼는 피로는 단순히 '피곤함'의 영역이 아닙니다." | 화면 암전 후, 경고음(Alarm Tone)만 남기고 시작. 타이포그래피 강조. |
| **결핍/손실 강조 (Loss Framing)** | "당신의 뇌가 처리할 수 있는 최대 용량, 즉 *작업 기억*은 이미 임계점을 넘어섰습니다. 이 시스템 과부하는 단순한 지침의 오류를 만듭니다. 중요한 결정을 내릴 때마다, 당신의 인지적 자원은 소진되고 있고... **결과적으로, 가장 결정적인 순간에 치명적인 실수를 저지르고 있습니다.**" | '임계점', '소진', '치명적 실수' 등의 단어에 글리치/오버레이 효과 적용. (CD Bar가 Red 영역으로 진입하는 시각화) |
| **CTA 유도 문구** | "이 상태로 계속 방치된다면, 당신의 역량은 더 이상 개인의 문제가 아닙니다. *시스템적 결함*입니다." | Mini-Module을 '시스템 복원 도구'로 포지셔닝하며 Paywall 진입 준비. |

### 🟡 [섹션 2] 잦은 작업 전환 비용 (Task Switching Cost)
*(키워드: Attention Residue, Structural Loss, 비효율)*

**[원래 전달 방식의 문제점]:** "여러 가지 일을 하려니 집중이 안 되죠?" (→ 관리 능력 부족으로 치부됨)
**[수정 방향]:** 멀티태스킹 자체가 **'시간과 에너지라는 자원을 파괴하는 행위'**임을 강조. 손실은 '가치 있는 성장의 지연'으로 연결.

| 유형 | 스크립트 (Voice: 냉소적 분석, 시스템 오류 경고) | 연출 지시 (Director's Note) |
| :--- | :--- | :--- |
| **서사적 전환 문구 (Hook)** | "여러 개의 창을 띄우는 행위. 그것이 효율적인 멀티태스킹이라고 착각하셨나요?" | 빠르고 혼란스러운 오피스/코딩 화면들이 교차 편집되는 빠른 리듬의 B-roll 사용. |
| **결핍/손실 강조 (Loss Framing)** | "당신은 지금, '주의력 잔여물(Attention Residue)'이라는 이름의 구조적 부채를 지고 있습니다. 한 작업을 끝내도 이전 작업에 대한 인지적 흔적이 남아있어, 다음 작업에 완전히 몰입하지 못하게 만듭니다. **결국 당신이 쏟는 노력은 실제보다 30% 이상 비효율적으로 소모되고 있는 겁니다.**" | '구조적 부채', '비효율적' 같은 단어를 강조하며 그래프가 급격히 하락하는 시각화 삽입. (CWG의 미세한, 그러나 치명적인 하강) |
| **CTA 유도 문구** | "이 낭비되는 시간과 에너지를 측정할 수 있다면, 당신은 더 이상 '바쁘다'고 변명하지 못할 겁니다. 근본부터 재설계가 필요합니다." | Mini-Module을 '에너지 최적화 시스템'으로 포지셔닝하며 해결책 제시. |

### 🟢 [섹션 3] 정보 과부하와 맥락 상실 (Context Collapse)
*(키워드: Information Overload, Contextual Knowledge, 길을 잃음)*

**[원래 전달 방식의 문제점]:** "정보가 너무 많아서 뭘 해야 할지 모르겠어요." (→ 선택 장애/노력 부족으로 치부됨)
**[수정 방향]:** 정보 자체의 양이 문제가 아니라, **'맥락적 연결 고리(Contextual Linkage)'가 끊어져서 아무것도 이해할 수 없는 상태**임을 강조. 손실은 '방향 상실'과 '결단력 마비'로 연결.

| 유형 | 스크립트 (Voice: 광활함 속의 공포, 혼란) | 연출 지시 (Director's Note) |
| :--- | :--- | :--- |
| **서사적 전환 문구 (Hook)** | "지금 당신 앞에 펼쳐진 정보들은 정말 '지식'인가요? 아니면 그저 분류되지 않은 '데이터의 파편들'일 뿐인가요?" | 무수한 자막과 키워드가 화면을 가득 채우지만, 초점이 흐릿하고 혼란스러운 느낌 연출. (미로 같은 시각 효과) |
| **결핍/손실 강조 (Loss Framing)** | "정보는 폭발했지만, 맥락적 지식은 구조화되지 못했습니다. 이것이 바로 '맥락 붕괴(Context Collapse)'입니다. 우리는 무한한 정보의 바다에 떠밀려나 길을 잃었고... **그래서 무엇이 중요한지 판단할 기준점 자체가 사라져버렸습니다.**" | 시청자를 둘러싼 데이터 파편들이 공포 영화처럼 다가오는 연출. (시각적 압박감) |
| **CTA 유도 문구** | "파편들 사이에서 길을 잃기 전에, 이 혼란스러운 정보를 하나의 '운영 체제(OS)'로 재조립해야 합니다." | Mini-Module을 '지식 구조화 시스템'으로 포지셔닝하며 궁극적 해결책 제시. |
