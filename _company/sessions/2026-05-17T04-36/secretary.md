# ✨ [운영 플레이북] Mini-Module 콘텐츠 제작 가이드라인 (V1.0)
**목표:** 사용자의 불안감을 증폭시키고, 셀브릿지가 유일한 해결책임을 각인시킨다.
**톤앤매너:** 학술적, 긴박감 조성형, Cinematic Industrial Drama.

## 🗺️ Stage 1: 진입 및 문제 제기 (Pain Point Identification)
*   **목표:** 사용자에게 '개인의 부족'이 아닌, '외부 시스템의 구조적 오류'가 원인임을 암시한다.
*   **콘텐츠 흐름 (Timeline):** T=0s ~ T+30초

| 구성 요소 | 상세 스펙 및 가이드라인 | 에이전트 담당 역할 |
| :---: | :---: | :---: |
| **[핵심 메시지]** | "지금의 학습 방법은, 구조적 결함(Structural Defect)을 간과하고 있습니다." (개인 책임 회피 유도). | Writer/Leo (스크립트 초안) |
| **[텍스트 길이]** | **인트로 멘트:** 20~30초 분량의 구두 설명. 질문형으로 시작하여 궁금증을 증폭시킨다. | Writer |
| **[시각 자료 종류]** | 1. **데이터 스트리밍 효과:** (필수) 복잡하고 빠르게 움직이는 데이터 그리드 배경. <br>2. **질문/설문 UI Mock-up:** 사용자가 스스로 답하게 만드는 인터랙티브 요소(애니메이션 필수). | Designer/Developer |
| **[CTA 유도 문구]** | "혹시, 당신의 학습 패턴이 시스템 오류를 일으키고 있지는 않나요? 진단해 보세요." (클릭을 통해 다음 단계로 넘어가게끔 설계) | Leo/Instagram (캡션/댓글 고정) |
| **🛠️ 개발 명세 (Developer)** | **[Technical Spec]:** 이 구간은 '정보 수집'이 아니라 '데이터 입력 유도 및 불안감 조성'에 초점을 맞춰야 하므로, 로딩 페이지처럼 디자인되어야 함. 설문 응답 시 딜레이(Delay)를 주어 긴장감을 유지할 것. | Developer |

## ⚠️ Stage 2: 구조적 결함 감지 (System Alert & Dissonance)
*   **목표:** 사용자에게 객관적인 지표(데이터)를 통해 충격과 경계심을 심는다.
*   **콘텐츠 흐름 (Timeline):** T+30초 ~ T+60초

| 구성 요소 | 상세 스펙 및 가이드라인 | 에이전트 담당 역할 |
| :---: | :---: | :---: |
| **[핵심 메시지]** | "경고. 시스템 자원(Cognitive Resource) 고갈 감지. 현재 학습 패턴은 비효율적입니다." (학술 용어 사용 필수). | Writer/Leo (스크립트 초안) |
| **[텍스트 길이]** | 1. **데이터 설명:** 전문성을 갖춘 어휘를 사용하여, 왜 이 현상이 '구조적 결함'인지 논리적으로 설명한다. <br>2. **위기감 문구:** "만약 지금 개선하지 않으면..." 형태의 경고 메시지 (최대 50자). | Writer |
| **[시각 자료 종류]** | 1. **Context Drain Bar/Gauge:** (필수) 게이지가 하강하는 애니메이션(Visualizing Loss). <br>2. **PFC Index Meter:** '분산 비용', '비효율 지수' 등 학술적 수치를 보여주는 대시보드 형태의 데이터 시각화. | Designer/Developer |
| **[CTA 유도 문구]** | "이 오류를 해결할 방법이 궁금하신가요? 전문 진단이 필요합니다." (문제 해결에 대한 갈망 자극) | Leo/Instagram (댓글 유입 질문) |
| **🛠️ 개발 명세 (Developer)** | **[Technical Spec]:** Context Drain Bar의 하강 속도는 콘텐츠 전개 속도와 비례해야 하며, 이 감소가 곧 '위기감'을 상징함. 애니메이션 전환 시 네온 글리치 효과(Neon Glitch Effect)를 반드시 적용할 것. | Developer |

## 🔑 Stage 3: 솔루션 필요성 주입 (Solution Hook & CTA)
*   **목표:** 셀브릿지만이 유일한 해결책임을 확정하고, 프로필 링크로의 이동을 극대화한다.
*   **콘텐츠 흐름 (Timeline):** T+60초 ~ End

| 구성 요소 | 상세 스펙 및 가이드라인 | 에이전트 담당 역할 |
| :---: | :---: | :---: |
| **[핵심 메시지]** | "해결책은 '노력'이 아닌, '시스템 점검'입니다. 셀브릿지가 그 해결책을 제시합니다." (자신감 부여). | Writer/Leo (클라이맥스) |
| **[텍스트 길이]** | **마지막 펀치라인:** 10~15초 분량의 짧고 강력한 확정 메시지. "진단받으세요.", "지금 점검하세요." 등 명령형 사용. | Writer |
| **[시각 자료 종류]** | 1. **패치 성공 모달(Patch Success Modal):** (필수) 경고창이 사라지고, 깨끗하고 안정적인 UI가 나타나는 대비 효과 연출. <br>2. **CTA 버튼:** 크고 명확하며 '클릭 유도'가 극대화된 애니메이션 버튼. | Designer/Developer |
| **[CTA 유도 문구]** | "프로필 링크에서 [Mini-Module 진단 페이지]를 통해 구조적 오류 여부를 무료로 확인하세요." (명확한 행동 지침 제시) | Leo/Instagram (최종 캡션 및 댓글) |
| **🛠️ 개발 명세 (Developer)** | **[Technical Spec]:** Stage 2의 불안정성(Noise)에서 Stage 3의 완벽한 안정성(Signal)으로 전환되는 순간에 극적인 시각적 대비가 필요함. CTA 버튼은 페이지 진입 후에도 지속적으로 눈에 띄도록 애니메이션 처리할 것. | Developer |
