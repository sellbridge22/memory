## ⏳ Mini-Module 전환 퍼널: '시간 부족 불안 극대화' UX/애니메이션 브리프

**목표:** 사용자가 자신의 문제점을 '개인의 의지 부족'이 아닌 '시스템 구조의 결함(Time Drain)'으로 인지하게 하여, Pro 솔루션 구매 필요성을 최대치로 끌어올린다.
**톤앤매너:** 시네마틱, 경고성(Warning), 아날로그 노이즈 가미 (VHS Glitch Effect 필수)
**기반 레이아웃:** Fixed-Grid (16:9 비율 가정). 3개의 주요 Zone으로 분할.

### I. [Zone A] 초기 진단 및 문제 제기 (Diagnosis - 불안감 주입 단계)
*   **Trigger:** 사용자가 자가진단 질문에 응답을 시작함과 동시에 활성화.
*   **핵심 감정:** 의아함 $\rightarrow$ 경계심(Alertness).

| 요소 | 레이아웃 좌표/구조 (Fixed Grid Basis) | 애니메이션 상세 브리프 (Timing/Logic) | 비주얼 논리 / 색상 코드 |
| :--- | :--- | :--- | :--- |
| **1. 메인 타이머** | Top Center (Header Bar, 20% 높이 고정) | 정상 흐름(Green-Yellow Gradient) $\rightarrow$ *시간 압박 시* 급격한 노이즈와 함께 빨간색 경고 깜빡임으로 전환. (T+0s: Normal -> T+1s: Red Flash/Glitch). | **배경:** `#1a1a1a` (어두운 산업적 배경) / **정상:** `#4CAF50` $\rightarrow$ **위험:** `#FF3B30` (강한 경고 레드) |
| **2. 집중도 게이지** | Center Left (메인 정보 출력 영역, 60% 차지) | 사용자가 답을 입력할 때마다 게이지가 미세하게 하락하는 것이 시각적으로 관찰되어야 함. (Smooth Deceleration Curve). 게이지 바에 '데이터 손실' 느낌의 노이즈 필터 적용. | **색상:** `#FFB700` (불안정한 황금색) / **노이즈 효과:** `VHS Glitch Filter` 필수 적용. |
| **3. 데이터 피드백** | Center Right (보조 정보 영역, 40% 차지) | 질문에 대한 답변을 입력할 때마다, '당신의 집중 시간은 평균보다 X% 낮습니다'와 같은 구체적인 통계 수치가 데이터 패킷 형태로 빠르게 스크롤되며 노이즈가 끼임. (Rapid Data Stream Effect). | **폰트:** Mono-spaced(Monospace) 필수. / **색상:** `#6B8E23` (칙칙한 시스템 그린, 비활성화된 느낌). |

### II. [Zone B] 문제 인식 및 필요성 극대화 (Need Creation - 전환 고리 구축 단계)
*   **Trigger:** 자가진단 점수 합계가 '임계점(Threshold)' 이하로 떨어졌을 때 발동.
*   **핵심 감정:** 좌절감 $\rightarrow$ 구조적 결함에 대한 공포(Systemic Fear).

| 요소 | 레이아웃 좌표/구조 (Fixed Grid Basis) | 애니메이션 상세 브리프 (Timing/Logic) | 비주얼 논리 / 색상 코드 |
| :--- | :--- | :--- | :--- |
| **1. 경고 메시지** | 전체 화면 Overlay (Full Screen, 팝업 효과). | 갑작스러운 사운드(Low Drone/Buzzing Sound)와 함께 화면 전체가 강렬한 빨간색 깜빡임으로 전환됨. 글자가 마치 전자기 충격(EMP)을 받은 것처럼 깨지는(`Glitch`) 애니메이션 필수. (T+0s: Fade-in $\rightarrow$ T+0.5s: Red Flash/Stutter). | **배경:** `#8B0000` (어두운 경고 레드). / **메시지 폰트:** Bold, Impactful Sans-Serif. |
| **2. 핵심 카피** | Zone A 전체를 가로지르는 띠 형태(Banner), 중앙 배치. | "당신의 문제는 의지가 아닙니다."라는 메시지가 마치 시스템 코드가 오류처럼 오버레이 되어 나타나야 함. (Code Overlay/Matrix Style). 이 문구는 반복적으로 '오류' 상태로 깜빡여야 함. | **폰트:** Technical, Digital Look. / **색상:** `#FFD700` (경고용 골드)와 `Glitch Effect`. |
| **3. 대안 제시** | 화면 하단 띠 형태 (CTA 영역). | '자가 개선 노력'이라는 항목이 회색으로 흐릿하게 비활성화되고, 그 옆에 Pro 솔루션의 로고/기능 설명만 선명하고 밝게 빛나야 함(Spotlight Effect). | **대비:** 낮은 대비(`Gray-Scale`) vs. 높은 대비(`Vivid Blue`/`Gold`). |

### III. [Zone C] Pro 솔루션 제시 (Solution - 안정화 및 전환 유도)
*   **Trigger:** 사용자가 '해결책이 필요하다'는 심리적 수용 단계에 도달했을 때.
*   **핵심 감정:** 안도감 $\rightarrow$ 통제력 회복(Control).

| 요소 | 레이아웃 좌표/구조 (Fixed Grid Basis) | 애니메이션 상세 브리프 (Timing/Logic) | 비주얼 논리 / 색상 코드 |
| :--- | :--- | :--- | :--- |
| **1. 안정화 시각화** | 전체 화면 배경으로 부드러운 파형(Waveform) 패턴이 나타남. | Zone B의 격렬한 빨간색/노이즈가 사라지고, 대신 데이터를 매끄럽게 흐르는 듯한 청록색 또는 코발트블루 톤의 애니메이션이 배경을 채움. (From Chaos to Order). | **배경:** `#008080` (안정적인 사이언틱 터콰이즈). / **효과:** Smooth Gradient Shift, Data Flow Pattern. |
| **2. CTA 버튼** | 화면 중앙 하단에 고정 배치. | 'Pro 솔루션으로 전환' 버튼은 주변의 불안정한 노이즈와 완전히 분리된 듯한 물리적 존재감을 가져야 함. (Floating/Solid Structure). 마우스를 올릴 때(Hover) 빛나는 효과가 극대화되어야 함. | **색상:** `#4169E1` (진뢰청색 - 신뢰성 상징). / **효과:** 3D Depth, Subtle Glow. |
