## 🚀 PoC 영상 연계형 디자인 브리프: 비주얼 커뮤니케이션 확장 (V3.0)
**목표:** PoC 영상의 핵심 경험(시스템 경고, 데이터 과부하, 위기 고조)을 정지된 이미지 매체에 이식하여 클릭률과 전문적 신뢰도를 동시에 극대화하는 썸네일 및 포스트레이아웃 시스템 구축.

### 1. 브랜드 비주얼 시스템 가이드 (Visual System Standard)
PoC의 분위기를 유지하기 위해, 다음 요소를 핵심 디자인 요소로 규정하고 모든 산출물에 강제 적용합니다.

| 요소 | 사양/규칙 | 목적 및 활용 지침 |
| :--- | :--- | :--- |
| **핵심 팔레트** | `#FF0033` (Red Alert), `#FFCC00` (Warning), `#2A6EBF` (System Default Blue), `#111111` (Background/Deep Space) | 위험(Red), 경고(Yellow), 표준(Blue) 3색 대비를 모든 콘텐츠에 적용. 배경은 어둡게 유지하여 전자기기 UI 느낌 극대화. |
| **타이포그래피** | **헤드라인:** `Orbitron` (Bold, Condensed, Techy). \n **바디/데이터:** `Roboto Mono` (Fixed-Width, Code Look). | 학술적이고 기술적인 긴박감을 부여합니다. 모노 스페이스는 데이터나 수치를 배치할 때 필수로 사용합니다. |
| **핵심 패턴** | **글리치/VHS 노이즈:** 텍스트와 이미지 가장자리에 미세한 수평 깜빡임 효과를 시뮬레이션하는 오버레이 레이어(Opacity 5-10%) 적용. | '구조적 결함'의 존재 자체를 시각화하여, 콘텐츠에 깊이를 더합니다. |
| **정보 모듈** | 모든 썸네일/포스트는 우측 하단 또는 좌측 상단에 고정된 **[System Metric Box]** (Context Drain Bar 또는 Index Meter)를 배치해야 합니다. 이는 내용과 관계없이 '진단의 일부'처럼 보이게 합니다. |

### 2. 썸네일 컨셉 3안 (PoC 영상 연계형)
(해상도: 16:9 / 핵심 목표: 문제 발견 $\to$ 위기 고조 시각화)

| 컨셉명 | 스토리텔링 초점 | 레이아웃 구성 및 요소 배치 | 기대 효과 |
| :--- | :--- | :--- | :--- |
| **[A] 시스템 경고형 (The Red Alert)** | *문제 발견* - "당신의 뇌는 이미 과부하 상태다." | **배경:** `#111111` 바탕에 미세한 그리드 패턴 적용. \n **중앙:** 인물의 고뇌하는 모습(혹은 추상적인 뇌/데이터 구조물)을 배치하고, 그 위에 거대한 `SYSTEM OVERLOAD` 경고 배너를 오버레이 합니다. \n **핵심 요소:** 좌측 상단에 **[CD Bar]** (빨간색으로 가득 찬 바)와 "CRITICAL DECAY DETECTED" 텍스트를 배치. \n **헤드라인:** `Orbitron` 볼드, 흰색/노란색 경고 문구로 '3가지 구조적 결함' 등 구체적인 숫자를 언급하며 위기감 조성. | 가장 직관적으로 '위험'을 전달합니다. PoC 영상의 클라이맥스를 그대로 가져와 공포감을 극대화합니다. (가장 추천) |
| **[B] 데이터 분석형 (The Diagnostic Chart)** | *해결 필요성 인식* - "당신의 학습 방식은 오류를 내고 있다." | **배경:** 어두운 청색 계열(`Deep Space Blue`)에 복잡한 그래프 선들이 흐르는 듯한 패턴을 적용. \n **중앙:** 핵심 인물 사진 대신, '학습 사이클'이나 '시간 관리'와 관련된 추상적 데이터 시각화(예: 역삼각형 모양의 하락 곡선)를 배치. \n **핵심 요소:** 우측에 `Roboto Mono`로 작성된 **[PFC Index Meter]** (현재 수치 65% $\to$ 경고 30%)와 'Cognitive Load Index'라는 전문 용어를 타이틀처럼 사용. \n **헤드라인:** 질문형 카피 (`왜 당신은 효율적이지 못한가?`)를 사용하여 호기심을 유발합니다. | 지식 기반의 권위를 확립합니다. 감성적 공포보다, '데이터로 증명된 문제'라는 논리적 압박감을 줍니다. (교육 콘텐츠에 적합) |
| **[C] 아날로그 오류형 (The Glitch Evidence)** | *즉각 진단/증거 제시* - "이것은 시스템의 결함이다." | **배경:** VHS 노이즈와 필름 그레인을 강하게 적용한 톤. 낮은 채도와 따뜻하고 불안정한 색감을 사용. \n **중앙:** 모자이크나 '깨진' 듯한 형태로 처리된 핵심 키워드 이미지(예: 책, 타이머)를 배치. \n **핵심 요소:** 전경에 투명도가 높은 `Glitch Effect` 텍스트 레이어(`ERROR CODE: [XXXX]`)를 반복적으로 오버레이합니다. \n **헤드라인:** '구조적 결함'이라는 핵심 키워드를 가장 크게, 그리고 깨진(Distorted) 타이포그래피로 처리하여 시각적 충격을 극대화합니다. | 신비롭고 미스터리한 느낌을 주며, 콘텐츠에 깊은 서사적 배경을 부여합니다. (브랜딩 단계에서 활용 적합) |
