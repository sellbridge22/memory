## 🎬 Mini-Module 진단 과정: 상세 편집 구성 및 Shot List (V1.2)

본 문서는 'Mini-Module 진단 과정' 영상의 제작팀(편집자, 디자이너, B-roll 담당)을 위한 최종 가이드라인입니다. 시간 코드에 맞춰 필요한 시각적 요소와 애니메이션 호출 지점을 명확히 분리하여 전달합니다.

### ⚙️ I. 전반적인 편집 원칙 및 스타일 가이드 (General Directives)

| 항목 | 디테일 / 액션 | 참고 사항 |
| :--- | :--- | :--- |
| **톤앤매너** | Cinematic Industrial Drama. 학술적 권위성(Academic Authority) 유지. | 색상: 딥 차콜, 브론즈, 경고 시 #FF0000 (Critical Red), #FFA500 (Warning Orange). |
| **컷 리듬 (Pacing)** | 초반부: 느리고 명료함 (정보 전달). 중반부(Crisis): 매우 빠르고 불규칙적임 (패닉/긴장감). 후반부: 다시 명확하고 단호함 (해결책 제시). | 3초 이상의 정지된 샷은 피하고, 항상 미세한 움직임(카메라 패닝, 글리치 등)을 유지할 것. |
| **자막 스타일** | 고딕 계열의 산세리프체 사용. 핵심 키워드는 '글리치 아티팩트' 또는 '네온 레드'로 강조. | 정보 전달 시에는 화면 하단 1/5 지점에 배치. 경고 메시지時は 중앙 오버레이. |
| **사운드 디자인** | 배경 음악은 미니멀한 신스 사운드의 긴장감을 유지하며, 모든 애니메이션 발생 지점마다 '시스템 알림음(Beep)', '전압 누설음(Humming/Leak)' 등 SF적 효과음을 의무적으로 삽입. |

### 📈 II. 시간대별 상세 Shot List 및 디렉션 (Time-Coded Breakdown)

#### **[Phase 1: 문제 제기 및 인식 (The Gap) | Time Code: 0:00 - 0:35]**
*   **목표:** 시청자에게 현재 지식 시스템의 근본적인 결함(위기감)을 인지시킨다.
*   **B-roll 유형:** 고해상도의 복잡한 데이터 스트림, 작동하는 서버실, 회로도 패턴 (클린하고 차가운 톤).

| Time Code | 스크립트 핵심 내용 | Shot 구성 및 액션 디렉션 | 애니메이션/UI 호출 지점 |
| :--- | :--- | :--- | :--- |
| **0:00 - 0:15** | *[나레이션 도입]* "당신은 이 지식을 충분히 이해하고 있다고 생각했을지 모릅니다. 하지만..." | (OPENING) 느리고 안정적인 데이터 흐름 영상으로 시작. 화면 전체에 학술적 권위가 느껴지는 타이틀 애니메이션 호출. | **Title Sequence:** 딥 차콜 배경, 브론즈/화이트 색상 사용. 서서히 나타나며 글리치 효과를 주되, *완벽하게* 끝남 (안정성 연출). |
| **0:15 - 0:25** | "...현재 당신의 시스템은 이미 과부하 상태입니다." | 데이터 스트림이 갑자기 불규칙하게 흔들리는 B-roll 사용. 자막에 '과부하(OVERLOAD)' 키워드를 강조하며 순간적인 *노이즈/지직거림* 효과 삽입. | **Context Drain Bar (CD Bar):** 화면 상단 1/3 지점에 배치. 초기에는 녹색으로 가득 차 있다가, 나레이션 중 '과부하' 언급 시점부터 서서히 주황색으로 감소하며 경고 시작. |
| **0:25 - 0:35** | "핵심적인 메커니즘을 놓치고 있습니다." | 시스템 전반에 걸쳐 미세한 진동(Tremor Effect)이 감지되는 클로즈업 샷. 자막은 '메커니즘'과 '놓치다'에 집중적으로 강조. | **Critical Warning Gauge (CWG):** 화면 우측 상단에 배치. CD Bar의 감소와 연계되어, 미세하게 빨간색 영역으로 진입하며 *점진적인* 경고음을 발생시킨다. |

#### **[Phase 2: 위기 고조 및 시스템 실패 (The Crisis) | Time Code: 0:35 - 1:45]**
*   **목표:** 긴장감을 최고조로 끌어올리고, 기존 지식의 무용함을 극대화한다. 이 구간은 가장 역동적이어야 함.
*   **B-roll 유형:** 빨간색/주황색 계열의 경고등 플래시, 데이터가 폭발적으로 누출되는 시각 효과(Leakage), 붉은 필터와 글리치 아티팩트가 가미된 영상들.

| Time Code | 스크립트 핵심 내용 | Shot 구성 및 액션 디렉션 | 애니메이션/UI 호출 지점 |
| :--- | :--- | :--- | :--- |
| **0:35 - 0:50** | *[강한 어조]* "이것은 단순한 부족함이 아닙니다. 근본적인 구조적 결함입니다." | 화면 전체에 빨간색/주황색의 플래시가 주기적으로 지나감 (Strobe Effect). 빠른 컷 전환(Quick Cuts)을 통해 정보 과부하 상태 연출. | **CWG:** 급격하게 주황색 -> 빨간색으로 치솟으며 'CRITICAL'이라는 타이틀이 중앙에 깜빡임. **사운드:** BPM 변화와 함께 경고음의 피치가 높아지고, 굉음(Roar)을 삽입. |
| **0:50 - 1:20** | "기존 방식으로는 이 결함을 해소할 수 없습니다." | 여러 실패하는 시스템 컴포넌트 (예: 와이어프레임이 깨지는 효과). 화면에 'ERROR'라는 단어가 반복적으로 글리치하며 오버레이됨. | **Glitch Overlay:** 지속적이고 불규칙하게 삽입되어 영상 전체를 감싸야 함. CD Bar가 빨간색으로 바닥까지 떨어지며 *배터리 방전* 효과음과 연계된다. |
| **1:20 - 1:45** | "오직 시스템의 재설정이 필요합니다." | 잠시 정지된 듯한 '암흑'의 순간을 만든 후, 매우 빠르게 Mini-Module 관련 정보가 빛처럼 폭발적으로 등장하는 연출(Flash of Insight). | **UI 전환:** 빨간색 경고 화면이 급격히 사라지고, 청록색/흰색 계열의 '해결책 인터페이스'로 전환됨. (시각적 안도감과 동시에 기술적 우월함을 부여) |

#### **[Phase 3: 해결책 제시 및 CTA (The Solution) | Time Code: 1:45 - 끝]**
*   **목표:** Mini-Module이 유일하고 절대적인 해법임을 각인시키고, 다음 행동(CTA)을 명확하게 지시한다.

| Time Code | 스크립트 핵심 내용 | Shot 구성 및 액션 디렉션 | 애니메이션/UI 호출 지점 |
| :--- | :--- | :--- | :--- |
| **1:45 - 2:05** | "Mini-Module은 당신의 시스템에 필요한 유일한 업그레이드입니다." | 깨끗하고 구조화된 UI가 화면을 채움. Mini-Module의 핵심 기능을 그래픽으로 명료하게 분할하여 보여줌 (A, B, C 모듈). | **CTA 시퀀스:** Module 이름과 효능이 마치 API 호출되듯(데이터가 연결되는 것처럼) 깔끔한 브론즈/화이트 톤으로 나타남. 배경 음악의 긴장감이 부드러운 기대감으로 전환됨. |
| **2:05 - 끝** | "지금, 시스템 진단부터 시작하십시오." | CTA 문구와 링크를 화면 중앙에 배치하고 시청자가 읽을 시간을 충분히 제공해야 함. (최소 10초 이상 유지). | **Final Overlay:** Mini-Module 로고 및 웹사이트 URL이 애니메이션과 함께 가장 크게 표시됨. 자막에는 "손실을 막으세요"라는 문구를 반복적으로 노출시켜 심리적 압박감 부여. |
