# 🚨 [셀브릿지] 시스템 경고 UI 컴포넌트 라이브러리 v1.0
**목표:** '구조적 시스템 과부하'라는 핵심 주제를 전 채널에 일관되고 위기감 있게 적용하는 표준 모듈 제공.
**톤앤매너:** Cinematic, Industrial, High-Tech Alert System (미스터비스트급의 스케일과 미니멀한 데이터 HUD 조합)

## 1. 메인 제목 컴포넌트: [GLITCH HEADLINE]

가장 중요한 메시지(Video Title, Module Headline 등)에 적용되는 핵심 모듈입니다. 단순 텍스트를 넘어 '시스템 오류'처럼 보이게 하는 것이 목표입니다.

| 속성 | 사양 (Spec) | 상세 지침 (Instructions) |
| :--- | :--- | :--- |
| **글꼴** | `Monospace` 계열 (예: IBM Plex Mono, Space Mono) | 굵기: SemiBold ~ Bold. 자간(Letter Spacing): 미세하게 넓게 설정하여 기계적인 느낌 강조. |
| **컬러 팔레트** | Primary Text: `#FFFFFF` (흰색)<br>Accent/Warning: `#FF3B30` (네온 레드) | 텍스트 자체는 흰색으로 하되, 오류 메시지나 핵심 키워드에만 네온 레드를 사용. |
| **기본 배치** | 중앙 정렬 또는 좌측 상단 고정 위치(Fixed Position). | 영상의 시선이 가장 먼저 머무르는 공간을 차지하도록 설계. |
| **글리치 효과 (Glitch Effect)** | **1. Chromatic Aberration:** R/G/B 채널 분리 및 미세한 X축 오프셋 적용.<br>**2. Flicker/Jitter:** 3~5 프레임 단위의 불규칙적인 밝기 변화(0% ~ 90%).<br>**3. Data Corruption:** 간헐적으로 글자 일부가 `[ERR]` 또는 `#` 기호로 대체되었다가 복구되는 애니메이션 적용. | **적용 타이밍:** 콘텐츠 시작 시, 혹은 주제 전환이 일어나는 지점 등 '시스템 불안정'을 연출해야 할 때만 작동. 지속적인 사용은 피할 것. (강한 임팩트 유지) |
| **애니메이션 로직** | **In-Effect:** 100ms 동안 글리치 효과가 빠르게 반복되다가, 마지막 프레임에서 원래의 깨끗한 상태로 '시스템 재부팅'되는 듯한 느낌으로 안정화. |

## 2. 경고 바 컴포넌트: [ALERT BANNER]

서브 카피, CTA(Call to Action), 중요 알림 등 보조 정보를 전달하는 네온 레드 기반의 표준 모듈입니다.

| 속성 | 사양 (Spec) | 상세 지침 (Instructions) |
| :--- | :--- | :--- |
| **기본 크기** | 높이: 30px ~ 50px (배치 위치에 따라 유동적)<br>가로 폭: 콘텐츠 영역 전체를 커버하는 방식. | 모바일 환경(9:16)에서는 화면 상단과 하단에 각각 고정 배치를 고려해야 함. |
| **컬러 팔레트** | 배경: `#FF3B30` (네온 레드)<br>텍스트: `#FFFFFF` 또는 `#FFFFCC` (약한 노란색/흰색) | 네온 레드를 주력으로 사용하며, 경고의 심각도를 나타냄. |
| **종류별 활용** | **A. System Warning:** `[SYSTEM ALERT] - DFI 임계치 초과 감지.`<br>**B. CTA Prompt:** `[필수 진단 필요] Mini-Module을 통해 과부하 상태를 측정하십시오.`<br>**C. Sub-Copy:** (경고 메시지를 담은 부가 설명 문구). | 경고 바의 내용은 반드시 짧고, 강렬하며, 행동(Action)을 유도하는 방식으로 작성되어야 함. |
| **애니메이션 로직** | 1. 등장 시: 좌우에서 네온 레드 빛이 스캔하듯 지나가며 (Scanning Sweep), 메시지가 '데이터 로드'되는 듯한 효과를 준 후, 정지. <br>2. 지속 시간: 콘텐츠 전반에 걸쳐 고정적으로 노출될 경우, 배경에 매우 느린 `VHS Noise` 오버레이와 미세한 떨림(`Jitter`)을 상시 적용하여 긴장감 유지. |

## 3. 데이터 지표 컴포넌트: [SCANNING GAUGE]

사용자의 '구조적 시스템 과부하' 상태를 측정하고 시각적으로 증명하는 핵심 모듈입니다. DFI(Decision Fatigue Index) 등을 표현합니다.

| 속성 | 사양 (Spec) | 상세 지침 (Instructions) |
| :--- | :--- | :--- |
| **기본 구조** | 원형(Circular Gauge) 또는 수평 바(Linear Bar) 형태의 게이지를 기본으로 합니다. | 시각적 몰입도를 높이기 위해 단순히 숫자를 보여주는 것이 아니라, '게이지가 채워지는/비워지는' 과정 자체가 정보여야 함. |
| **색상 로직 (Critical Tri-Color)** | 🟢 **정상(Normal):** `#00CC99` (안전한 청록) - 게이지의 시작 지점.<br>🟡 **경고(Warning):** `#FFC72C` (앰버/노랑) - 임계값 진입 시. <br>🔴 **위험(Critical):** `#FF3B30` (네온 레드) - 과부하 상태 감지. | 색상 변화는 게이지의 메인 로직이며, 이 경계를 넘어서는 순간 애니메이션이 폭발적으로 변해야 함. |
| **표준화된 스펙** | **1. Full Screen Gauge:** 직경 300px 기준. (Mini-Module 진단 결과 페이지용). 배경에 미세한 회로 기판(Circuit Board) 패턴 오버레이 필수.<br>**2. Corner Overlay Gauge:** 가로 150px, 세로 80px. (유튜브/인스타 영상 시청 중 상시 노출 HUD 요소). 화면의 구석진 곳에 배치하여 '시스템 모니터링' 느낌을 부여. |
| **애니메이션 로직** | **측정 과정:** 게이지가 채워지거나(정보 입력) 비워지는(시간 경과, 집중력 하락) 애니메이션은 절대 선형적으로 진행해서는 안 됩니다. 마치 '데이터 스트림이 흐르듯', 불규칙하고 빠르게 변화하며 에너지 코어가 역류하는 듯한 **'펄스 효과(Pulse Effect)'**를 적용해야 합니다. |
