## ⚙️ 하이파이 디자인 브리프: 핵심 트래킹 모듈 (Deep Metric Tracking)

본 브리프는 애니메이션 전문가가 즉시 작업을 시작할 수 있도록, 컨셉, 시각적 스펙(Visual Specs), 인터랙션/애니메이션 레퍼런스를 포함하여 작성되었습니다. 전체적인 톤은 'Cinematic Industrial Drama'를 유지하며, 사용자가 능동적으로 사용하는 'Utility Tool'의 느낌을 극대화하는 데 중점을 둡니다.

### MODULE #1: 집중도 게이지 (Focus/Concentration Gauge)

**[🔍 기능 정의]**
사용자의 실시간 집중 상태(Flow State Level)를 측정하고 시각적으로 피드백합니다. 단순한 막대가 아닌, 에너지 코어나 시스템 압력계처럼 보이도록 설계하여 '측정 가능한 자원'이라는 느낌을 부여합니다.

**[🎨 비주얼 스펙 (Visual Specs)]**
*   **위치:** 화면의 측면 또는 하단 중앙에 위치하며, 메인 UI 요소들과 연결된 것처럼 디자인되어야 합니다. (System Overlay 느낌)
*   **형태:** 원통형(Cylindrical) 압력 게이지 혹은 에너지 코어 형태. 바늘이나 레벨이 움직이는 것이 아니라, 액체/광원처럼 내부가 차오르거나 빠지는 형태로 표현합니다.
*   **컬러 팔레트 (Dynamic):**
    *   **배경/프레임:** Deep Charcoal (`#1A1E24`) - 산업적인 금속성 질감.
    *   **Low Focus (방황/산만):** 딥 브론즈-그레이 (`#6B7085`). 어둡고 불안정한 색조. 낮은 주파수의 미세한 깜빡임(flicker) 효과가 동반됩니다.
    *   **Medium Focus (몰입 시작):** 밝은 브론즈 (`#C19A5B`). 안정적인 빛으로 채워지는 느낌. 규칙적이고 부드러운 흐름을 가집니다.
    *   **High Flow State (최적 집중):** 순도 높은 골드-브론즈 (`#FFD700` 계열의 강렬한 브론즈). 이 색상이 게이지 내부를 가장 강력하게 채우며, 전반적인 UI에 미세한 빛 번짐(Glow) 효과를 부여합니다.
*   **타이포그래피:** 메인 텍스트는 모노스페이스체 (예: IBM Plex Mono). 현재 수치(%)와 상태 레이블은 간결하게 배치하여 계기판 느낌을 강화합니다.

**[🎬 인터랙션/애니메이션 레퍼런스]**
1.  **초기 로딩:** 게이지 내부가 어둠 속에서 전력 공급이 시작되듯, 아주 미세한 스파크와 함께 빛이 점진적으로 차오르며 초기 상태를 표시합니다 (Line Drawing Effect).
2.  **Focus Drop (산만함):** 집중도가 급격히 떨어질 때(예: 10% 이상 하락), 게이지의 브론즈 액체가 역류하는 듯한 *급강하 애니메이션*을 보여줍니다. 동시에 배경에 빨간색 경고 사운드와 함께 짧은 시스템 오류 메시지(`WARNING: FOCUS DECAY DETECTED`)가 플래시 됩니다.
3.  **Optimal Flow State (최적 흐름):** 집중도가 최고점에 도달하면, 게이지 내부의 브론즈 광원이 마치 에너지를 방출하듯 주변 UI 컴포넌트(예: 타이머)를 향해 빛줄기를 쏘아 보내는 드라마틱한 효과를 연출합니다.

### MODULE #2: 작업 주기 재조정 (Work Cycle Re-adjustment Module)

**[🔍 기능 정의]**
사용자가 설정한 집중/휴식 주기의 경과와 다음 사이클의 준비 상태를 시각화하고, 시스템적 리셋 과정을 드라마틱하게 보여줍니다. 단순히 타이머가 끝나는 것이 아니라, '에너지가 소진되고 재충전되는' 과정으로 포지셔닝해야 합니다.

**[🎨 비주얼 스펙 (Visual Specs)]**
*   **위치:** 화면의 하단 중앙을 가로지르는 형태로 배치되어, 전체 작업 시스템의 *메인 컨트롤 패널*처럼 보이게 합니다.
*   **형태:** 2개의 독립된 섹션(WORK / BREAK)이 나란히 존재하며, 각 사이클은 마치 전력을 공급받는 회로망 위에 표시되는 것처럼 디자인합니다.
*   **컬러 팔레트 (Systemic):**
    *   **Work Mode:** 브론즈-골드(`#C19A5B`)가 주도적이며, 활성화된 사이클을 상징합니다. 배경에 전력 흐름 같은 얇은 연결선(Connection Lines)이 미세하게 깜빡입니다.
    *   **Break Mode:** 차분한 딥 차콜-브론즈(`#4A5060`)가 주도적이며, 시스템 재정비의 느낌을 줍니다. 에너지를 비축하는 듯한 '대기 전력' 느낌이 강조됩니다.
    *   **Transition/Reset:** 모든 색상이 잠시 어두워졌다가(딥 차콜), 다음 사이클 시작과 함께 강렬하고 빠르게 브론즈 빛으로 전환되는 것이 핵심입니다.
*   **타이포그래피:** 시간 표시에는 디지털 클럭 느낌의 고정폭 폰트를 사용하며, 진행률은 전진하는 바늘이나 그래프 형태로 시각화합니다.

**[🎬 인터랙션/애니메이션 레퍼런스]**
1.  **Work Cycle Start:** 타이머가 시작되면, 배경 회로망을 따라 브론즈 빛이 왼쪽에서 오른쪽으로 빠르게 흐르는 애니메이션(Data Flow Animation)이 재생됩니다. 동시에 게이지(Module #1)에 집중 에너지가 공급되는 시각적 연동 효과를 줍니다.
2.  **Work Cycle End (Transition):** 남은 시간이 거의 바닥나면, 타이머 숫자가 떨리는 듯한 불안정한 플래시 현상을 보입니다. 경고음과 함께 시스템이 **강제 비상 정지(Emergency Stop)**되는 느낌의 시각적 충격파가 발생합니다.
3.  **Break Cycle Start (Reset):** 사이클 전환 후, 화면 전체에 짧은 노이즈와 글리치 효과(Glitch Effect)를 준 뒤, 브론즈 빛이 마치 *새로운 전력원이 공급된 것처럼* 재부팅되는 강력한 시각적 드라마를 연출합니다. 이 때의 애니메이션 속도는 이전 사이클보다 훨씬 빠르고 경쾌하게 느껴져야 합니다.
