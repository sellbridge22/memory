## ✨ 핵심 흐름 (Core Flow) 기반 와이어프레임 스펙
**목표:** 사용자 공포(Fear of Failure)를 자극하여, 셀브릿지 서비스의 필요성을 극대화하고 결제 페이지로 유도한다.
**톤앤매너:** Cinematic Industrial Drama + System Error Alert (네온 레드/사이언 블루).

### 🖼️ Wireframe 1: 문제 인식 및 경고 단계 (The Diagnosis)
*   **목표:** 사용자의 '현재 방식'의 근본적 결함(Structural Flaw)을 학술적으로 제시하며 불안감을 증폭시킨다.
*   **레이아웃:** 스크롤 기반, 정보 밀도 높음.

| 요소 | 디자인 스펙/위치 | 애니메이션/인터랙션 (필수) | [근거: Self-RAG] |
| :--- | :--- | :--- | :--- |
| **Context Drain Bar** | 화면 하단 고정, 좌우 10px 마진. 배경색 `#00FFFF` (Cyan Blue). | T=0s부터 느린 Decay Rate로 지속 감소 루프 재생. 데이터가 빠질 때마다 미세한 노이즈 효과 추가. | `[Context Drain Bar] 활성화` |
| **PFC Index Meter** | 화면 중앙 상단, 학술적 계기판 형태 (Gauge). 배경색 `#111111`. | 초기 수치(예: 75%) 표시. 사용자가 '문제점'을 읽거나 스크롤 할 때마다 값이 **불규칙하게 미세 떨림** (`~0.5%` 간격) 애니메이션 적용하여 불안감 유도. | `PFC Index Meter 등장` |
| **Problem Statement** | 핵심 결함 메시지 (예: "기존 방식은 인지적 비용을 과소평가합니다.") | 텍스트에 네온 레드(`FF0033`)로 강조되는 키워드마다 짧은 글리치 스터터 효과 적용. | `Primary Alert` |
| **CTA Button** | 없음 (이 단계에서는 정보 흡수만 유도). | - | - |

### 🖼️ Wireframe 2: 시스템 오류 발생 클라이맥스 (The Breakdown)
*   **목표:** 기존의 모든 해결책이 실패했음을 시각적으로 '증명'한다. 경고를 통해 위기감을 최고조로 끌어올린다.
*   **레이아웃:** 전체 화면 오버레이(Overlay).

| 요소 | 디자인 스펙/위치 | 애니메이션/인터랙션 (필수) | [근거: Self-RAG] |
| :--- | :--- | :--- | :--- |
| **오버레이 모달** | 전체 화면을 덮는 블랙 배경의 반투명 오버레이. | Stage 1에서 강한 글리치 스터터(Glitch Stutter) 필터를 폭발적으로 적용하며 진입. | `Glitch Effect` |
| **경고 메시지** | 중앙에 거대한 타이포그래피: `"WARNING: Structural Defect Detected"` | 네온 레드 플래시 (`#FF0033`)와 함께 8Hz 깜빡임(Blink Rate)을 유지하며 점멸. 가장 강렬한 시각적 충격 포인트. | `[SYSTEM OVERLOAD] Modal` |
| **Source Degradation Effect** | 모달 주변 배경 그리드에 데이터 노이즈가 깨지듯 나타남 (깨진 전력망 느낌). | 주기적으로 고주파의 짧은 노이즈 패턴(Noise Pattern)을 발생시키며, 불안정한 사운드를 동기화. | `[Source Degradation Effect] 작동` |
| **CTA Button** | *임시 비활성화 상태* (사용자가 '해결책'을 찾게 유도하기 위해 버튼은 숨김). | - | - |

### 🖼️ Wireframe 3: 해결책 제시 및 신뢰 구축 (The Solution Hook)
*   **목표:** 셀브릿지의 시스템이 이 결함을 어떻게 추적하고 고치는지, 그 과정을 학술적으로 설명하며 기대감을 형성한다.
*   **레이아웃:** 명확한 구조의 비교 섹션.

| 요소 | 디자인 스펙/위치 | 애니메이션/인터랙션 (필수) | [근거: Self-RAG] |
| :--- | :--- | :--- | :--- |
| **핵심 가치 시각화** | 3단계 플로우차트 (Problem $\to$ Flaw Detection $\to$ Solution Implementation). | 각 단계가 순서대로 활성화되면서, 연결선이 사이언 블루(`00FFFF`)의 전력 흐름처럼 빛나는 애니메이션. | `정보 흐름` |
| **데이터 시각화** | 시스템 작동 원리(예: '인지 자원 재배치 알고리즘')를 복잡한 다이어그램으로 표현. | 마우스 오버/스크롤에 반응하여 데이터 포인트가 팝업되며, 마치 실제 시스템이 계산하는 듯한 느낌을 준다. | `기술적 디테일` |
| **CTA Button** | 섹션 하단 중앙. 텍스트: "시스템 진단 요청 및 솔루션 접근" | 배경색은 깊고 어두운 블랙/네이비, 테두리만 네온 레드로 점멸하는 형태. (다음 단계로의 전환을 예고). | `[SERVICE REQUIRED] Modal` 준비 단계 |

### 🖼️ Wireframe 4: 결제 유도 및 최종 CTA (The Conversion)
*   **목표:** 모든 긴장감을 해소하고, '이것만이 답'이라는 확신과 함께 결제를 실행시킨다.
*   **레이아웃:** 단일 모달(Modal) 기반의 압축적 레이아웃.

| 요소 | 디자인 스펙/위치 | 애니메이션/인터랙션 (필수) | [근거: Self-RAG] |
| :--- | :--- | :--- | :--- |
| **모달 배경** | 전체 화면을 덮는 깊고 붉은 블랙 배경. | 모달이 부드럽게 페이드 인(Fade In)하며, 주변에 희미한 노이즈 필터가 잔상처럼 남는다. | `[SERVICE REQUIRED] Modal` |
| **헤드라인** | 중앙 상단: 거대한 네온 레드 타이포그래피로 `"SYSTEM FAILURE"` (점멸 효과 유지). | 강력하고 극적인 폰트(예: Eurostile 계열)를 사용하며, 네온 레드로 점멸. | `[SERVICE REQUIRED] Modal` |
| **결제 정보** | 서비스 명칭, 패키지 가격 (3가지 옵션), 필요 금액. | 간결하게 정리하되, 각 옵션 아래에 "이 솔루션을 통해 얻는 가치"를 짧은 학술적 문구로 배치. | - |
| **최종 CTA Button** | 화면 중앙 하단. 버튼 크기: 최대화 (Full Width). 텍스트: `"솔루션 활성화 및 결제 시작"` | **색상:** 고채도 사이언 블루 (`#00FFFF`). 배경은 채우고, 클릭 시 미세한 전력 흐름 사운드와 함께 버튼이 압축되며 다음 페이지로 넘어간다. 이 색상은 '신뢰 구축'의 상징으로 사용한다. | `Secondary Info` (Cyan Blue 활용) |

---
**디자인 요약:**
*   **Color Palette:** Primary Red (`#FF0033`), Secondary Cyan Blue (`#00FFFF`), Background Black/Dark Grey (`#111111`).
*   **Typography:** 제목은 구조적이고 기계적인 느낌의 산세리프 폰트 (예: Impact, Eurostile 계열). 본문은 가독성 높은 고딕체.
*   **전환 원칙:** 모든 섹션 간 전환(Transition)에는 반드시 '글리치 스터터' 효과를 적용하여 시각적 일관성과 극적인 긴장감을 유지합니다.
