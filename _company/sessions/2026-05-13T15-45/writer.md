### 🎬 Script Draft 1: 확증 편향 (Confirmation Bias)
**주제:** 당신의 지식은 '필터'를 통과한 오류일 수 있다.
**길이 목표:** 45초 ~ 50초
**톤:** 권위적, 고발적, 학술적 긴장감 최고조

| 시간대 | 오디오 (Voice Over / BGM) | 비주얼 액션 및 지시사항 (Designer Module 활용) |
| :--- | :--- | :--- |
| **[0:00 - 0:08]** | **(BGM: 긴장감 높은 드론 사운드 시작)** VO: 당신은 자신이 세상을 *제대로* 보고 있다고 착각합니다. 하지만, 그 시야 자체가 오류일 수 있습니다. `[SYSTEM ALERT]` 네온 레드 글리치 효과와 함께 타이틀 카드 등장. | **STAGE 1: 진단 및 문제 제기 (Diagnosis)**<br/>`Context Drain Bar`가 빠르게 하강하며 긴장감을 조성.<br/>PFC Index Meter에 '정보 신뢰도' 수치가 불안정하게 깜빡임. |
| **[0:08 - 0:25]** | VO: 우리의 뇌는 본능적으로 자신의 가설을 뒷받침하는 정보만을 찾아냅니다. 이것이 바로 '확증 편향(Confirmation Bias)'이라는 구조적 결함입니다. 우리는 반대 증거를 아예 **필터링**해버리죠. 마치 우리 시스템 자체가 오류 코드를 무시하도록 설계된 것처럼요. | **STAGE 2: 문제 심층 분석 (The Deficiency)**<br/>화면 분할(Split Screen) 효과 사용. 한쪽은 밝고 명확한 '가설 지지 데이터', 다른 쪽은 흐릿하고 거부되는 '반대 증거'를 대비시켜 시각적 오류 강조.<br/>그래픽: Filter Bubble이 씌워지는 애니메이션. |
| **[0:25 - 0:40]** | VO: 기존의 지식이나 논리적인 반박만으로는 이 고리를 끊어낼 수 없습니다. 우리는 외부 시스템의 개입, 즉 *객관화된 구조 진단 도구*가 필요한 단계에 와 있습니다. 지금 당신에게 부족한 것은 의지가 아닙니다. **패치(Patch)**입니다. | **STAGE 3: 서비스 필요성 주입 (Necessity)**<br/>'ERROR' 모달이 중앙에 나타나며 `[CORE LOGIC FAILURE]` 메시지 표시.<br/>Utility Tool API Module의 개념도를 네온 블루로 오버레이하며 '필수 시스템 컴포넌트'처럼 보이게 함. |
| **[0:40 - 0:50]** | VO: 셀브릿지는 당신의 무의식적 편향성을 시스템 레벨에서 역추적하고, 진짜 구조적 결함을 강제로 노출시키는 **시스템 패치(System Patch)**입니다. 이 오류 코드를 수정할 수 있는 유일한 방법입니다. | **STAGE 4: CTA 및 후크 강화.**<br/>Utility Tool API Module 인터페이스가 클로즈업되며 빛을 발함.<br/>**[SYSTEM ALERT]**: 화면 전체에 경고 메시지 오버레이. |
| **CTA 문구** | (음성 변조, 단호하게) 당신의 인지 아키텍처는 지금 비정상 상태입니다. [SERVICE REQUIRED] |

### 🎬 Script Draft 2: 지적 과부하 (Cognitive Overload)
**주제:** 정보 홍수 속에서 우리의 두뇌가 작동을 멈추고 있다.
**길이 목표:** 35초 ~ 40초
**톤:** 경고성, 통계 기반, 압박감

| 시간대 | 오디오 (Voice Over / BGM) | 비주얼 액션 및 지시사항 (Designer Module 활용) |
| :--- | :--- | :--- |
| **[0:00 - 0:08]** | **(BGM: 빠르고 혼란스러운 데이터 노이즈 사운드 시작)** VO: 당신은 지금 몇 개의 정보에 압도되어 있습니까? 매 순간, 우리의 인지 자원은 한계를 넘어 폭주하고 있습니다. `[SYSTEM ALERT]` 네온 레드 글리치 효과와 함께 타이틀 카드 등장. | **STAGE 1: 진단 및 문제 제기 (Diagnosis)**<br/>`Context Drain Bar`가 매우 빠르게 하강하며 불안정성을 강조.<br/>PFC Index Meter에 '처리 용량' 수치가 급격히 떨어지는 애니메이션 구현. |
| **[0:08 - 0:25]** | VO: 현대 사회는 지식의 양을 요구합니다. 하지만 인간의 뇌는 무한한 데이터 스트림을 감당하도록 설계되지 않았습니다. 끊임없이 주입되는 정보 폭주는 우리의 인지 자원을 고갈시키고, 결국 '인지적 불안정성(Cognitive Instability)'이라는 오류 코드를 발생시킵니다. | **STAGE 2: 문제 심층 분석 (The Deficiency)**<br/>데이터 스트림이 화면을 가득 채우는 시각 효과 사용.<br/>그래픽: 인간의 두뇌를 거대한 서버처럼 묘사하고, 과부하로 인해 스파크가 튀는 애니메이션. |
| **[0:25 - 0:35]** | VO: 단순히 '쉬면' 해결될 문제가 아닙니다. 시스템 자체가 고장 난 겁니다. 문제는 당신의 노력 부족이 아니라, 현재 인지 아키텍처에 근본적인 결함이 있다는 증거입니다. 이제는 강제 패치가 필요합니다. | **STAGE 3: 서비스 필요성 주입 (Necessity)**<br/>'ERROR' 모달이 나타나며 `[OVERLOAD FAILURE]` 메시지를 표시.<br/>강력하고 복잡한 데이터 분석 그래프가 '해결책'을 찾아내는 듯 움직임. |
| **[0:35 - 0:40]** | VO: 셀브릿지는 이 과부하 상태를 정상화시키는 유일한 시스템 안정화 모듈입니다. 당신의 인지 자원을 보호할 수 있는 필수 패치입니다. | **STAGE 4: CTA 및 후크 강화.**<br/>Utility Tool API Module 인터페이스가 중앙에 나타나며 시원하게 작동하는 모습 연출.<br/>**[SYSTEM ALERT]**: 화면 전체에 경고 메시지 오버레이. |
| **CTA 문구** | (음성 변조, 단호하게) 인지 시스템 과부하 상태입니다. [SERVICE REQUIRED] |

### 🎬 Script Draft 3: 주의력 분산 비용 (Attention Fragmentation Cost)
**주제:** 집중력이 사라진 것이 아니라, '자원'이 고갈되고 있다.
**길이 목표:** 40초 ~ 50초
**톤:** 직설적, 자극적, 경제학적 접근

| 시간대 | 오디오 (Voice Over / BGM) | 비주얼 액션 및 지시사항 (Designer Module 활용) |
| :--- | :--- | :--- |
| **[0:00 - 0:08]** | **(BGM: 잔잔한 듯 하지만 불안정한 미니멀리즘 사운드)** VO: 혹시, 집중력이 떨어졌다고 생각하십니까? 아닙니다. 당신의 '주의력 자원'가 고갈되고 있는 겁니다. `[SYSTEM ALERT]` 네온 레드 글리치 효과와 함께 타이틀 카드 등장. | **STAGE 1: 진단 및 문제 제기 (Diagnosis)**<br/>`Context Drain Bar`를 '집중 에너지 레벨'로 은유.<br/>PFC Index Meter에 '주의력 유지 시간(Attention Span)' 수치가 지속적으로 떨어지는 애니메이션 구현. |
| **[0:08 - 0:25]** | VO: 우리는 모든 정보를 단발성으로 소비하며, 집중력을 자원으로 착각합니다. 하지만 주의력은 한정된 에너지이며, 파편화될수록 그 비용(Cost)은 기하급수적으로 증가합니다. 당신의 에너지는 '분산'되고 있습니다. | **STAGE 2: 문제 심층 분석 (The Deficiency)**<br/>돈이 새는 것을 보여주는 애니메이션처럼, 주의력이 여러 방향으로 빠져나가는 시각적 효과 연출.<br/>그래픽: Attention Cost를 측정하는 계량기 장치와 함께 'Non-linear decay' 그래프 제시. |
| **[0:25 - 0:40]** | VO: 이 문제는 습관의 문제가 아닙니다. 당신의 인지 아키텍처가 끊임없이 외부 자극에 의해 재설정(Reboot)되고 있기 때문입니다. 근본적인 설계 오류가 있는 것입니다. 스스로 해결할 수 없는 시스템 문제입니다. | **STAGE 3: 서비스 필요성 주입 (Necessity)**<br/>'ERROR' 모달이 나타나며 `[ATTENTION FAILURE]` 메시지를 표시.<br/>어떤 '도구'나 '노력'으로는 안 되고, 전면적인 시스템 재설계가 필요함을 강력하게 암시. |
| **[0:40 - 0:50]** | VO: 셀브릿지 Cognitive Stabilizer Module(CSM)은 이 자원을 회수하고 최적의 상태로 강제 복구하는 '시스템 패치'입니다. 당신이 다시 시스템 안정성을 확보할 수 있게 해주는 유일한 방법입니다. | **STAGE 4: CTA 및 후크 강화.**<br/>Utility Tool API Module 인터페이스가 마치 고급 하드웨어처럼 작동하는 모습을 클로즈업.<br/>**[SYSTEM ALERT]**: 화면 전체에 경고 메시지 오버레이. |
| **CTA 문구** | (음성 변조, 단호하게) 주의력 자원 고갈 임계점에 도달했습니다. [SERVICE REQUIRED] |
