### 📊 최종 확정 인포그래픽 데이터 세트 (총 3종)
**테마:** 시스템 오류 경고 (System Failure Alert)
**핵심 컬러:** 네온 레드 (#FF0033), 사이언 블루 (#00FFFF), 배경: 딥 블랙
**형식:** 숏폼(Reels/Shorts)용 15~20초 분량의 '경고 메시지' 포맷

#### **[Set 1] 지적 과부하 (Cognitive Overload): 데이터 폭주 경고**
*   **문제 정의:** 현대 정보 환경에서 인간의 인지가 감당할 수 있는 처리 용량을 초과하는 현상.
*   **시스템 메타포:** CPU/RAM 사용률이 비정상적으로 높은 상태.
*   **시각화 요소:** 데이터 스트림, 오버레이된 텍스트, 경고 그래프.

#### **[Set 2] 시간적 비효율성 (Time Drain): 구조적 결함 경고**
*   **문제 정의:** 개인의 노력이 아니라, 현대 사회 시스템 자체가 시간을 빼앗아가는 근본적인 패턴.
*   **시스템 메타포:** 누수되는 자원(Leakage), 효율이 떨어지는 파이프라인.
*   **시각화 요소:** 시계/흐름 다이어그램, 그래프 아래에 '누수' 애니메이션 필수.

| 항목 | 제목 (Title) | 내용 구성 및 애니메이션 가이드 | DATA INPUT REQUIRED |
| :--- | :--- | :--- | :--- |
| **헤드라인** | `[SYSTEM FAILURE] Time Drain Pattern Detected` | 네온 블루/레드가 번갈아 깜빡이며 불안감을 조성. 글리치 스터터 효과 적용. | - |
| **핵심 통계 1** | **최대 비효율 구간 Top 3:** (가장 많은 시간을 소모하는 활동 패턴) | 리스트 및 아이콘화: ① 알림 확인(Notification Check), ② 작업 전환(Context Switching), ③ 불필요한 탐색(Infinite Scrolling). 각 항목 옆에 '시간 손실' 배터리 게이지 하락 시각화. | `[DATA INPUT REQUIRED]: 지식 노동자가 가장 많은 시간을 낭비하는 구체적인 행동 패턴 Top 3의 통계적 비중 (예: 전체 시간 중 X%)` |
| **핵심 통계 2** | **'인지적 마찰(Cognitive Friction)' 비용:** 작업을 시작하거나 전환할 때 발생하는 정신적 에너지 소모. | 그래프/수치: 'A 작업 $\to$ B 작업'으로의 전환 시, 초기 단계에서 필수적으로 드는 추가 노력(에너지)을 수치화하고 이를 과장하여 보여줌. | `[DATA INPUT REQUIRED]: 특정 작업을 시작하거나 전환하는 데 필요한 평균 시간 또는 에너지 비용 (시간/%)` |
| **CTA 메시지** | `DIAGNOSIS COMPLETE: PATCH NEEDED.` | '진단 완료'라는 톤으로, 이 모든 문제가 개인의 잘못이 아니라 시스템적 결함임을 확정적으로 선언. | - |

*   **시스템 메타포:** 배터리 방전, 시스템 다운 카운트.
*   **시각화 요소:** 카운트다운 타이머, 경고등, '임계점' 그래프.
