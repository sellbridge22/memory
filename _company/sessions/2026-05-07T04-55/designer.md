## 📊 Mini-Module 인터랙티브 프로토타입 스토리보드 (최종본)
**Goal:** 사용자가 '시스템 구조적 과부하'를 자가 진단하고, 이를 해결하기 위해 Pro 솔루션이 필수적임을 인지하는 UX 플로우 구축.
**Format:** Fixed-Grid Storyboard & Technical Specification Sheet
**톤앤매너:** SYSTEM ALERT / Cinematic Industrial Drama (네온 레드, VHS 노이즈)

---

### 🛠️ 전체 프로토타입 흐름도 (The User Journey Flow)

| 단계 | 사용자 카피 (Writer 제공) | 시스템 상태 변화 | 주요 목표 및 UX 목적 |
| :--- | :--- | :--- | :--- |
| **Phase 1: 진단 시작** | "당신의 인지적 예산은 안전한가요?" | [STATUS] Normal $\rightarrow$ [ALERT] Warning (Initialization) | 사용자의 흥미 유발 및 '문제 정의'의 필요성 인식. 시스템에 대한 신뢰도 구축. |
| **Phase 2: 진단 진행** | "현재 인지 자원 고갈 지점을 찾아보세요." | [STATUS] Normal $\rightarrow$ [CRITICAL] Degrading (Data Visualization) | 데이터 기반으로 사용자의 문제(과부하)를 정량화하고 위기감을 조성. 가장 많은 정보를 시각적으로 제시하는 단계. |
| **Phase 3: 진단 완료/결론** | "당신의 시스템은 과부하 상태입니다." | [STATUS] CRITICAL $\rightarrow$ [FAILURE] (The Hook) | 문제의 심각성 극대화 및 '개인 노력'이 아닌 '구조적 결핍'으로 원인 확정. Pro 솔루션 필요성을 감정적으로 자극. |

### 🖼️ Fixed-Grid 스토리보드 상세 설계 (Screen Breakdown)

#### **[SCREEN 1: 시작 화면 - 시스템 점검 모듈]**
*   **레이아웃:** 중앙 집중형, 미니멀리즘 + 경고 메시지 오버레이
*   **핵심 요소:** 타이머/게이지, 로딩 애니메이션, 제목.
*   **애니메이션 및 상호작용:**
    1.  (0.0s) 화면 전체에 VHS 노이즈가 흐르며 진입 (시각적 몰입 유도).
    2.  (0.5s) 중앙에 'SYSTEM DIAGNOSTIC MODULE' 텍스트가 네온 레드 컬러로 깜빡이며 로드됨.
    3.  (1.5s) **[Energy Core Gauge]** 모듈이 화면 하단에서 서서히 채워지며 작동 시작을 알림. (색상: Blue $\rightarrow$ Yellow).
*   **오디오/UX:** 낮은 앰비언트 노이즈와 함께, 기계적인 '삐-' 하는 진동음을 배경에 깔아 긴장감 조성.

#### **[SCREEN 2: 데이터 증명 - 인지 자원 고갈 모듈] (핵심)**
*   **레이아웃:** Fixed-Grid 기반의 대시보드 형태. 좌측(데이터), 우측(상태 메시지).
*   **핵심 요소:** **1) 이탈률/산만함 그래프**, 2) 집중도 게이지, 3) 경고 플래시 UI 오버레이.
*   **애니메이션 및 상호작용:**
    1.  사용자가 데이터를 입력(가상 클릭 또는 스크롤)할 때마다 **[이탈률 그래프]** (예: 'Context Switching Rate' 변화 곡선)가 실시간으로 급격히 상승하는 애니메이션을 보여줌. (데이터 시각화의 위력 극대화).
    2.  그래프가 일정 임계점(Threshold)을 넘으면, 화면 전체에 **빨간색 경고 플래시**가 1초 간격으로 깜빡임.
    3.  **[집중도 게이지]** 색상이 Yellow $\rightarrow$ Orange $\rightarrow$ Red로 변하며 시각적 하강 애니메이션을 구현함.
*   **카피 배치:** 우측 상태 메시지에 "경고: 현재 인지적 예산이 위험 수준에 도달했습니다." 등의 경고 문구를 오버레이 함.

#### **[SCREEN 3: 클라이맥스 - 시스템 오류 및 필요성 인지 (CTA)]**
*   **레이아웃:** 전체 화면 강렬한 메시지 전달 구조. 모든 데이터가 사라지고, 중앙의 핵심 카피만 남음.
*   **핵심 요소:** 'ERROR' 대형 텍스트, Pro 솔루션 로고/이미지, CTA 버튼.
*   **애니메이션 및 상호작용 (가장 중요):**
    1.  (0.0s) 모든 데이터 시각화 요소들이 갑자기 **VHS 노이즈와 함께 블랙 아웃 처리됨.** (시스템 충격).
    2.  (0.5s) 화면 중앙에 대형 빨간색 글자로 `SYSTEM OVERLOAD`가 깜빡이며 팝업됨.
    3.  (1.5s) 시스템 오류의 원인을 지적하는 문구 ("이는 개인의 노력이 아닌 구조적 자원의 문제입니다.")가 천천히 나타나며 사용자에게 통찰력을 제공함.
    4.  (2.5s) **[CTA Transition]** 화면 하단에 'Mini-Module 진단 완료' 버튼이 사라지고, 그 자리에 크고 빛나는 네온 레드 컬러의 **'Pro 솔루션으로 시스템 안정화하기'** CTA 버튼이 등장함.
*   **UX 목표:** 사용자에게 "문제를 아는 것"과 "해결하는 것" 사이의 거대한 간극(Gap)을 느끼게 하여, Pro 상품 구매를 필연적인 다음 단계로 인식하게 만드는 것이 핵심.

### ⚙️ 기술 구현 상세 브리프 (Technical Design Constraint Sheet)

| 모듈/요소 | 디자인 컨셉 | 애니메이션 레퍼런스 | 필수 컬러 코드 | 개발 제약 조건 / 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **경고 플래시** | SYSTEM ALERT, 극도의 위기감 조성. | 1초 간격의 빠른 깜빡임 (Flickering). 단순한 Opacity 변화가 아닌, 채도(Saturation)와 밝기(Luminosity)를 동시에 조절하는 Shimmer 효과 필수. | `#FF3366` (Hot Neon Red) | GPU 부하 주의: 플래시는 CSS/WebGL 기반의 Shader Gradient로 구현하여 리소스 최적화 필요. |
| **에너지 코어 게이지** | 시간 경과 및 자원 고갈 시각화. | 선형적인 하강(Linear Decay). 단순한 바 그래프가 아닌, 액체처럼 '역류'하는 애니메이션을 적용해야 함. | `#00FFCC` (Flow State Blue) $\rightarrow$ `#FF3366` | 상태 변화에 따라 게이지의 질감(Texture)이 점차 거칠어지도록 처리하여 시각적 심리 효과 극대화. |
| **데이터 그래프** | 인지 자원 고갈 증명. | 실시간으로 데이터 포인트가 급증/급락하는 애니메이션 (Spike Graph). 과거 데이터를 추적할수록 노이즈와 함께 왜곡되는 표현 사용. | `#3399FF` (Data Blue) | 데이터 축(Y-axis)의 범위 설정 시, 초기에는 좁게 보이다가 과부하 상태에서 갑자기 넓어져 '문제의 크기'가 커지도록 연출해야 함. |
| **VHS 노이즈** | 아날로그/향수 필터링. | 배경에 지속적으로 흐르는 Grain(입자)과 주기적인 화면 떨림(Jitter). 특정 전환점(Transition Point)에서 강도(Intensity)를 극대화하여 충격 효과 제공. | N/A (필터 적용) | 모든 모듈의 경계면이나 데이터 로딩 시에만 국한적으로 사용하며, 과도하면 전문성이 떨어지므로 절제해야 함. |
