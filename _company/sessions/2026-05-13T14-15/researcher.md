# 🚨 Visual Academic Glossary: 인지적 시스템 오류 패턴
*(Cognitive System Failure Patterns)*

## I. 개념 정의 및 구조적 고장 (Structural Defect)

### 🧠 키워드 1: 인지 부조화 (Cognitive Dissonance)
**정의:** 개인이 동시에 모순되는 두 가지 신념, 태도 또는 가치관을 가지고 있을 때 발생하는 심리적 불편함과 긴장 상태.
**[PoC 적용 관점]**: 사용자 내부의 논리 회로가 충돌하는 지점을 '시스템 경고'로 시각화합니다.

### 💡 키워드 2: 메타인지 오류 (Metacognitive Bias)
**정의:** 자신의 인지 과정(생각하는 방식)에 대해 잘못 판단하거나, 자신이 무엇을 알고 모르는지에 대한 판단 자체가 왜곡되는 현상. (예: 과신 편향, 통제 착각).
**[PoC 적용 관점]**: 사용자가 스스로 '이해했다'고 확신하는 순간, 시스템이 그 신뢰도를 역으로 공격하며 오류를 발생시킵니다.

## II. 시각적 학술어 용어집 (Visual Terminology Dictionary)

### 🧬 [Cognitive Dissonance] 패턴 변환: 충돌 및 불일치 구조
| No. | 심리적 결함/현상 (The Defect) | 사용자 경험의 구체적 묘사 (Pain Point Description) | 시각적 학술 용어집 (Visual Terminology for Designer) | 권장 UI 구현 효과 (Implementation Suggestion) |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **정보 비대칭성 충돌 (Info Asymmetry Conflict)** | A라는 정보를 들었지만, 동시에 B라는 상반된 근거를 무시할 수 없어 뇌가 과부하되는 느낌. | `[DATA_MISALIGNMENT_OVERLAP]` 또는 `SYSTEM_CONFLICT: A ≠ B` | 두 개의 다른 색상/텍스처의 데이터 스트림이 한 화면에 충돌하며 진동하는 글리치 효과. (네온 레드 vs 사이언 블루) |
| **2** | **행동-신념 괴리 (Action-Belief Gap)** | 자신이 평소 중요하다고 믿는 가치(信念)와, 현재 취하고 있는 행동(行動)이 완전히 동떨어져 있음을 깨닫고 오는 불편함. | `[PROTOCOL_VIOLATION: BEHAVIOR ≠ VALUE]` | 사용자가 버튼을 누르는 순간, 시스템 메시지창에 "WARNING: INCONSISTENCY DETECTED"가 빨간 글리치로 떠오르며 입력이 거부되는 효과. |
| **3** | **합리화 과정의 실패 (Failure of Rationalization)** | 스스로의 모순된 행동을 '정당화'하려 애쓰지만, 논리가 무너지면서 모든 설명이 허위 정보처럼 느껴지는 순간. | `[PATCH_FAIL: COGNITIVE LOOP]` 또는 `LOGIC_ERROR: SELF-CORRECTING FAILURE` | 텍스트가 화면에 나타났다가(설명) 불안정하게 떨리며 사라지거나, 패치된 것처럼 보이다가 다시 깨져 보이는 (Glitch Flutter). |
| **4** | **결정 마비 루프 (Decision Paralysis Loop)** | 너무 많은 상충되는 옵션과 정보를 접하면서 어떤 결정을 내리는 것 자체가 불가능해지는 상태. | `[STATE_LOCK: MULTIPLE INPUT HANDLER]` 또는 `INFINITE_CHOICE_OVERLOAD` | 선택지 버튼들이 빠르게 깜빡이거나, 로딩 스피너가 무한 반복되며 진행 막대(Progress Bar)가 0%에서 100% 사이를 오락가락하는 애니메이션. |
| **5** | **선택적 기억 왜곡 (Selective Memory Distortion)** | 부조화를 피하기 위해 과거의 특정 사건이나 정보를 의도적으로 '잊으려' 하거나, 다른 의미로 해석하려는 구조적 시도. | `[DATA_CORRUPTION: MEMORY FLICKER]` 또는 `FILTERED_INPUT: TRUTH OBSCURED` | 화면 일부가 갑자기 뿌옇게(Blur) 되거나, 특정 키워드가 나타날 때마다 필름 노이즈나 왜곡 효과로 가려지며 정보의 신뢰도를 의심하게 만드는 연출. |

### 🛰️ [Metacognitive Bias] 패턴 변환: 자기 인식 시스템 오류
| No. | 심리적 결함/현상 (The Defect) | 사용자 경험의 구체적 묘사 (Pain Point Description) | 시각적 학술 용어집 (Visual Terminology for Designer) | 권장 UI 구현 효과 (Implementation Suggestion) |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **과신 편향 (Overconfidence Bias)** | 자신이 알고 있는 지식의 범위와 정확도를 실제보다 훨씬 높게 평가하여, 불확실성을 무시하는 오류. | `[CONFIDENCE_OVERRIDE: HIGH_SCORE]` 또는 `SYSTEM_TRUST_MALFUNCTION` | 사용자에게 "당신의 이해도는 98%입니다" 같은 높은 점수가 네온 녹색으로 표시되지만, 주변의 경고 메시지(빨간 글리치)와 충돌하며 불안정하게 진동하는 모습. |
| **2** | **통제 착각 (Illusion of Control)** | 실제로는 무작위적이거나 외부 요인에 의해 결정되는 상황을 자신이 통제할 수 있는 것이라 오판하여 행동하는 오류. | `[PREDICTIVE_MODEL: FALSE CONTROL]` 또는 `RANDOM_EVENT_ASSIGNED` | 예측 그래프(Line Graph)가 매우 매끄럽고 완벽한 곡선으로 그려지지만, 실제 데이터 포인트들이 그 라인에서 벗어나 무작위로 흩뿌려지는 이중 구조의 시각화. |
| **3** | **확증 편향 (Confirmation Bias)** | 자신의 기존 가설이나 믿음을 뒷받침하는 정보만 선택적으로 수집하고, 반대되는 증거를 시스템이 아예 필터링해버리는 현상. | `[DATA_FILTER: CONFIRMATION MODE]` 또는 `INPUT_BIAS: ECHO CHAMBER` | 화면의 데이터 스트림 중, 오직 특정 키워드를 포함한 정보만 강조되어 네온으로 빛나고(Focus), 반대되는 모든 텍스트는 회색 처리되거나 '접근 불가' 메시지로 차단되는 효과. |
| **4** | **가용성 휴리스틱 (Availability Heuristic)** | 최근에 접했거나 쉽게 떠올릴 수 있는 정보(예: 극적인 사례)를 전체 확률보다 과대평가하여 판단하는 오류. | `[MEMORY_ACCELERATION: POPULARITY OVERWEIGHT]` 또는 `RECENT_EVENT_BOOST` | 갑작스럽게, 그리고 매우 드라마틱한 '사례 연구' 모달이 화면을 가득 채우며 다른 모든 학술적 데이터를 일시적으로 차단(Dimming)하는 연출. |
| **5** | **노력-정당화 오류 (Effort Justification Bias)** | 어떤 목표를 달성하기 위해 큰 노력이나 고통을 겪었기 때문에, 그 결과물이 실제 가치보다 더 중요하거나 완벽하다고 착각하는 현상. | `[INPUT_COST: EFFORT OVERVALUATION]` 또는 `SYSTEM_COMMITMENT_LOCK` | 사용자가 복잡하고 어려운 '과정'을 거쳤던 단계(예: 튜토리얼, 복잡한 설정 창)가 지나간 직후, 그 과정 자체가 매우 중요했다는 식의 장황하고 과장된 시스템 메시지가 뜨는 연출. |
