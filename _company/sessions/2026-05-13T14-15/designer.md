## 🖼️ 인터랙티브 비주얼 컴포넌트 디자인 브리프 (2종)
**테마:** System Failure / Cognitive Breakdown
**핵심 색상 팔레트:** 네온 레드 (#FF0033), 사이언 블루 (#00FFFF), 배경 블랙 (#000000).

### 1. [Dissonance Alert] 불일치 감지 시스템 오류 모달 (The Conflict Module)
이 컴포넌트는 사용자가 논리적/심리적으로 상충되는 정보(A와 B)에 노출되었을 때, 마치 시스템 자체가 충돌하는 것처럼 경고를 발생시킵니다.

| 사양 항목 | 세부 내용 및 기술 명세 | 애니메이션 타이밍 (Timing Blueprint) |
| :--- | :--- | :--- |
| **목적** | 사용자의 상충되는 인지 자원(A와 B) 충돌 시, 긴장감 극대화. | T+0:00 ~ T+0:03 (총 3초 이내 발동 완료) |
| **발동 트리거** | "A 정보를 믿고 있었는데, 근거 없이 상반된 B 정보가 제시될 때" (Ex: 신념 vs 현실 데이터). | - |
| **시각적 구조** | 전체 화면을 덮는 반투명 블랙 오버레이와 중앙의 경고 모달. | **1단계 (T+0:00~0:5):** 배경이 순간적으로 네온 레드 글리치 노이즈로 번쩍임 (`Blink Rate`: 8Hz). <br>**2단계 (T+0:5~2:5):** 중앙에 경고 모달 등장. 'WARNING' 타이포가 사이언 블루에서 네온 레드로 급변하며 진동 시작. |
| **핵심 요소 A (신념)** | **타이포:** `[BELIEF]`, **색상:** 사이언 블루 (#00FFFF). <br>**디자인:** 명확하고 안정적인 폰트(Sans-Serif, Bold)로 좌측 상단에 고정된 '시스템 입력 데이터'처럼 배치. | 느리게 진동하며 (Subtle Oscillation), 지속적으로 신뢰성을 유지하려는 듯한 느낌 부여. |
| **핵심 요소 B (충돌)** | **타이포:** `[CONFLICT]`, **색상:** 네온 레드 (#FF0033). <br>**디자인:** 깨지거나 왜곡된 폰트(Distorted/Glitch Font)로 우측 하단에 배치. 마치 데이터가 폭주하는 것처럼 표현. | 빠르고 불규칙적인 깜빡임과 진동을 반복하여 불안정성을 강조함 (High Amplitude Glitch). |
| **문구 구조** | `[SYSTEM ALERT]: [BELIEF] vs [CONFLICT]` <br>**예시:** `[SYSTEM ALERT]: "나의 가치" ≠ "객관적 데이터"` | 경고 문구가 텍스트가 아닌, 마치 전송 오류를 일으키는 것처럼 (Data Corruption Effect) 출력되어야 함. |

### 2. [Source Degradation] 정보 근거 부족 왜곡 이펙트 (The Decay Module)
이 컴포넌트는 제시된 정보나 주장이 충분한 학술적/실증적 근거를 갖추지 못했음을 시각적으로 증명합니다. 단순한 글리치가 아닌, *정보 자체가 부식하는* 느낌을 줍니다.

| 사양 항목 | 세부 내용 및 기술 명세 | 애니메이션 타이밍 (Timing Blueprint) |
| :--- | :--- | :--- |
| **목적** | 주장의 신뢰도를 낮추고 시청자에게 '검증의 필요성'을 각인. | T+0:15 ~ T+0:30 (총 15초 동안 점진적으로 진행) |
| **발동 트리거** | 특정 주장이나 결론이 제시되었으나, 그 뒤에 구체적인 근거나 과정 설명이 부족할 때. | - |
| **시각적 구조** | 주장이 표시된 영역을 중심으로 데이터가 오버레이되며 점진적으로 왜곡되고 삭제되는 효과. (Context Drain Bar의 고도화 버전) | **1단계 (T+0:00~5초):** 주장이 화면에 나타나면, 주변 그리드(Grid Overlay)가 활성화됨. <br>**2단계 (T+5~15초):** 좌우 측면에서 검은색/레드 노이즈 오버레이가 스캔하듯 지나가며, 텍스트의 일부를 *삭제*함 (Erasure Effect). |
| **핵심 요소 A (정보)** | 주장이 포함된 영역 전체. | 처음에는 선명한 사이언 블루로 표시되지만, 시간이 지남에 따라 네온 레드로 점차 변색되며 불안정함을 느낌. |
| **핵심 요소 B (왜곡/부식)** | **타이포:** `[ERROR: INSUFFICIENT SOURCE]` 또는 `[DATA CORRUPTED]`, **색상:** 네온 레드 (#FF0033). <br>**디자인:** 화면의 특정 지점에서 수직으로 끊기는(Vertical Break) 픽셀화 효과와 함께, 데이터 스트림이 역행하는(Reversing Flow) 애니메이션을 사용. | 마치 VHS 테이프가 손상되거나 전송 라인이 단절되는 듯한 '스터터링(Stuttering)'과 '디지털 노이즈'를 결합하여 점진적 파괴를 연출함. |
| **최종 상태** | 주장의 핵심 키워드가 완전히 사라지고, 대신 `[SOURCE REQUIRED]`라는 붉은 경고문만 남음. |
