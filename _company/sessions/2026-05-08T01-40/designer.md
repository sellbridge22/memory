## [최종 산출물] System Overload 경고 UI 컴포넌트 라이브러리 (Asset Pack v1.0) 전달서

본 패키지는 Developer가 MVP 개발을 위한 프론트엔드 코드를 구현하고, Editor가 실제 유튜브 영상에 적용할 수 있는 *영상 편집용 에셋* 및 *기술 사양서*를 통합한 것입니다. 모든 요소는 'Critical Failure' 서사를 극대화하도록 설계되었습니다.

### 📁 Part 1. 핵심 시스템 가이드라인 (Core System Specs)

#### 1. 컬러 팔레트 (Color Palette - Hex Code 기준 고정)
| 용도 | 명칭 | HEX 코드 | CMYK/RGB 값 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **🚨 경고 메인** | Neon Red (CRITICAL) | `#FF3B30` | C0 M95 Y10 K0 / R255 G59 B48 | 가장 긴급한 상태, 플래시 효과 주 색상. |
| **🟢 데이터 액티브** | Data Cyan (CORE) | `#00FFFF` | C10 M0 Y100 K0 / R0 G255 B255 | 정보 제공, 활성화/성공 지표. |
| **⚫ 배경 시스템** | Deep Black (MATRIX) | `#0A0A1E` | - | UI의 깊이와 위기감을 주는 기본 배경색. |
| **⚪ 텍스트/보조** | System White | `#F0F0FF` | - | 경고가 아닐 때의 가독성 확보용 텍스트 색상. |

#### 2. 타이포그래피 및 계층 구조 (Typography & Hierarchy)
*   **메인 폰트:** Space Mono (또는 유사한 모노스페이스 계열): 모든 데이터, 코드 블록, 시스템 메시지에 적용하여 기술적/전문적인 느낌 극대화.
*   **서브 폰트:** Inter 또는 Pretendard: 일반 설명 문구 및 제목에 사용하며, 가독성을 높임.
*   **글리치 효과:** 모든 핵심 텍스트 요소(헤딩, 지표)는 글리치 필터가 적용될 때 **좌우로 무작위 1-3픽셀 오프셋**을 가지도록 설계합니다.

### ⚙️ Part 2. 컴포넌트 라이브러리 상세 사양 (Asset Pack Detail)

#### A. 데이터 시각화 모듈
| 컴포넌트 | 기능/표현 | 애니메이션/인터랙션 스펙 | 에디팅 가이드 (Editor용) |
| :--- | :--- | :--- | :--- |
| **1. Energy Core Gauge** | 현재 집중력 레벨 시각화 (0%~100%). | **[트리거]**: 페이지 로딩 시작 (0s). **[애니메이션]**: 0.5초 동안 선형 상승 애니메이션. **[상태 변화]**: 70% 이상: Data Cyan (활성) 유지. 30% 이하: Neon Red로 변색 및 진동(0.1초 간격, 크기 2px 깜빡임). | After Effects의 *Stroke* 속성을 활용하여 게이지 선을 그립니다. 레벨 변화 시 **Scale/Opacity Keyframe**을 사용하고, 붉은 구간에서는 네온 레드 색상으로 오버레이 플래시를 추가해야 합니다. |
| **2. Context Drain Bar** | 주의 분산 비용(Context Switching Cost) 추적. | **[트리거]**: 데이터 수집 시작 (0s). **[애니메이션]**: 1초 간격으로 좌측에서 우측으로 점진적 누적 애니메이션. **[특징]**: 바가 가득 찰수록 배경의 노이즈(VHS/Glitch)가 증가하는 연동 효과 필수. | 레이어 트랙을 활용하여 Gradient Mask를 사용합니다. 데이터 누적에 맞춰 마스크 위치와 크기를 Keyframe으로 제어하며, 마지막 구간에서는 **Chromatic Aberration (색수차)** 필터를 추가합니다. |
| **3. PFC Index Meter** | 인지 자원 고갈 지표(PFC Overload). | **[트리거]**: 데이터 수집 시작 (0s). **[애니메이션]**: 파동 그래프 형태(Sine Wave)로 진동하며 데이터를 시뮬레이션. **[위기 상황]**: 임계치 도달 시, 그래프 전체가 Neon Red으로 변색되며 주파수가 높아지며 격렬하게 떨림(Jitter effect). | 복잡한 그래프는 *Shape Layer*를 이용해 파동 함수를 구현하고, 위기 상태에서는 Amplitude와 Frequency 값을 Keyframe로 급격히 변화시키십시오. |

#### B. 시스템 경고 및 UI 모듈
| 컴포넌트 | 기능/표현 | 애니메이션/인터랙션 스펙 | 에디팅 가이드 (Editor용) |
| :--- | :--- | :--- | :--- |
| **4. System Overload Banner** | 최상단 고정 경고 메시지. | **[트리거]**: 시스템 오류 발생 시. **[애니메이션]**: 0.2초 간격의 빠른 깜빡임(Blink) 효과와 함께, 좌우로 무작위한 글리치 프레임 오프셋 (3~5프레임). | 영상 편집 툴에서 *Opacity*를 100% $\rightarrow$ 0% $\rightarrow$ 100%의 주기로 매우 빠르게 반복하는 키프레임을 만듭니다. 여기에 **Wave Warp** 또는 **Data Corruption Filter**를 오버레이로 적용합니다. |
| **5. Data Alert Card (경고 카드)** | 핵심 문제 정의 제시. | **[트리거]**: 진단 완료 시. **[애니메이션]**: 화면 중앙에서 0.4초 동안 확대(Scale up)되며 등장. 경계선은 네온 레드 색상으로 깜빡이는 박스 형태가 필수. | 단순한 사각형이 아닌, 테두리에 전기가 흐르는 듯한 **Electric Arc** 효과를 추가합니다. (After Effects의 *Glow*와 *Repeater* 속성 활용 권장). |

#### 2. 에디터 활용 원칙 (The Rule of Drama)
1.  **절대 정지된 화면 금지:** 모든 장면은 최소한의 데이터 흐름(Context Drain Bar의 누적 등)이나 미세한 노이즈/글리치 효과를 통해 **움직이는 것**처럼 느껴져야 합니다.
2.  **사운드와 시각의 연동:** Neon Red 경고가 발생할 때, 배경 사운드의 저주파수(Low Frequency Hum) 진폭을 급격히 증폭시키고, 영상에 강한 스윕 노이즈를 추가하여 **공간적인 긴장감**을 극대화해야 합니다.
3.  **시간 간격의 통일:** 시스템 경고 플래시 주기는 0.1초 단위로 매우 빠르고 불규칙하게 유지합니다.
