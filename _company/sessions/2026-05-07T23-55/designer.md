# 💾 Selbridge UI/UX Asset Pack v1.0: 시스템 과부하 경고 모듈

## I. 핵심 디자인 토큰 (Core Design Tokens)
모든 컴포넌트의 기초가 되는 색상 및 타이포그래피 가이드입니다.

### A. 컬러 팔레트 (Color Palette - Hex Codes 필수)
| 역할 | 이름 | HEX Code | 사용 규칙 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Alert** | 네온 레드 (Warning Red) | `#FF3B30` | 위험, 과부하 임계점 초과. 경고 메시지 배경/하이라이트. | 🔴 긴급성 강조 |
| **Secondary Accent** | 데이터 청록 (Data Cyan) | `#00FFFF` | 정상 작동 영역, 과학적 데이터 라인, 포커스 영역. | 🔵 기술 및 분석 강조 |
| **Background Base** | 다크 네이비/블랙 | `#0A192F` | 기본 배경색. 정보의 깊이와 무게감을 부여함. | ⚫ 높은 대비율 확보 (Accessibility) |
| **Text Primary** | 시스템 화이트 | `#E6FFFA` | 주 텍스트 및 라벨. | - |

### B. 타이포그래피 가이드 (Typography Guide)
*   **폰트명:** `Electrolize`, `Orbitron`, 또는 유사한 모노스페이스/기술적 느낌의 폰트를 사용합니다. (실제 제작 시 웹 안전성 고려 필요)
*   **활용 원칙:** 모든 숫자는 모노스페이스(Monospace) 형태로 처리하여 계측기 같은 느낌을 극대화합니다.
*   **강조 방식:** 핵심 데이터 수치와 경고 문구는 네온 레드(`FF3B30`)로, 일반 정보는 데이터 청록(`00FFFF`)으로 처리하여 시각적 위계를 만듭니다.

## II. 모듈형 컴포넌트 상세 사양 (Component Specifications)

### 1. [Gauge/Graph] 데이터 시각화 게이지 및 그래프
**[목표]:** 인지 부하, 집중도 등 추상적인 데이터를 수치로 증명하는 '측정 기기'의 느낌 구현.

*   **A. 핵심 지표 게이지 (Cognitive Load Gauge):**
    *   **형태:** 원형(Radial) 또는 아날로그 계기판 형태.
    *   **작동 방식:** 0%에서 시작하여 최대 임계치(100%)까지 바늘이 움직입니다.
    *   **색상 변화 규칙:**
        *   0-40%: 데이터 청록 (안정) $\rightarrow$ 선형 증가
        *   41-85%: 노란 계열 경고색 (주의) $\rightarrow$ 톤 다운된 사이언 활용 가능
        *   86-100%: 네온 레드 (위험/과부하 임계점) $\rightarrow$ 진동 애니메이션 필수 적용.
    *   **UI 요소:** 게이지 주변에 미세한 `scanline` (스캔 라인) 패턴을 오버레이하여 '실시간 측정 중' 느낌 부여.

*   **B. 추이 그래프 (Trend Graph):**
    *   **형태:** X축(Time)과 Y축(Value)의 선형 차트.
    *   **라인 스타일:** 끊어진 점선(`dashed line`)을 기본으로 사용하며, 데이터 포인트마다 작은 사각형/원 형태의 `Metric Pin`이 표시되어야 함.
    *   **데이터 흐름 표현:** 그래프 라인 자체가 네온 청록색 데이터를 따라 움직이며(Trail Effect), 특정 임계점을 넘어서면 순간적으로 붉은 빛을 내며 끊기는 효과를 연출합니다.

### 2. [Effect] 시스템 경고 '글리치 프레임' 애니메이션 브러시
**[목표]:** 모든 정보의 전달 지점마다 콘텐츠에 구조적 오류가 발생했다는 서사를 부여하는 핵심 시각 효과.

*   **활용 범위:** 영상/이미지의 컷 전환(Cut Transition), 중요 정보 등장 직전, 경고 메시지 노출 순간 등.
*   **기술 사양 (Animation Spec):**
    1.  **Duration:** 매우 짧게 (5~10 프레임).
    2.  **Movement:** 수평 방향으로 화면을 찢는 듯한(Horizontal Tear) 왜곡 효과를 사용합니다.
    3.  **Color Shift:** 기본 이미지의 색상 채널(RGB)이 순간적으로 분리되어 나타나며, 청록색과 빨간색 노이즈가 번개처럼 교차하는 것이 핵심입니다.
    4.  **Texture:** 디지털 '데이터 깨짐'을 표현하기 위해 미세한 사각 픽셀화(Pixelation) 효과를 동반합니다.

### 3. [Card] 진단 결과 데이터 카드 UI (Diagnosis Data Card)
**[목표]:** Mini-Module에서 얻은 결과를 전문적이고 권위 있는 '진단서' 형태로 제시.

*   **레이아웃 구조:** 3단 또는 4단 그리드 레이아웃을 기본으로 합니다. 각 카드는 하나의 측정 항목을 담습니다.
*   **핵심 컴포넌트:** `[Metric Name]` - [Value] / (기준치 대비)
    *   **예시:** **Context Switching Cost**: $23 \text{ mins} / (>10 \text{ mins})$
*   **상태 표시기:** 각 카드 하단에는 작은 원형 인디케이터를 배치합니다.
    *   🟢 (청록): 정상 범위 (Optimal)
    *   🟡 (노랑/주황): 주의 필요 (Caution)
    *   🔴 (네온 레드): 심각 과부하/위험 (Critical Failure)
*   **애니메이션:** 카드 데이터가 로딩될 때, 마치 터미널에서 텍스트가 타이핑되듯이(`Typewriter Effect`) 점진적으로 나타나게 합니다.
