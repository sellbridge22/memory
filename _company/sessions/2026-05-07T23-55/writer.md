# 📽️ [A] 숏폼 콘텐츠 스크립트 (Reels/Shorts) - 즉각적 불안 유발
*길이: 15~40초 / 톤: 긴급 경고, 질문형 의혹 제기*

## 💡 Set 1: Context Switching 비용 과부하 (인지 부하 Pain Point)
**[핵심 주제]:** 왔다 갔다 하는 것 자체가 에너지를 소진시킨다. (시간 낭비에 대한 자책 유도)

| 요소 | 스크립트 내용 (구어체/빠른 속도감) | 비주얼 지시 / 효과 | CTA 포인트 |
| :--- | :--- | :--- | :--- |
| **후크 1안** | "혹시… 지금 하는 일, 제대로 하고 있다고 착각하고 있진 않나요?" (정지 화면 + 빨간색 경고음) | [Glitch/Hacking UI] - 'Error: Focus Lost' 오버레이. 시계 초침이 빠르게 돌아가는 애니메이션. | **(최종)** 당신의 실제 인지 자원 소모량을 진단하세요. (프로필 링크 유도) |
| **본문 전개** | "여러 프로젝트를 동시에 맡았다고 생각하시죠? 아닙니다. 매번 컨텍스트를 전환할 때마다, 뇌는 '재부팅 비용'을 지불합니다. 이걸 과학적으로 '맥락 전환 비용(Context Switching Cost)'이라고 해요." | 그래프가 나타나며 (작업 전환 횟수) → (집중력 하락 곡선)으로 이어지는 시각화. 복잡한 업무 화면이 빠르게 오버레이되고 튕겨져 나가는 효과. | "그 재부팅 비용, 몇 분이나 쓰고 계신가요?" |
| **본문 전개** | "여러 개의 알림과 태스크 목록 사이를 헤매는 것 자체가 당신의 에너지를 고갈시키고, 결과적으로 생산성을 갉아먹습니다. 이건 의지의 문제가 아니에요." | 'Attention Residue' 같은 전문 용어를 네온 청록색으로 강조하며 자막 처리. | Mini-Module 진단 페이지로 이동하여 정확한 소모량을 측정하세요. |

## 💡 Set 2: 주의력 분산 및 디지털 피로 (집중력 저하 Pain Point)
**[핵심 주제]:** 무의식적으로 외부 자극에 중독되어 있다. (자기 통제력 상실 경고)

| 요소 | 스크립트 내용 (구어체/빠른 속도감) | 비주얼 지시 / 효과 | CTA 포인트 |
| :--- | :--- | :--- | :--- |
| **후크 1안** | "분명 집중했는데, 왜 이렇게 시간이 빠졌죠? 당신의 주의력은 이미 '시스템 과부하' 상태입니다." (사용자에게 직접 질문하는 듯한 카메라 워크) | [Glitch/Hacking UI] - 화면 전체에 노이즈가 끼는 효과. 경고 메시지: "WARNING: Cognitive Drift Detected". | **(최종)** 당신의 집중력 시스템 오류, 지금 바로 진단해야 합니다. (프로필 링크 유도) |
| **본문 전개** | "알림음 하나에 반응하고, 틱톡을 잠깐 보고… 이 작은 행동들이 우리의 주의력을 무의식적으로 분산시키고 있습니다. 이게 '간헐적 주의력 저하'입니다." | 스마트폰 화면이 빠르게 전환되는 모션 그래픽. 각 알림마다 빨간색 경고 문구가 번쩍임. | "단순히 산만해서가 아닙니다. 시스템 자체가 고장 났을 가능성." |
| **본문 전개** | "뇌는 지금 지속적인 '보상 루프'에 빠져 있습니다. 잠깐의 자극이 주는 도파민에 중독된 거죠. 이걸 해결하려면, 당신의 기준점을 재설정해야 합니다." | 'Dopamine Reward Loop' 같은 전문 용어를 마치 해킹된 데이터처럼 띄우기. (위험성 강조) | Mini-Module 진단 페이지에서 본인의 실제 분산 지표를 확인해 보세요. |

# 🎬 [B] 유튜브 긴 호흡 도입부 스크립트 (Long-form Intro Hook)
*길이: 1분 30초~2분 / 톤: 시네마틱 드라마, 전문적 경고, 위기감 고조*

## 💡 Set 1: '만성적인 비효율' 진단 - 작업 기억 과부하 (Professional Angle)
**[핵심 주제]:** 당신은 단순히 피곤한 것이 아니라, 시스템적으로 무너지고 있다. (의학적/과학적 근거 제시)

| 시간대 | 스크립트 내용 (전문적이면서도 공포감을 유발하는 구어체) | 비주얼 지시 / 효과 | CTA 포인트 |
| :--- | :--- | :--- | :--- |
| **0:00 - 0:15 (Hook)** | "혹시 매일 아침, 마치 배터리가 20%만 충전된 것처럼 시작하시나요? 그건 단순히 잠을 못 자서가 아닙니다. 당신의 '작업 기억(Working Memory)' 자체가 과부하 상태에 돌입했기 때문입니다." | [Cinematic Industrial Drama] - 어둡고 차가운 톤. 복잡하게 돌아가는 기계 장치나 회로도를 보여주며, 핵심 키워드만 네온 레드/청록색으로 강조. | (전환점) 자막: "당신의 시스템에 오류가 발생했습니다." |
| **0:15 - 0:45 (문제 정의)** | "우리는 스스로를 '멀티태스킹 전문가'라고 생각합니다. 하지만 과학은 말합니다. 여러 가지 작업을 왔다 갔다 하는 과정 자체가, 엄청난 에너지 소모를 일으킨다는 것을요. 이걸 우리는 '맥락 전환 비용(Context Switching Cost)'이라고 부릅니다." | 복잡한 업무 현장을 빠르게 교차 편집하며 (화면 속 인물의 혼란스러움 강조). 데이터 그래프가 붉은색으로 치솟는 애니메이션 삽입. | "이 지점에서 당신의 에너지는 이미 한계에 도달했습니다." |
| **0:45 - 1:30 (진단 및 솔루션 예고)** | "지금부터 저희가 보여드릴 건, 일반적인 '자기 관리법'이 아닙니다. 이건 시스템 레벨에서 발생하는 구조적 오류를 찾아내는 진단 과정입니다. 당신의 인지 자원이 어디서 새고 있는지, 그 누출 지점을 정확하게 알아내야 합니다." | 화면 전체에 데이터 분석 UI(HUD)가 겹쳐지는 느낌. 신뢰성 있는 전문성을 강조하는 배경음악으로 전환. | **[핵심 CTA]** (Mini-Module 진단 페이지로의 명확한 안내) "지금, 당신의 시스템 과부하 상태를 정확하게 측정해보세요." |

## 💡 Set 2: '주의력 경제'에 의한 착취 (사회적/경제적 불안 Pain Point)
**[핵심 주제]:** 문제는 내가 아니라, 정보 홍수라는 외부 환경 때문이다. (분노와 공감을 유도하며 해결책 제공)

| 시간대 | 스크립트 내용 (공감 유발 + 거대한 음모론 느낌의 경고) | 비주얼 지시 / 효과 | CTA 포인트 |
| :--- | :--- | :--- | :--- |
| **0:00 - 0:20 (Hook)** | "우리는 지금 '주의력'이라는 가장 귀한 자원을 끊임없이 빼앗기고 있습니다. 여러분이 느끼는 만성적인 피로감, 그것은 단지 야근 때문이 아닙니다." | [Glitch/Hacking UI] - 배경에 수많은 알림창과 정보가 폭포처럼 쏟아지는 시각 효과. 청록색의 위험 경고 메시지 강조. | (최종) 당신의 주의력 시스템을 보호할 방화벽이 필요합니다. |
| **0:20 - 1:00 (문제 정의)** | "현대 사회는 우리의 '주의'를 상품화하고 있습니다. 잠깐의 자극, 짧은 재미가 주는 도파민 보상 루프에 우리는 중독되고요. 이건 개인의 의지 문제가 아니라, 구조적인 문제입니다." | 소셜 미디어 피드를 배경으로 보여주며, 사람들이 화면에 빠져들어 가는 듯한 연출. '도파민'이라는 단어를 붉은색 경고 문구로 처리. | "스스로를 통제할 수 없다는 무력감에 공감하셨다면." |
| **1:00 - 1:45 (진단 및 솔루션 예고)** | "이 거대한 정보의 흐름 속에서, 당신만의 '핵심 자원'을 보호하는 방법이 필요합니다. 단순한 휴식이 아닌, 시스템 자체를 점검해야 합니다. 어디서 주의력이 누출되고 있는지 정확하게 진단할 수 있는 도구가 필수입니다." | 전문적인 느낌의 미니멀한 디자인으로 전환. Mini-Module 인터페이스가 마치 '시스템 패치'처럼 화면에 떠오르는 연출. | **[핵심 CTA]** (Mini-Module 페이지로의 안내) "외부 자극으로부터 당신을 지킬 방화벽, 지금 바로 진단하여 확인하세요." |
