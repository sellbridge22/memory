## ⚙️ PoC 필수 비주얼 컴포넌트 디자인 브리프 (3종 세트)

### 1. 시스템 경고 타이틀 카드: [SYSTEM ALERT]
**목적:** 영상의 도입부 또는 주제 전환 시, 학술적 긴장감을 조성하고 '구조적 결함'이라는 분위기를 즉각적으로 주입하는 역할.
**재사용성:** `[SYSTEM OVERLOAD]` 상황이 발생하는 모든 장면에 사용 가능하며, 텍스트만 변경하여 활용.

| 항목 | 세부 사양 | 개발자 지침 |
| :--- | :--- | :--- |
| **활성화 시점 (Timecode)** | T=0s 또는 주요 개념 전환 직전. | 최소 3초간 화면을 장악해야 함. |
| **주요 색상 팔레트** | 배경: `#060612` (딥 네이비/블랙). 경고색(A): `#FF004D` (네온 레드). 보조색(B): `#00FFFF` (사이언 블루). | 글리치 효과는 주 색상 A와 B의 교차로 구현. |
| **타이포그래피** | **폰트:** `Orbitron` 또는 산업용 산세리프 폰트 계열. <br>**스타일:** 대문자 전용, 트래킹(Tracking) 극대화 (글자 간격 넓게). | 핵심 메시지는 네온 레드(`A`)로 처리하고, 보조 정보는 사이언 블루(`B`)를 사용해 기술적 느낌 강조. |
| **애니메이션 로직** | 1. **진입:** 배경 그리드 패턴이 미세하게 깜빡이며(Flicker) 화면 전체에 네온 레드 노이즈가 퍼지며 등장. <br>2. **효과 (Glitch):** 타이틀 텍스트가 무작위로 수평/수직으로 몇 프레임씩 순간적으로 이탈했다 재조립되는 '데이터 글리치(Data Glitch)' 효과를 적용. <br>3. **사운드:** 저주파의 웅장한 드론 사운드와 함께, 고주파의 *삐-익* 하는 전력 불안정 경고음 삽입. |
| **예시 문구** | `[SYSTEM ALERT]: Structural Defect Detected` / `WARNING: Cognitive Bias Identified` |

### 2. 데이터 흐름 차단/오버레이 효과: [BIAS FILTER] (Context Drain Bar 변형)
**목적:** 인지 자원의 고갈(Context Drain)을 시각화하는 기존 방식을 확장하여, **'편향성 필터링'**이라는 개념 자체를 인터랙티브하게 보여주는 오버레이.
**재사용성:** '정보의 왜곡', '선입견' 등 사고방식적 오류가 논의될 때마다 적용 가능.

| 항목 | 세부 사양 | 개발자 지침 |
| :--- | :--- | :--- |
| **활성화 시점 (Timecode)** | 정보 제시 구간 중, 관찰자가 '편향된 결론'을 내릴 것 같은 순간. | 15초~20초간 지속적으로 화면 하단을 가로지르거나 오버레이 형태로 존재해야 함. |
| **주요 색상 팔레트** | 기본 배경: 투명도 60%의 어두운 회색 그리드 오버레이. <br>차단 효과: 네온 레드(`A`)와 사이언 블루(`B`)가 혼합된 그라디언트 패턴 사용. |
| **애니메이션 로직** | 1. **진입:** 화면에 'BIAS FILTER ACTIVE' 문구와 함께 오버레이가 나타남. <br>2. **효과 (Leak):** 마치 미세한 균열이 생기듯, 사각형의 그리드 패턴을 따라 네온 레드색의 데이터가 끊임없이 새어 나오는(Leak) 애니메이션 구현. 이 누출 속도가 '편향성 강도'에 비례함. <br>3. **인터랙션:** 영상에서 반대 증거를 제시할 때마다, 필터 오버레이가 순간적으로 떨림 효과(Jitter Effect)와 함께 깨지는 듯한 시각적 충격을 주어야 함. |
| **예시 텍스트** | `[BIAS FILTER ACTIVE]: Confirmation Bias Level: HIGH` / `WARNING: Filtering Out Contradictory Data` |

### 3. 최종 CTA 모달 템플릿: [SERVICE REQUIRED] - 구조적 결함 진단 완료
**목적:** PoC 스크립트의 클라이맥스(결론)에서, 시청자가 스스로가 해결할 수 없는 '시스템적인 문제'를 인식하게 하고 유료 솔루션 접근을 유도.
**재사용성:** 모든 PoC 영상의 마지막 10초에 배치되는 표준화된 수익 창출 장치.

| 항목 | 세부 사양 | 개발자 지침 |
| :--- | :--- | :--- |
| **활성화 시점 (Timecode)** | T+0:45 (스크립트의 클라이맥스 직후). | 화면 전체를 덮는(Full Screen) 모달 형태로 강제 호출되어야 함. |
| **주요 색상 팔레트** | 배경: `#1A0812` (매우 어둡고 깊은 와인 레드/블랙). 강조색: 네온 레드(`A`)와 황금빛 노랑(`Gold`: `#FFCC00`). | 글리치 효과의 중심 색상은 네온 레드 유지. |
| **타이포그래피** | 메인 메시지: `SYSTEM FAILURE` (가장 크게, 굵게). <br>보조 설명: 'Utility Tool API Module'을 강조하며 전문적이고 학술적인 느낌 부여. |
| **애니메이션 로직** | 1. **진입:** 화면 전체에 강렬한 네온 레드 플래시(Blink Rate 8Hz)와 함께 모달이 등장하며, 마치 시스템이 다운되는 듯한 효과를 연출해야 함. <br>2. **메인 메시지 출력:** `SYSTEM FAILURE` 타이포그래피가 글리치 노이즈와 함께 *점진적으로* 나타나야 하며, 이 과정에서 고주파의 경고음이 최고조에 달함. <br>3. **CTA 버튼:** 하단의 'Utility Tool API Module 접근' 버튼은 은은한 황금빛으로 빛나며, 클릭 시 다음 단계(결제/가입)로 매끄럽게 전환되는 느낌을 주어야 함. |
| **핵심 문구** | `SYSTEM FAILURE: Self-Correction is Impossible.` <br>하단: `[SOLUTION REQUIRED]: Access Utility Tool API Module` |
