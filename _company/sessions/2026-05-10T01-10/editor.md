# 🎥 Mini-Module 진단 과정: 영상 스토리보드 & 컷 구성 디렉션 (V1.0)

**💡 핵심 원칙:** **권위성 확보 $\rightarrow$ 위기감 고조 $\rightarrow$ 해결책 제시**의 감정 아크를 시각적 속도(Pacing), 색상 변화, 자막 스타일로 극대화합니다. 모든 컷은 하드한 전환(Hard Cut)을 기본으로 합니다.

| 시간대 (Timecode Range) | 스토리/내용 목표 | 비주얼 액션 및 편집 디렉션 | B-roll / 그래픽 배치 지침 |
| :--- | :--- | :--- | :--- |
| **[T+0:00 ~ T+0:25]** (도입부) | **정상 상태/문제 제기:** 우리의 인지 자원은 끊임없이 소모되고 있다. | **Pacing:** 느리고 안정적. 컷 전환은 부드럽게(Soft Dissolve) 시작하여 학술적인 분위기를 조성. <br>**톤앤매너:** Deep Blue (`#3498DB`). 고해상도 데이터 시각화 위주로 구성. | **B-roll:** 추상적인 신경망 이미지, 복잡한 코드 흐름(실제 코드는 불필요), 학술 서적의 페이지 넘김 등 '지식'과 관련된 권위 있는 자료. <br>**자막/타이틀:** 깔끔하고 정돈된 산세리프 계열 (예: Roboto Mono). 핵심 키워드에만 얇은 브론즈 색상 하이라이트 처리. |
| **[T+0:25 ~ T+1:10]** (경고 시작) | **위기 인식:** 단순한 피로가 아닌, 시스템적 결함이다. 자원이 가속적으로 고갈되고 있다. | **Pacing:** 중간 속도. 컷 전환 빈도 증가. 시각적 불안정성 도입 (미세한 노이즈, 떨림). <br>**톤앤매너:** Blue $\rightarrow$ Yellow 변화 시작. CD Bar의 감소를 중심으로 화면 구도를 잡고, 마치 그래픽에 의해 끌어당겨지는 듯한 역동적인 느낌을 부여해야 함. | **B-roll:** 여러 개의 창이 동시에 열리고 닫히는 장면(Context Switching), 너무 많은 정보가 한 번에 스쳐 지나가는 플래시 이미지들. <br>**그래픽 강조:** CD Bar의 Yellow Zone 진입 시, 화면 좌우에 사운드 이펙트와 동기화된 **글리치 오버레이**를 필수적으로 삽입하여 긴장감 증폭. |
| **[T+1:10 ~ T+2:00]** (최대 위기) | **임계점 도달:** 지금 당장 시스템의 개입이 필요하다! 이것은 개인의 문제가 아니다. | **Pacing:** 매우 빠름(Rapid Cuts). 컷당 지속 시간 극단적으로 짧게 설정. <br>**톤앤매너:** Yellow $\rightarrow$ Red (`#E74C3C`) 급변. 화면 전체가 경고 메시지와 빨간색 필터에 잠식되는 느낌을 연출해야 함. | **B-roll:** 멈추거나 오작동하는 기계 장치, 'ERROR' 또는 'SYSTEM OVERLOAD'와 같은 고전적인 기술적 오류 메시지가 깜빡이는 영상 클립들. <br>**그래픽 필수:** CD Bar의 Red Zone 진입과 동시에, Designer가 제시한 **Strobe Effect (빠른 깜빡임)** 및 강렬한 **글리치 노이즈**를 화면 전반에 걸쳐 최대 강도로 적용. |
| **[T+2:00 ~ T+2:45]** (해결책 제시) | **Mini-Module의 등장:** 유일하고 과학적인 해결책을 제시한다. | **Pacing:** 급격히 느려지고 안정화(Deceleration). 컷 전환이 다시 의도적으로 여유로워짐. <br>**톤앤매너:** Red $\rightarrow$ Deep Blue/Clean White (해결의 색상). 모든 혼란스러운 시각 요소가 정리되고, 명확한 UI와 데이터 구조만이 화면을 지배해야 함. | **B-roll:** 깨끗하고 미니멀한 인터페이스 디자인 예시(Mini-Module 자체 UI Mockup 반복 노출), 학습 과정을 상징하는 깔끔한 인포그래픽. <br>**CTA/자막:** 가장 크고, 가장 명확하며, 브론즈와 화이트를 조합하여 신뢰성을 강조. "진단이 필요합니다"라는 문구가 마지막까지 시선에서 떠나지 않도록 디자인. |
