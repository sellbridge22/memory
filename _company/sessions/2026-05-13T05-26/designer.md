## ⚙️ 애니메이션 에셋 마스터 스펙 시트 (Master Animated Asset Specification Sheet)
**프로젝트:** PoC 영상 및 Mini-Module 전용 인터랙티브 UI/UX 자산
**목표:** 개발자가 바로 컴포넌트를 구현할 수 있도록 기술적 사양(Technical Specs)과 모션 가이드라인을 정의한다.

### 1. 핵심 효과: 글리치 & 시스템 노이즈 (The Glitch Module)

글리치는 단순한 시각적 방해가 아닌, '데이터 손실'이라는 학술적 개념으로 기능해야 한다. 모든 글리치 발생 지점에는 타이밍과 강도(Intensity)가 부여되어야 함.

| 파라미터 | 사양 및 가이드라인 | 비고 (기술 구현 참고) |
| :--- | :--- | :--- |
| **주파수 (Frequency)** | 최소 30Hz $\sim$ 최대 60Hz 사이의 불규칙적 깜빡임 (Stutter Rate). | 화면 전체에 적용 시 GPU 부하 체크 필수. |
| **색상 변화** | 크로마틱 에버레이션(Chromatic Aberration): R, G, B 채널이 X축/Y축으로 각각 $\pm 4$ ~ $\pm 6$ pixels만큼 분리되어 번져나감. | 색상 왜곡의 원인임을 시각적으로 명확히 해야 함. |
| **데이터 손실** | 화면의 일정 비율(10% $\sim$ 25%)을 임시로 '픽셀화'하거나, 녹색/파란색의 디지털 노이즈 블록으로 대체하는 효과를 주기적으로 삽입. | 데이터 스트림이 끊기는 듯한 느낌 연출에 활용. |
| **적용 타이밍** | 정보가 압도되거나(Overload) 결함 진단 메시지 직후 (예: 0:02-0:03 구간). | 과하게 사용하면 효과가 없어지므로, '강조점'에만 제한적으로 사용. |

### 2. 핵심 인터랙션: [SERVICE REQUIRED] 모달 창 (The Callout Module)

이 모듈은 영상 클라이맥스(Utility Tool API 언급 직후)에 배치되어 구매 전환을 유도하는 최우선 자산이다. 애니메이션 흐름(Flow)이 가장 중요하다.

| 단계 | 애니메이션 사양 및 시간 코드 (T+) | 비주얼/사운드 디렉션 |
| :--- | :--- | :--- |
| **A. 진입 (Entry)** | T+0:00 $\to$ T+1:00 (총 1초) / Ease-out Curve 적용. | 배경에 네온 레드 경고선이 깜빡이며 화면을 덮음. 마치 시스템이 '강제로 개입'하는 느낌. 사운드는 날카로운 피치 상승음을 동반해야 함. |
| **B. 노출 (Display)** | T+1:00 $\to$ T+2:00 (총 1초) / Slow Fade-in, 그리드 오버레이가 점진적으로 나타남. | 모달 중앙에 'SERVICE REQUIRED' 문구가 가장 큰 글자로 표시되고, 아래에 결함 진단 내용을 학술 용어로 배치한다. |
| **C. CTA 강조** | T+2:00 $\to$ T+3:00 (총 1초) / Subtle Pulse Animation 및 시각적 떨림(Jitter). | '[패치 실행]' 버튼은 단순히 클릭 가능한 버튼이 아닌, '시스템 명령'처럼 네온 레드 색상으로 주기적인 맥동 애니메이션을 주어 긴급성을 극대화한다. |

### 3. UI/UX 자산: Utility Tool API Module 오버레이 (The Overlay Module)

모듈의 사용법과 기능을 시각적으로 보여주는 인터랙티브 요소이다. 학습 과정을 '시스템 패치' 과정으로 치환해야 한다.

| 기능 컴포넌트 | 디자인 사양 및 동작 원리 | 애니메이션 가이드라인 |
| :--- | :--- | :--- |
| **모듈 설명창** | 마치 터미널 창이 뜨는 것처럼, 하단에서 위로 데이터 라인이 흘러 올라오며 텍스트가 타이핑되는 효과(Typewriter Effect). | 글자가 나타날 때마다 미세한 '지직거림' (Glitch)을 적용하여 디지털적 느낌 부여. |
| **활성화 게이지** | 현재 모듈의 '패치 진행률'을 표시하는 게이지 바 형태. 0% $\to$ 100%. | 진행도가 빨라질수록 네온 레드 색상의 점멸 주기가 짧아지고, 배경으로 데이터 흐름이 폭발하듯이 시각화되어야 함. (속도감 강조). |
| **핵심 기능 버튼** | 단순한 사각형 버튼 대신, 주변에 전선/데이터 연결선(Data Flow Line)이 마치 이 버튼을 '활성화'시키는 것처럼 모이는 애니메이션 필수. | 클릭(Tap) 시에는 짧은 '전류가 흐르는 듯한' 번개 효과와 함께 팝업되며, 다음 단계로의 이동을 유도하는 직관적인 피드백 제공. |
