## ⚙️ [셀브릿지] 핵심 UI/HUD 디자인 브리프 (V1.0)
**목표:** 모든 플레이리스트 영상에 공통 적용될 재사용 가능한 표준 모듈 시스템 구축. 시청자에게 '기술적 깊이'와 '집중력 증대'라는 기능적 가치를 시각적으로 전달하는 것이 핵심입니다.

### 🧱 디자인 원칙 및 기본 스펙 (Global Specs)
| 항목 | 규격 | 상세 설명 |
| :--- | :--- | :--- |
| **전체 분위기** | Cinematic Industrial Drama | 하드웨어, 데이터 흐름, 시간적 압박감을 시각화. 미니멀하지만 복잡한 느낌 유지. |
| **주요 컬러 팔레트** | Primary: Deep Charcoal (`#1A1B26`) / Accent: Bronze (`#A87932`) / Secondary: Electric Blue (Utility) (`#4DFFFF` - 보조 데이터 흐름용) | 딥 차콜을 배경/기본 UI에, 브론즈를 주요 강조 및 경고(Attention)에 사용. |

| **레이아웃 가이드** | 화면 좌하단(L-Bottom), 우측 하단(R-Bottom)에 주요 정보를 배치하며, 중앙 상단은 핵심 시각 이벤트에 할애한다. |

### 🛠️ Module Set 1: [Focus Timer & Progress Bar] (시간 압박 및 목표 달성 모듈)
**기능:** 현재 집중 세션의 시간 경과와 남은 시간을 시뮬레이션하며, 사용자에게 '제한된 자원'이라는 인지적 압박을 부여한다. (가장 필수적인 요소)

| 스펙 | 내용 | 상세 설명 및 활용 예시 |
| :--- | :--- | :--- |
| **위치** | 화면 좌하단 (L-Bottom, 고정) | 모든 영상에서 항상 같은 위치에 존재하여 안정감을 제공. |
| **디자인 요소** | 1. 원형 게이지 (Circular Progress Bar) / 2. 카운트다운 숫자 표시 (`HH:MM:SS`) / 3. 경고 라인(Warning Line) | 시간의 흐름을 시각적 '소모'로 표현. 시간이 임계점(예: 5분 미만)에 도달하면 게이지 테두리가 **브론즈**에서 **붉은색/앰버**로 전환되어 긴장감을 유발한다. |
| **컬러 적용** | 배경 외곽선: `Deep Charcoal` / 채워지는 게이지 (0% $\rightarrow$ 100%): 은은한 브론즈 그라디언트 (`#A87932` $\rightarrow$ `#6B5E3D`) / 남은 시간 표시 숫자: `#4DFFFF` |
| **애니메이션** | 시간 흐름에 따라 게이지가 부드럽게(Easing Curve) 채워지며, 끝 지점에서 미세한 떨림(Pulse Effect)을 주어 시각적 효과를 극대화한다. |

### 📊 Module Set 2: [Flow State Gauge] (인지 부하 및 집중도 트래킹 모듈)
**기능:** 사용자가 현재 경험하는 '몰입 상태' 또는 '데이터 처리 복잡도'를 추상적으로 측정하여 보여준다. 감성적(Emotional)인 요소를 기능적인 UI로 치환한다.

| 스펙 | 내용 | 상세 설명 및 활용 예시 |
| :--- | :--- | :--- |
| **위치** | 화면 우하단 (R-Bottom, 고정) | 타이머와 시각적으로 분리되어 독립성을 가진다. |
| **디자인 요소** | 1. 트래킹 바(Tracking Bar): 세로형 또는 가로형의 기울기 게이지 / 2. 지표 값 표시: `[Flow Score]: XX%` (숫자) / 3. 연결선(Connection Lines): 낮은 점수일 때 끊어지는 데이터 흐름 시각화. | 이 모듈은 배경 음악의 '리듬'이나 스크립트의 '밀도'에 비례하여 값이 변동한다. 최고 효율 구간(Flow State)에서는 바가 가장 넓고 안정적인 **브론즈** 빛을 낸다. |
| **컬러 적용** | 기본 게이지 트랙: `Deep Charcoal` / 현재 점수 값: 부드럽한 브론즈 그라디언트 (진동 효과를 주어 살아있는 느낌 부여) / 경고(저점): 불안정한 파란색 (`#4DFFFF`)의 깜빡임. |
| **애니메이션** | 값이 변할 때, 게이지 바가 '데이터 패킷'이 빠르게 쌓이는 듯한 시각적 애니메이션을 적용한다 (디지털 노이즈와 결합). |

### 🔗 Module Set 3: [Data Stream Visualizer] (시스템 연결 및 정보 흐름 모듈)
**기능:** 단순히 시간을 세는 것을 넘어, '정보'가 시스템 속에서 이동하고 처리되는 과정을 시각적으로 보여준다. 전체 영상의 배경에 은은하게 깔리며 드라마틱한 분위기를 조성한다.

| 스펙 | 내용 | 상세 설명 및 활용 예시 |
| :--- | :--- | :--- |
| **위치** | 화면 전역 (Global Overlay) / 주로 좌측 상단, 우측 상단 구석에 집중 배치. | 배경 영상의 주요 액션이 없을 때, 시선이 머무르는 곳에 정보를 제공하며 몰입을 돕는다. |
| **디자인 요소** | 1. 데이터 연결선(Connection Lines): 미세하고 복잡한 그리드 라인 / 2. 데이터 패킷(Data Packets): 작은 사각형/원형의 빛나는 점들 / 3. 레이블: `[Input Source] $\rightarrow$ [Process Node]`와 같은 간결한 로깅 형태. | 영상 콘텐츠 내에서 '연결', '분석', '전환' 등의 개념이 등장할 때, 이 연결선과 패킷의 움직임을 증폭하여 사용한다. (예: 문제 제기(Input) $\rightarrow$ 해결 과정(Output)) |
| **컬러 적용** | 기본 라인/그리드: 아주 옅은 `#3A3B46` (배경에 녹아드는 느낌). 데이터 패킷 이동 경로: 차가운 전기 블루 (`#4DFFFF`)를 주 색상으로 사용하여 '데이터'의 느낌을 강조. |
| **애니메이션** | 라인들은 주기적으로 매우 미세하게(Subtle Flicker) 깜빡이며 전력이 흐르는 듯한 느낌을 주고, 데이터 패킷은 일정한 속도로 끊임없이 이동한다. (루프 애니메이션 필수). |
