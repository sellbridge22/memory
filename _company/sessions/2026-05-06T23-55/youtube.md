#### 2. 시네마틱 썸네일 브리프 (VHS 노이즈 / 아날로그 필터 적용)
**[브랜드 컨셉]:** *System Error / Diagnostic Report*
**[톤앤매너]:** 저채도, 높은 대비, 경고(Warning) 분위기.

| 요소 | 상세 브리프 내용 | 레오의 지시 사항 (디자이너/영상팀) |
| :--- | :--- | :--- |
| **배경 비주얼** | 복잡하게 얽힌 전선 다발, 고장 난 회로 기판(Circuit Board), 또는 폭주하는 데이터 스트림 같은 '시스템' 이미지를 사용합니다. 배경 전체에 VHS 노이즈와 아날로그 글리치 효과를 적용해야 합니다. | **필수:** 중앙이나 측면에 미세한 깜빡임과 지글거리는 아티팩트를 유지하여, 영상 시작부터 불안정성을 시각화하세요. |
| **메인 이미지** | 인물은 직접적인 표정(좌절감, 생각에 잠긴)보다는 *'진단을 받는 사람'*처럼 보이게 합니다. (예: 한 손으로 관자놀이를 누르거나, 복잡한 화면을 응시하는 모습). | 인물의 감정보다 **'상황적 고통'**이 부각되어야 합니다. |
| **텍스트 구조** | 1단계(메인 카피)가 가장 크고 강렬해야 합니다. 2단계는 보조적인 근거를 제공합니다. | **폰트:** 산세리프 계열 중, 마치 터미널 창이나 구형 시스템 메시지에 쓰이는 듯한 '디지털 오류체' 느낌을 주는 폰트를 사용하세요. |
| **색상 팔레트** | 주 색상: 블랙(Black), 그레이(Gray). 강조색 (경고): 네온 레드/앰버 오렌지 (⚠️, 🔥) | 전체적으로 낮은 채도로 통일하고, 경고 메시지만 극단적인 색 대비를 사용하여 시선을 강탈합니다. |
| **핵심 카피 조합** | 메인: "당신의 번아웃은 개인 문제가 아닙니다." / 서브: "시스템 오류 진단 보고서 (System Overload Diagnosis)" | 썸네일 오른쪽 상단이나 하단에 작은 '⚠️ Warning' 아이콘을 배치하여 전문성을 더합니다. |
