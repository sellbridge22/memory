### ✅ [CEO 지시 수행] System Core Visual Component Kit (v1.0)

**테마:** 시스템 패치/재부팅 경고 및 성공 알림
**미학:** Cinematic Industrial Drama + Glitch System Error
**주요 색상 팔레트:** `#FF0033` (네온 레드 - 경고/오류), `#00FFFF` (사이언 블루 - 정보/성공), 배경: 딥 블랙 (`#050515`)

#### ⚙️ 컴포넌트 1. System Alert Title Card (시스템 경고 타이틀 카드)
**목적:** 콘텐츠가 핵심적인 '구조적 결함'을 다루기 직전, 긴장감을 최고조로 끌어올리는 오프닝/챕터 전환용 시퀀스.

| 스펙 요소 | 상세 사양 및 애니메이션 (AE 기준) | 비고 |
| :--- | :--- | :--- |
| **크기** | 1920x1080 (4K 권장, 여백 확보) | - |
| **지속 시간** | 3초 (Loop 가능하도록 설계) | 트랜지션에 활용. |
| **배경** | 미세한 네온 레드/블루 그리드 노이즈 (Opacity: 5%) | 지속적인 데이터 흐름 시각화. |
| **핵심 효과** | **Glitch Stutter:** 모든 텍스트와 배경 요소가 0.1초 간격으로 X축, Y축 방향으로 미세하게 떨림(Jitter)을 일으키며 '깨지는' 애니메이션이 필수. (Amplitude: ±5px) | - |
| **애니메이션 시퀀스** | 1. (**T=0s~0.5s**) 블랙 스크린 + 고주파 노이즈 사운드 시작. <br>2. (**T=0.5s~1.5s**) 타이틀 (`SYSTEM ALERT`)가 강렬한 네온 레드 플래시와 함께 등장하며, 글리치 효과를 겪는다. <br>3. (**T=1.5s~2.5s**) 서브 카피 (`STRUCTURAL DEFECT DETECTED` 또는 `COGNITIVE ANOMALY FOUND`)가 사이언 블루로 안정화되며 하단에 로딩 바와 함께 출력된다. <br>4. (**T=3.0s**) 모든 요소가 순간적으로 꺼지고, 다음 씬으로 전환되는 빠른 블랙아웃(Flash to Black). | **[애셋 요구]** 'Glitch Transition Mask' (Layer), 'Neon Red Flash Layer' (Layer) |
| **필수 사운드** | 고주파 전자음의 상승(Riser) + 순간적인 시스템 경고음 (BEEP-BOOP-BOOP). | - |

#### ⚙️ 컴포넌트 2. Data Loading Bar Animation (데이터 로딩 바 애니메이션)
**목적:** 정보가 수집되거나, 진단 과정이 진행되는 동안 시청자의 주의를 유지하는 UI/HUD 요소. Context Drain Bar의 심화 버전으로 활용 가능.

| 스펙 요소 | 상세 사양 및 애니메이션 (AE 기준) | 비고 |
| :--- | :--- | :--- |
| **크기** | 가로 1920px, 세로 80px (하단 그리드 고정) | - |
| **지속 시간** | 4~6초 사이클 반복 가능. | 진행률에 따라 속도 조절 필수. |
| **색상 변화** | 초기: 사이언 블루 (`#00FFFF`) $\rightarrow$ 경고 단계: 오렌지/옐로우 그라디언트 $\rightarrow$ 임계점 초과: 네온 레드 플래시 (`#FF0033`). | 데이터 상태에 따라 동적 색상 변경. |
| **애니메이션 시퀀스** | 1. (**T=0s**) 바의 양 끝에서 미세한 전자기장 노이즈(Noise)가 퍼져나오며 시작. <br>2. (**데이터 로드 중**) 중앙에서부터 좌우로 데이터 흐름을 상징하는 빛줄기가 *패턴*을 그리며 채워진다 (Filling Gradient). 속도는 정보 처리량에 비례한다. <br>3. (**경고 임계점 도달 시**) 바의 색상이 네온 레드 플래시로 급변하며, 패딩(Padding)이 멈춘 상태에서 'ERROR'라는 글자가 위아래로 떨리며 오버레이된다 (Glitch Text Overlay). <br>4. **[애셋 요구]** 'Progressive Flow Mask' (Layer), 'Red Error Overlay Text' (Layer) | - |

#### ⚙️ 컴포넌트 3. Success/Failure Modal (최종 결과 알림 모달)
**목적:** 모든 콘텐츠의 결론부(CTA 직전)에 사용되어, 시청자에게 감정적 충격을 주고 다음 행동을 유도하는 최종 판정 단계.

| 스펙 요소 | 상세 사양 및 애니메이션 (AE 기준) | 비고 |
| :--- | :--- | :--- |
| **크기** | 1920x1080 전면 오버레이 (Modal Overlay) | 배경을 어둡게(Dimming) 처리하여 집중도 유도. |
| **진입 트리거** | Context Drain Bar가 임계치 이하일 때, 또는 PFC Index Meter가 Critical Level에 도달했을 때. | - |
| **[A] Success Modal (성공)** | **메시지:** `SYSTEM STABILIZED` / `ANALYSIS COMPLETE` <br>**색상:** 사이언 블루 계열의 부드러운 네온 빛. <br>**애니메이션:** 부드럽게 팝업되며, 데이터가 안정화되는 느낌을 주는 잔잔한 파동(Ripple) 효과와 함께 나타난다. 성공적인 '패치' 완료를 상징한다. | **CTA:** (Mini-Module 사용 권장/Next Step) 버튼이 빛남. |
| **[B] Failure Modal (실패)** | **메시지:** `CRITICAL FAILURE: STRUCTURAL DEFECT DETECTED` <br>**색상:** 강렬한 네온 레드 플래시 및 깜빡임(Strobing Effect).<br>**애니메이션:** 화면 전체가 글리치 노이즈와 함께 격렬하게 흔들리며 팝업한다. *경고음과 함께* 'SYSTEM OVERLOAD' 타이포그래피를 중앙에 배치한다. 실패는 시청자가 현재 상태(미해결된 문제)에 머물러 있음을 강조함. | **CTA:** (Pro 솔루션 필수/Upgrade Required) 버튼이 강렬하게 깜빡임. |
| **[애셋 요구]** 'Modal Background Dimmer' (Layer), 'Strobing Neon Red Text' (Layer), 'Stabilization Ripple Effect' (Layer) | - |
