# ⚙️ [SOP] Music Playlist 영상 컴파일 워크플로우 (V1.0)
**목표:** 단순한 배경음악을 넘어, '시스템 결함을 진단하고 개선한다'는 내러티브를 구조화하여 콘텐츠의 학술적 가치와 긴장감을 극대화한다.
**핵심 미학:** 네온 레드 글리치 (Neon Red Glitch) 및 데이터 스트림 시각화.

## 1. B-roll/시각 자료 수급 및 구성 가이드라인 (Asset Gathering Protocol)

| 테마 | 학술적 개념어 (Keywords) | 필수 B-roll 유형 (Shot Type) | 액션 포인트 (Visual Directive) |
| :--- | :--- | :--- | :--- |
| **[Overload]** (과부하/집중력) | Information Overload, Task Memory Limit, Resource Allocation | 1. 복잡한 데이터 스트림 (Binary Code) 2. CPU 과열 게이지/모니터링 화면 3. 신경망의 '오버플로우' 시각화 | **[진단 단계]:** 빠르고 불규칙적인 깜빡임(Strobe Effect). 무작위 데이터가 폭주하는 느낌을 주어 혼란도를 높인다. |
| **[DMN Calibration]** (창의성/아이디어 막힘) | Default Mode Network, Divergent Thinking, Concept Mapping | 1. 뉴런 네트워크 그래픽 (연결 및 분리) 2. 기하학적 패턴이 확장되는 추상 이미지 3. 개념 노드 간의 연결선(Pathfinding) 애니메이션 | **[분석 단계]:** 느리고 우아하며 구조적인 움직임. 깨끗한 그리드 위에 점들이 체계적으로 이동하는 느낌을 준다. |
| **[Pre-Crisis Diagnostic]** (불안감/고압적 상황) | Physiological Threshold, System Instability, Stress Response Curve | 1. 심박수 모니터링 그래프(EKG Waveform) 2. 타이머 카운트다운 시각화 3. 압력 게이지가 임계점(Red Zone)에 도달하는 그래픽 | **[긴장 단계]:** 주기적이고 규칙적인 위협감. 낮은 주파수의 진동(Tremolo) 효과를 배경에 깔아 불안감을 유도한다. |

## 2. 사운드 싱크 및 편집 타이밍 지침 (Audio-Visual Sync Protocol)

영상은 단일한 BPM이 아닌, **'긴장 고조 → 임계점 도달 → 급격한 해소/전환'**의 3단계 리듬 변화를 가져야 합니다.

| 시간대 (Timecode) | 사운드 주파수 및 음악 역할 | 시각적 효과 지침 (Visual Directive) | 편집 기법 (Transition) |
| :--- | :--- | :--- | :--- |
| **0:00 ~ 0:12** (도입/설정) | Ambient & Low-Frequency Drone. 정보 과부하의 '배경 소음' 역할. | 느린 속도의 B-roll(데이터 흐름, 뉴런 등) 배치. 화면에 학술적 용어 자막만 천천히 등장. | **Smooth Cross Dissolve:** 부드럽게 장면을 전환하여 안정감을 가장한 불안함을 조성한다. |
| **0:13 ~ 0:25** (문제 제기/클라이맥스) | 음악의 BPM이 갑자기 상승(Build-up). 시스템 경고음, 날카로운 피치 변화 사운드 추가. | 핵심 문제 지점(Pain Point)에 맞는 B-roll을 **극단적으로 빠르게 교차 편집**. 네온 레드 글리치와 텍스트가 화면 전체를 장악한다. | **Hard Cut & Glitch Transition:** 장면과 장면이 논리적 연결 없이 갑자기 끊기며, '시스템 오류'의 느낌을 강하게 전달한다. (필수) |
| **0:26 ~ End** (솔루션 제시/CTA) | 음악이 일시적으로 멈추거나(Silence), 안정적인 저주파 사운드로 전환. 명확한 내레이션에 집중. | 배경은 어두워지며, 오직 CTA 모듈과 핵심 문구만 네온 레드 빛으로 강조되어 나타난다. | **Focus Zoom/Fade Out:** 화면이 빠르게 줌인하며 CTA에 시선이 강제적으로 고정되도록 유도한다. (강력한 몰입감 조성) |

## 3. CTA 노출 최적화 편집 지침 (Conversion Point Mapping)

유료 모듈 구매를 유도하는 `[SERVICE REQUIRED]`와 같은 CTA는 **시청자가 가장 높은 좌절감(Frustration)**을 느낄 때 배치되어야 합니다.

*   **최적 위치:** 0:25초 ~ 0:35초 사이 (문제 제기 클라이맥스 직후)
*   **전환 효과 (The Reveal):**
    1.  **배경 전환:** 모든 B-roll이 갑자기 **네온 블랙/딥 차콜 그라데이션**으로 일제히 먹먹해지며 빛을 잃는다. (시각적 충격)
    2.  **글리치 효과 증폭:** 화면 전체에 레드 글리치가 가장 강하게, 그리고 길게(최소 1초) 오버레이된다.
    3.  **CTA 모달 등장:** `[SERVICE REQUIRED]` 문구가 마치 **시스템이 스스로 진단하며 팝업된 경고창**처럼 나타난다. (사용자가 원해서 본 것이 아님을 느끼게 함).
*   **자막/강조:** CTA 주변의 모든 자막은 '임시' 또는 '불완전함'을 암시하는 단어로 처리하고, 모듈 명칭만 크고 확정적인 폰트로 배치한다.
