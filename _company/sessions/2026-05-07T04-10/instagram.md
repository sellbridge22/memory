## 🚨 Mini-Module 연계 릴스 실행 계획 (3종)

최신 의사결정(Mini-Module 진단, SYSTEM OVERLOAD 콘셉트)을 반영하여, 단순한 '팁' 제공이 아닌 '문제 정의 및 경고'에 초점을 맞춘 릴스 3가지의 최종 실행 계획입니다. 모든 콘텐츠는 시청자에게 구조적인 결핍감과 위기감을 느끼게 하여 Mini-Module 진단으로 유도합니다.

---

### 🎬 Reel 1: [집중력 분산 비용]
**주제:** Context Switching Cost (작업 전환 비용)의 무서움
**연결 Mini-Module 단계:** 인지적 예산 고갈 지점
**콘셉트/비주얼 브리프:** 시계 초침 소리, 알람음, 그리고 'SYSTEM ERROR' 경고 메시지가 화면을 빠르게 플래시함. 여러 앱 창이 오버레이되고 겹쳐지는 혼란스러운 애니메이션 사용.

| 요소 | 내용 (실행 가이드) |
| :--- | :--- |
| **🔥 강력한 후크 (Hook)** | *(0~3초)* "당신이 아는 것보다 당신은 지금 몇 %의 에너지를 잃고 있을까요? (화면: [40% 손실] 경고등 깜빡임)" |
| **🔊 보이스오버/내레이션** | "여러 작업을 오가는 순간, 뇌는 매번 초기화를 시도합니다. 이 '작업 전환 비용'이 누적되면 당신의 집중력은 이미 시스템 과부하 상태입니다." |
| **📝 자막 강조 포인트** | "🧠 인지 부하 손실: [X]% 누적", "⏰ 시간 낭비가 아닌, 에너지 낭비" |
| **🎯 CTA (Call to Action)** | "이 경고등을 직접 확인하세요. 프로필 링크에서 Mini-Module 진단을 시작하세요." |
| **📅 최적 게시 시간** | 화요일 저녁 8:00 ~ 9:00 (주중 피로도가 누적되어 자기계발 콘텐츠 소비가 높은 시간대) |

### 🎬 Reel 2: [결정 마비]
**주제:** Decision Fatigue (과도한 선택으로 인한 결정 장애)
**연결 Mini-Module 단계:** 의사결정 피로도 스코어 측정
**콘셉트/비주얼 브리프:** 수많은 메뉴, 옵션 버튼, 선택지가 화면을 가득 채우고 있음. 캐릭터가 그 앞에서 압도당해 멈춰 서 있는 슬로우 모션 연출. 배경에 'OVERLOAD' 경고문구 삽입.

| 요소 | 내용 (실행 가이드) |
| :--- | :--- |
| **🔥 강력한 후크 (Hook)** | *(0~3초)* "결정 장애? 그건 당신의 의지 문제가 아닙니다. 시스템이 과부하된 증거입니다." |
| **🔊 보이스오버/내레이션** | "선택지가 많다는 것은 축복이지만, 사실은 뇌에 가장 큰 자원 고갈을 일으킵니다. 무한한 선택의 바다에서 길을 찾는 것은 불가능합니다." |
| **📝 자막 강조 포인트** | "✅ [X]가지 옵션 앞에서 정지", "🧠 결정 피로도는 당신의 에너지를 갉아먹습니다" |
| **🎯 CTA (Call to Action)** | "나의 의사결정 시스템을 진단해야 합니다. 프로필 링크 확인." |
| **📅 최적 게시 시간** | 목요일 오후 2:00 ~ 4:00 (업무 중 지루함/피로도를 느끼는 시간대에 문제 제기) |

### 🎬 Reel 3: [시스템 경고]
**주제:** 지속 가능한 에너지 관리의 필요성 (전체 구조적 불안정성 진단)
**연결 Mini-Module 단계:** 종합 진단 및 솔루션 제시 (가장 강력한 Funnel Top 콘텐츠)
**콘셉트/비주얼 브리프:** 영화 속 '시스템 다운' 직전의 붉은 경고등 콘셉트를 메인으로 사용. 갑자기 모든 것이 정지되고, 화면에 빨간 글씨로 [CRITICAL ERROR] 메시지가 뜨는 연출.

| 요소 | 내용 (실행 가이드) |
| :--- | :--- |
| **🔥 강력한 후크 (Hook)** | *(0~3초)* "🔴 경고: 당신의 인지적 예산이 위험 수준에 도달했습니다." (가장 시각적인 충격 요법) |
| **🔊 보이스오버/내레이션** | "만성적인 피로는 나태함이 아닙니다. 시스템이 보내는 '정비 필요' 경고 신호입니다. 지금 당신의 구조적 결핍을 측정해야 합니다." |
| **📝 자막 강조 포인트** | "🚫 [❌] 노력 부족 X, [⭕] 시스템 과부하 O", "💡 진단만이 최선의 솔루션" |
| **🎯 CTA (Call to Action)** | "시스템 안정화를 시작하세요. 프로필 링크에서 Mini-Module을 통해 지금 바로 자가진단하기." |
| **📅 최적 게시 시간** | 월요일 저녁 7:00 ~ 8:00 (새로운 한 주를 시작하며 가장 큰 동기 부여와 위기감을 느끼는 시간대) |

## ✨ 통합 콘텐츠 배포 전략

### 📝 추천 캡션 구조 (공통 패턴)
(🚨 경고 메시지 형식의 도입부로 시선을 강탈합니다.)

**[제목 예시]** 🛑 당신이 매일 무심코 흘리는 에너지. 이대로 괜찮으신가요?

**[본문 구성]**
1. **Pain Point 정의 (문제 제기):** "많은 사람들이 이걸 '노력이 부족해서'라고 생각하지만, 사실은 당신의 뇌 시스템 자체가 과부하 상태에 빠졌을 수 있습니다." (구조적 문제임을 강조)
2. **Mini-Module 연결:** "우리의 Mini-Module 진단 페이지는 당신이 놓치고 있는 [작업 전환 비용/결정 피로도 등]을 정확히 측정합니다. 추측하지 마세요, 숫자로 확인하세요."
3. **CTA 및 위기감 극대화:** "시스템의 경고등을 무시하면 안 됩니다. 더 깊은 진단이 필요하다면 프로필 링크를 클릭하여 Mini-Module을 통해 당신의 인지적 예산을 점검하세요."
