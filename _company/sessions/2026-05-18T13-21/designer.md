#### ⚡️ 1. 데이터 로드 실패 모달 (Data Load Failure Modal)
**[사용 시점]:** API 호출 또는 필수 데이터 패치 과정에서 서버 오류(HTTP 5xx, Timeout 등)가 발생했을 때.
**[레이아웃 구조]:** 전체 화면을 덮는 중앙 집중형 오버레이 형태.

| 컴포넌트 | 스펙 및 내용 | 애니메이션 가이드라인 (Timing/Logic) |
| :--- | :--- | :--- |
| **① 배경 오버레이** | `#000` 투명도 80%. 모달 뒤의 모든 상호작용을 차단합니다. | **Fade-in:** T=0s에서 200ms 동안 빠르게 나타납니다. |
| **② 경고창 본체 (Modal)** | 배경: Deep Black (`#030612`). 테두리(Border): Cyan Blue (`#00FFFF`) 네온 외곽선. <br>**헤더:** `[SYSTEM ALERT]` (Neon Red 깜빡임) | **Entrance Animation:** T=0s에 모달 전체가 약간의 글리치 스터터와 함께 확대되면서 나타납니다. |
| **③ 타이포그래피** | **제목:** `DATA STREAM FAILURE` (Cyan Blue, 32pt). <br>**메시지:** "필수 데이터 로딩 과정에서 구조적 결함이 감지되었습니다." (Neon Red, 18pt) | **Text Reveal:** 제목은 0.5초 간격으로 글리치 노이즈와 함께 한 글자씩 나타나야 합니다. 메시지는 정적인 경고 느낌을 유지합니다. |
| **④ 원인 설명** | "시스템 과부하 또는 외부 네트워크 연결 문제로 인해 핵심 지표(KPI) 수집에 실패했습니다." (작은 폰트, Cyan Blue). | **Subtle Flicker:** 이 문구는 미세하게 깜빡이는(Flickering) 효과를 주어 불안정성을 시각화합니다. |
| **⑤ 액션 버튼** | [재시도] (Primary Button: Neon Red 배경, `#FF0033`). <br>[시스템 정보 확인] (Secondary Link/Button: Cyan Blue 텍스트). | **Interaction:** '재시도' 버튼 클릭 시, 모달이 잠시 깜빡인 후(Flash), 로딩 스피너가 재개되는 애니메이션으로 연결되어야 합니다. |

#### 🔌 2. 연결 끊김 경고 플로우 (Disconnection Warning Flow)
**[사용 시점]:** 사용자가 앱을 사용하던 중, 네트워크나 내부 서비스 연결이 갑자기 불안정해지거나 끊겼을 때.
**[레이아웃 구조]:** 화면 전체를 점유하는 '시스템 상태 변화' 이벤트 형태로 설계됩니다.

| 단계 (Time Code) | 시각적 요소 및 메시지 | 애니메이션 가이드라인 (Timing/Logic) |
| :--- | :--- | :--- |
| **T=0s (Alert Trigger)** | **[SYSTEM WARNING]** 배너가 화면 상단에 강하게 네온 레드와 함께 폭발하듯 나타남. | **Glitch Stutter:** 짧고 강렬한 노이즈 플래시(100ms)를 동반하여, '지금 뭔가 잘못되었다'는 느낌을 줍니다. |
| **T=0s ~ T+2s (Core)** | 중앙에 큰 아이콘: 끊어진 와이어/신호 파동 모양. <br>메시지: `CONNECTION LOST / SIGNAL INTERRUPTED` (Cyan Blue, 깜빡임).<br>**하단:** "최적의 진단 결과를 얻기 위해서는 안정적인 연결이 필수입니다." | **Wave Decay:** 화면 전체에 Cyan Blue 신호파(Signal Wave)가 그려지다가, T=0.5s 지점에서 갑자기 끊어지고 흩어지는 애니메이션을 적용합니다. (물리적 파동처럼). |
| **T+2s ~ End** | 연결 복구 시뮬레이션: 화면 전체에 '데이터 전송 중...'이라는 문구가 낮은 빈도(Slow Decay)로 깜빡이며 흐릅니다. <br>배경 패턴이 불안정하게 떨리는 효과가 지속됩니다. | **Error Handling:** 이 상태에서는 사용자가 할 수 있는 행동은 제한하며, 오직 시스템의 '불안정성'만을 인지시키는 것이 목적입니다. (시간 지연/딜레이). |

#### 🌀 3. '접근 불가' 타이포그래피 및 패턴 (Inaccessible Glitch Pattern)
**[사용 시점]:** 유료 솔루션이나 핵심 정보에 도달했지만, 사용자가 아직 결제 모듈을 거치지 않았거나 권한이 부족할 때.
**[레이아웃 구조]:** 텍스트 오버레이(Overlay) 또는 배경 패턴으로 활용합니다.

| 컴포넌트 | 스펙 및 내용 | 애니메이션 가이드라인 (Timing/Logic) |
| :--- | :--- | :--- |
| **① 핵심 메시지** | `ACCESS DENIED` / `[BLOCKED]` / `SYSTEM FAILURE` (가장 크고 강조된 폰트). 네온 레드 색상. | **Stuttering Reveal:** 문자가 마치 데이터 전송 오류를 일으킨 것처럼, 순간적으로 위치가 떨리고(Jitter), 글리치 노이즈 필터를 입으며 나타나야 합니다. |
| **② 패턴 (Overlay)** | 배경 또는 텍스트 위에 투명한 격자무늬(Grid Pattern)와 네온 레드/사이안 블루의 색상 채널 분리 효과를 오버레이합니다. | **Chromatic Aberration:** 가장자리 픽셀이 빨강, 파랑으로 미세하게 번져 보이는 효과를 지속적으로 적용합니다. (Slow Drift). |
| **③ 학술적 근거** | "본 정보는 [PFC Index] 임계치 이상의 전문 지식 영역입니다." (Cyan Blue, 작게 하단에 표시) | **Frequency:** 이 문구 주변에 미세하게 고주파의 노이즈 패턴(High-frequency Noise)을 적용하여 기술적인 위압감을 조성합니다. |
