## 🎬 [Critical Alert Level] 모션 그래픽 에셋 패키지 (15초 도입부용)

**목표:** 초반 3초 내에 시청자의 인지 부하를 최대로 끌어올려, '문제를 해결해야 한다'는 긴급성을 부여하고 Mini-Module 진단 페이지로의 유입을 강제한다.
**총 길이 분배 (예시):** Asset 1 (0~5초) $\rightarrow$ Asset 2 (6~10초) $\rightarrow$ Asset 3 (11~15초)

### ⚙️ 에셋 1: Context Drain Gauge (경고 게이지 애니메이션 프레임)
*   **기능:** 사용자의 '인지 자원 고갈' 상태를 시각적으로 측정하고 경고하는 핵심 장치.
*   **톤앤매너:** 전문적, 냉정함, 하드웨어 모니터링 UI 느낌.

| 스펙 요소 | Stage 1 (Normal) | Stage 2 (Warning: T1) | Stage 3 (Critical Failure: T2) |
| :--- | :--- | :--- | :--- |
| **시각적 변화** | 녹색(Healthy) 영역에 머무는 바늘/그래프. | 황색(Yellow Glow)으로 전환 및 진동 발생. 게이지가 70% 이상 상승. | 네온 레드(Neon Red) 플래시, 최대 임계점 도달 애니메이션. 게이지 전체가 경고등 상태로 고정. |
| **핵심 지표** | Cognitive Load Score (CL Score): $\text{Low} \sim 45\%$ | CL Score: $46\% \sim 75\%$ | CL Score: $> 80\%$ (SYSTEM OVERLOAD) |
| **색상 코드 (Hex)** | `#4CAF50` (진한 녹색), `#388E3C` (텍스트) | `#FFEB3B` (깜빡이는 황색), `#FBC02D` (경고선) | `#FF0000` (강렬한 레드), `#990000` (배경 오버레이) |
| **애니메이션 Spec** | Linear Easing. 부드러운 움직임. | Oscillating/Pulse Effect (1Hz, 2초 주기). 바늘 주변에 노이즈 필터 추가. | Rapid Glitch Flicker + 고주파수 깜빡임(Strobe effect)을 게이지 전체에 적용. **[필수]** |
| **트리거 타이밍** | 도입부 시작 시점 (0~5초 구간). | 클라이맥스 진입 직전 (3~6초 구간). | 임계점 도달 순간, 가장 높은 긴장감을 연출하는 컷 전환 지점. |

### 💸 에셋 2: Loss Cost Data Burst (손실 비용 충격 오버레이)
*   **기능:** 추상적 문제(비효율성)를 구체적인 금전적 손실($1,200)로 직결시켜 시청자의 공포/긴급성을 극대화.
*   **톤앤매너:** 금융 보고서의 오류 경고, 하드 데이터 폭주 느낌 (Data Dump).

| 스펙 요소 | 구현 방법 및 레이아웃 | 애니메이션 Spec | 핵심 사운드 연계 |
| :--- | :--- | :--- | :--- |
| **핵심 텍스트** | `ESTIMATED COST OF INACTION: $1,200.00` (반복 노출) | **Kinetic Typography:** 문자가 한 글자씩 폭발하듯(Burst Out) 등장하며, 마지막 '$'와 숫자에 강력한 *Scale Up* 효과를 적용한다. | **Sound Impact:** 텍스트가 터지는 순간, 낮은 주파수의 '웅장한 전기적 스파크 소리 (Low frequency electrical spark)' 필수 삽입. |
| **레이아웃** | 화면 중앙 하단에 고정된 HUD 패널 형태. 배경에는 무작위로 흘러가는 코드/숫자 스트림(Green Terminal Code)을 오버레이한다. | 데이터 폭주 시, 코드가 잠깐 멈추고 (Freeze Frame), 오류 경고 문구만 강하게 깜빡이는 *Stutter Effect*를 부여한다. | **Sound Context:** 배경에 지속적으로 낮은 '삐이이잉... (Humming/Warning Tone)' 사운드를 유지하여 위기감을 조성한다. |
| **재활용 용도** | 이 $1,200의 근거가 되는 '측정 가능한 시스템적 결함' 리스트를 빠르게 3~4개 나열할 때 활용 가능. (예: Focus Loss: $X, Context Switch Cost: $Y) |

### ✨ 에셋 3: System Overload Glitch/Text Overlay (시스템 오류 경고 오버레이)
*   **기능:** 콘텐츠 전체에 걸쳐 통일된 '붕괴 임박'의 시각적 언어(Visual Language)를 제공하고, 영상 전환 시 충격 효과로 사용.
*   **톤앤매너:** 디지털 아날로그 붕괴, 기술적 고장 (Digital Degradation).

| 스펙 요소 | 구현 방법 및 적용 부위 | 애니메이션 Spec | 활용 시점 |
| :--- | :--- | :--- | :--- |
| **필터 효과** | 전체 화면에 주기적으로 적용되는 글리치(Glitch) 노이즈 필터. (RGB 채널 분리, 수평 밴딩 등) | 1~3 프레임 간격으로 화면의 색상 채널을 미세하게 어긋나게(Chromatic Aberration) 처리한다. 이 패턴은 리듬감을 가지며 반복되어야 함. | 영상 도입부 전반에 걸쳐 배경처럼 은은하게 깔리되, 중요한 메시지 직전에 **강도(Intensity)**를 최대로 증폭시킨다. |
| **텍스트 오버레이** | `[CRITICAL ALERT]`, `SYSTEM OVERLOAD`, `DATA CORRUPTION` 등의 키워드를 좌우로 빠르게 스캔하며 나타나게 한다. (Scan Line Effect) | 텍스트가 화면을 가로질러 지나갈 때, 마치 VHS 테이프가 손상되는 듯한 'Tracking Noise'와 함께 깜빡임(Blink Rate: $10 \text{Hz}$)을 부여한다. | 주요 메시지 전환점이나 CTA 직전에 최대 강도로 노출하여 시각적 경고를 극대화한다. |
| **기술 구현 Tip** | 이 효과는 CSS의 `filter: glitch()`와 유사한 개념으로, 프레임 단위의 픽셀 조작(Pixel Manipulation)을 통해 가장 높은 임팩트를 얻는다. |
