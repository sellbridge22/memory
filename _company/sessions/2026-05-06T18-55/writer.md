# ✍️ Writer — 시스템이 사용자에게 경고/재활성화를 유도해야 하는 Decline State의 톤앤매너를 정의합니다. 단순히 '집중력 저하'라는 기술적 사실 전달을 넘어, 사용자가 스스로 쉬어가야 한다는 심리적 위로와 동기부여가 담긴 메시지 세트를 작성해주세요. (예: '잠시 숨 고르세요.', '시스템 재조정 필요', '5분 휴식 타이머 시작'). 이 문구들은 기술 스펙(Developer의 출력물)과 결합되어 시각적으로 노출될 때 가장 드라마틱하고 공감 가는 방식으로 구성해야 합니다.

✍️ Writer: 작업 시작합니다.

### 🧠 [가장 가치 있는 단일 작업 결정]

현재 팀은 '최적화된 학습 사이클'이라는 핵심 메커니즘의 **기술적 아키텍처**와 **시각적 구현 방법론(Shader Gradient, 애니메이션)**을 완성하는 단계에 있습니다. 다음으로 가장 중요한 것은 이 모든 기술적 요소들을 사용자의 **감정적 경험(Emotional Experience)**과 연결하는 것입니다. 단순히 '집중도가 낮다'는 사실 전달은 사용자에게 좌절감을 줄 수 있습니다.

따라서 가장 가치 있는 작업은, 시스템의 핵심 기능인 **[Decline State]**와 **[Reactivation Prompt]**에 대한 공감적이고 드라마틱한 카피라이팅/톤앤매너 정의입니다. 이 문구들은 향후 모든 마케팅 메시지(CTA, 블로그 글)와 제품 UI 전반에 걸쳐 '셀브릿지'만의 고유한 심리적 위로의 언어를 구축할 것입니다.

**✅ 배분 에이전트:** Writer (Copywriter)
**✅ 목표 달성도 기여:** 브랜드 톤앤매너 확정 및 사용자 경험(UX Writing) 개선.

### ✨ Decline State 카피라이팅 가이드라인: '셀브릿지'의 심리적 위로 언어 정의

시스템이 경고/재활성화를 유도하는 메시지는 단순히 기술적인 지표를 보여주는 것이 아니라, **사용자의 상태를 인정하고(Validation), 다음 단계를 부드럽게 제안하는 (Guidance) '디지털 조언자'의 역할**을 수행해야 합니다.

아래 3단계의 심각도와 목적에 따라 카피를 분리하여 적용합니다.

#### 🟢 Stage 1: 초기 경고 (Soft Warning / Pre-Decline)
*   **목적:** 사용자의 집중력이 미묘하게 떨어지기 시작했음을 알려주지만, 죄책감을 느끼게 해서는 안 됩니다. '주의 환기'가 목표입니다.
*   **톤앤매너:** 부드럽고, 사려 깊으며, 은밀한 속삭임(Whisper Tone).
*   **기술적 트리거 예시:** `[Deep Metric Tracking] Focus Score -5%` (변화율 기반)

| 유형 | 카피라이팅 후보군 (선택 가능) | 강조 포인트 |
| :--- | :--- | :--- |
| **1. 신체 감각 유도형** | "잠시, 호흡에 집중해 보세요. 주변의 소음이 아닌, 내 안의 리듬을 찾아보세요." | 명상적, 즉각적인 행동 유도 |
| **2. 환경 인지 유도형** | "눈빛이 흐릿합니다. 잠시 시야를 넓게 가져가 보세요. (Look up)." | 물리적 휴식 권장, 외부 자극 이용 |
| **3. 시간 인식 유도형** | "흐름(Flow)은 저절로 왔다가 사라지기도 합니다. 지금의 쉼표가 다음 페이지를 위한 준비입니다." | 프로세스 관점 제시, 안심시키기 |

#### 🟠 Stage 2: 위기 경고 (Critical Warning / Decline State)
*   **목적:** 집중력 저하가 명확하며, 시스템이 개입해야 할 때. '휴식의 필요성'을 가장 강력하고 드라마틱하게 각인시키는 단계입니다. **(CEO 지시사항 반영)**
*   **톤앤매너:** 긴박하지만 비난조는 아닌, 단호한 동기 부여와 책임감 있는 조언자의 목소리 (Cinematic Drama Tone).
*   **기술적 트리거 예시:** `[Deep Metric Tracking] Focus Score -25% / Work Cycle Overdue`

| 유형 | 카피라이팅 후보군 (선택 가능) | 강조 포인트 |
| :--- | :--- | :--- |
| **1. 시스템 재조정형** | "**⚠️ 경고: 에너지 코어 과부하 감지.** 잠시 멈추세요. [시스템 재조정 모드]가 활성화됩니다." | 기술적 용어를 활용하여 위기감 극대화. (Developer 스펙 연동) |
| **2. 심리 공감형** | "당신의 집중력은 소모품이 아닙니다. 잠시 멈춰 쉬는 것이 가장 강력한 재충전입니다. *[5분 리셋 타이머 시작]*" | 사용자의 가치를 인정하고 휴식을 권유 (가장 추천). |
| **3. 강제 개입형** | "지금의 패턴은 비효율적입니다. 10분의 간격으로 시각/청각 전환을 시도하세요. *[강제 인터럽트]*" | 명확한 지침과 기한 제시 (최후의 수단). |

#### 🔴 Stage 3: 재활성화 유도 (Reactivation Prompt / Recovery)
*   **목적:** 휴식이나 이탈 후, 다시 작업으로 복귀하는 순간. '잃어버렸던 몰입감'을 회복할 동기 부여가 필요합니다.
*   **톤앤매너:** 희망적이고, 명쾌하며, 추진력을 얻는 느낌 (Uplifting & Momentum).
*   **기술적 트리거 예시:** `[Deep Metric Tracking] Focus Score +10% / Rest Timer Complete`

| 유형 | 카피라이팅 후보군 (선택 가능) | 강조 포인트 |
| :--- | :--- | :--- |
| **1. 성취감 극대화형** | "준비되셨나요? 잃어버렸던 리듬을 되찾았습니다. 이제, 이 에너지로 [핵심 과제]를 끝내봅시다." | 목표 상기 및 동기 부여 (CTA 연동). |
| **2. 미세 조정 유도형** | "다시 돌아왔습니다. 가장 효율적인 다음 단계는 무엇일까요? 흐름을 다시 타보세요." | '다음 액션'에 초점을 맞추어 사용자를 능동화. |
| **3. 시각적 안내형** | "가장 중요한 지점(Climax Point)이 코앞입니다. 잠시만 더, 이 기회를 잡으세요." | 드라마틱한 스토리텔링 요소를 다시 활용. |
