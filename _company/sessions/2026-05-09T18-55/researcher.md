### 💡 주제 1: Context Switching Overload (주의력 분산/맥락 전환 비용)
**핵심 학술 개념:** 주의 자원의 비선형적 소모, 멀티태스킹의 심리적 비용.
**Mini-Module 포지셔닝:** "당신이 느끼는 피로는 의지의 문제가 아닌, 뇌의 **에너지 배분 실패(Resource Allocation Failure)**입니다."

| 이론/개념 | 상세 설명 및 콘텐츠 활용 방안 | 필수 학술 키워드 (구글 스콜라/DBpia) |
| :--- | :--- | :--- |
| **Context Switching Cost** | 한 작업에서 다른 작업으로 전환할 때 발생하는 인지적 비용. 이 과정 자체가 주의력 자원을 소모시키며, 원래 하던 작업을 재개하는 데 시간이 걸림(Switching Overhead). | `Task-switching cost`, `Attentional switching overhead`, `Cognitive resource depletion` |
| **Limited Working Memory** | 작업 기억(Working Memory)은 물리적 용량이 제한되어 있음. 너무 많은 정보 파편을 동시에 처리하려 할 때, 시스템 과부하가 발생하며 오류율과 시간이 급격히 증가함. (Mini-Module의 '용량 측정' 근거). | `Working memory capacity limits`, `Cognitive load theory`, `Information overload management` |
| **Attention Restoration Theory (ART)** | 주의력은 한정된 자원이며, 지속적인 집중(Directed Attention)은 빠르게 고갈된다는 이론. 자연 환경이나 몰입을 유도하는 활동이 이 회복에 필수적임을 강조하며 콘텐츠의 '해결책' 부분에 활용 가능. | `Attention Restoration Theory (ART)`, `Directed attention fatigue`, `Mental effort exhaustion` |

### 💡 주제 2: Sustained Focus & Flow State Mechanics (지속 집중 및 몰입 상태)
**핵심 학술 개념:** 인지 자원의 최대 효율성 발휘 메커니즘, 외부 방해 요인 차단.
**Mini-Module 포지셔닝:** "현재의 산만함은 당신이 **최적의 Flow State 진입 조건(Optimal Condition)**을 갖추지 못했기 때문입니다."

| 이론/개념 | 상세 설명 및 콘텐츠 활용 방안 | 필수 학술 키워드 (구글 스콜라/DBpia) |
| :--- | :--- | :--- |
| **Flow Theory** | 개인이 활동에 완전히 몰입하여 시간 감각을 잃고 높은 성취를 경험하는 심리 상태. 난이도와 기술 수준이 균형을 이룰 때 발생하며, '최적의 자극'을 찾아야 함을 강조. | `Csikszentmihalyi Flow Theory`, `Optimal experience balance`, `Flow state prerequisites` |
| **Deep Work** | 산만함을 완전히 배제하고 고도의 집중력으로 가치 있는 결과물을 만들어내는 활동. 현대 사회의 '산만함'과 대비되는 개념으로 사용하며, 지적 노동자(Knowledge Worker) 타깃에게 높은 공감대를 형성할 수 있음. | `Deep work capability`, `Cognitive flow state`, `Attention economy challenge` |
| **Executive Function (EF)** | 계획, 조직화, 문제 해결 등 고차원적인 인지 능력을 포괄하는 개념. 이 기능이 약해지면(과부하 시) 일상생활의 효율성이 떨어짐을 진단할 수 있는 근거로 활용. | `Executive function deficit`, `Self-regulation failure`, `Cognitive control theory` |
