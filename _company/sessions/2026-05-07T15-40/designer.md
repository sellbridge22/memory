# 🚨 셀브릿지 디자인 시스템 가이드라인 v1.0 — 구조적 과부하 경고 패턴 사양서

## I. ⚙️ 핵심 원칙 및 철학 (The Core Philosophy)

| 항목 | 정의 및 목적 | 제작 지침 (Actionable Rule) |
| :--- | :--- | :--- |
| **문제 인식 프레임** | 개인의 노력 부족 $\neq$ 시스템적 결함. 사용자에게 '시스템 자원의 한계'를 인지시켜야 함. | 모든 시각 요소는 '측정 가능하고 객관적인 경고등'처럼 작동해야 합니다. 감성적이지 않고, 과학적이고 기계적이어야 합니다. |
| **톤앤매너** | Cinematic Industrial Drama (영화 같은 산업 드라마). 고긴장감(High Tension) 유지. | 미니멀하지만 정보 밀도가 높아야 하며, 네온 레드 경고색을 통해 지속적인 위기감을 조성합니다. |
| **핵심 시각 요소** | Neon Red & Glitch Effect & Monospace HUD. | 이 3가지 요소를 단 하나의 장면도 빠짐없이 사용하며, 그 상호작용 타이밍이 스토리텔링의 핵심입니다. |

## II. 🎨 비주얼 언어 스펙 (Visual Language Spec)

### 1. 컬러 팔레트 (Color Palette)
| 이름 | HEX Code | CMYK/RGB 예시 | 역할 및 사용처 |
| :--- | :--- | :--- | :--- |
| **[A] 배경/딥 블랙** | `#080C25` | R: 8, G: 12, B: 37 | 모든 UI의 기본 바탕색. 깊고 차가운 느낌을 주어 '시스템 내부'라는 인상을 강화합니다. |
| **[B] 네온 경고 레드** | `#FF3B30` | R: 255, G: 59, B: 48 | **필수 경고색.** 과부하(Overload), 임계값 초과, 시스템 오류 발생 시 전면 적용. (플래시/강조) |
| **[C] 데이터 스트림 블루** | `#00FFFF` | R: 0, G: 255, B: 255 | 정상적인 데이터 흐름, 측정 지표 표시(HUD), 성공적 진단 결과를 시각화할 때 사용. (안정성) |
| **[D] 중립 그레이** | `#A0A8C0` | R: 160, G: 168, B: 192 | 보조 텍스트, 경계선(Border), 비활성화된 모듈에 사용. |

### 2. 타이포그래피 (Typography)
*   **주요 글꼴 (Display/Data):** `DSEG7 Segment` 또는 유사한 **모노스페이스 디지털 스타일**의 산세리프 계열. (디지털 디스플레이, 코딩 느낌 강조).
    *   *활용:* 모든 지표 수치, 경고 메시지, HUD 레이블링에 사용.
*   **보조 글꼴 (Body/Title):** `Inter` 또는 유사한 고가독성 산세리프 계열.
    *   *활용:* 일반적인 카피라이팅(설명문, 도입부) 및 제목에 사용하여 가독성을 확보합니다.

### 3. 특수 효과 정의 (Mandatory Effects)
| 효과 | 사양서 (Specification) | 에디터 주의사항 |
| :--- | :--- | :--- |
| **글리치 (Glitch)** | **1단계:** 수평 방향으로의 짧은 지연/왜곡(Horizontal Jitter). `[B]` 네온 레드를 사용하여 2~3프레임 동안 간헐적으로 색상 분리(`#FF0000` $\rightarrow$ `#0000FF` $\rightarrow$ 원래 색)를 발생시킵니다. | *주요 사용처:* 경고가 임계점에 도달하거나, 중요한 데이터 값이 발표되는 순간 (강조). 너무 자주 사용하면 피로도를 유발합니다. |
| **경고 플래시 (Alert Pulse)** | 배경 및 핵심 지표 박스에 `[B]` 네온 레드가 1~2Hz 주기로 미세하게 밝아졌다 어두워지는 깜빡임(Pulse)을 적용합니다. | *주요 사용처:* Mini-Module 진단 과정 전체를 관통하며, '시스템이 불안정하다'는 물리적 느낌을 제공해야 합니다. |
| **데이터 스캔 (Scanline)** | 화면의 상하좌우에 얇은 가로/세로 라인(Line) 패턴을 주기적으로 지나가며 데이터 값을 읽어내는 듯한 시각 효과를 적용합니다. | *주요 사용처:* 정보량이 폭발하는 구간, 또는 중요한 분석 결과가 도출되는 클라이맥스 직전에 배치하여 몰입도를 높입니다. |

## III. 🚨 인터랙티브 상태 정의 (The Three-Stage Alert Flow)

에디터는 시간 흐름(Timeline)에 따라 아래 세 가지 시각적 상태를 반드시 순차적으로 구현해야 합니다. 이 전환 자체가 서사(Narrative)입니다.

| 단계 (State) | 명칭 | 목표 및 기능 | 비주얼/애니메이션 스펙 (Timing 필수) |
| :--- | :--- | :--- | :--- |
| **STATE 0** | **정상 작동 모드** (Baseline) | 시청자에게 '평온함 속의 위험'을 암시. 시스템은 정상이나, 근본적인 문제가 있음을 은연중에 각인. | HUD는 `[C]` 블루와 중립 그레이 위주로 깔끔하게 유지. 경고색 사용 최소화. **(배경음악: 낮은 앰비언트 노이즈)** |
| **STATE 1** | **과부하 감지 단계** (Warning/T+5s) | 시스템의 미세한 자원 고갈을 인지시키기 시작. 경고가 '시작'되었음을 알림. | **[애니메이션]**: 화면 모서리나 데이터 지표의 배경색에 `[B]` 네온 레드가 점진적으로 침범합니다 (Gradient Fill). 글자 주변에 미세한 깜빡임(Pulse)이 시작됩니다. **[사운드]**: 낮은 주파수의 윙-하는 경고음 추가. |
| **STATE 2** | **시스템 임계점 도달/경고 발령** (Critical Alert/T+15s) | 문제의 심각성을 최고조로 끌어올림. 사용자의 즉각적인 행동(진단 페이지 클릭)을 유도해야 함. | **[애니메이션]**: 화면 전체에 `[B]` 네온 레드가 점멸하며 오버레이됩니다. 글리치 효과가 잦고 격렬해지며, HUD의 모든 요소가 불안정하게 진동합니다. (글리치 빈도 $\uparrow$, 깜빡임 주파수 $\uparrow$). **[사운드]**: 높은 음역대의 날카로운 경고음(Siren)과 함께 낮은 베이스 드롭을 결합하여 위기감을 극대화합니다. |

## IV. 🌐 채널별 적용 가이드라인 (Channel Adaptation Spec Sheet)

| 채널 | 콘텐츠 유형 | 디자인 필수 적용 요소 | 비고 및 에디터 지침 |
| :--- | :--- | :--- | :--- |
| **유튜브 썸네일** | 클립/하이라이트 요약 | 1. 네온 레드(`[B]`)의 압도적인 사용량. 2. 모노스페이스 타이포그래피를 중앙에 배치하여 '데이터'처럼 보이게 함. 3. 전체 배경에 미세한 글리치 필터 적용. | 텍스트는 **"SYSTEM ALERT: [키워드]"** 구조를 고수하며, 썸네일 자체가 하나의 경고등 역할을 해야 합니다. |
| **유튜브/인스타 영상** | 풀 콘텐츠 배경 (B-roll) | 모든 비주얼 전환 지점(Cut Point)에 State 1 $\rightarrow$ State 2로의 시각적 트랜지션을 의무적으로 삽입. | Transition은 단순 페이드 아웃이 아닌, **데이터가 끊기거나 깨지는 글리치 기반의 하드 커팅**을 사용해야 합니다. |
| **인스타그램 릴스** | 짧고 강렬한 후킹 콘텐츠 (Hook) | 첫 3초 안에 State 2 수준의 경고(예: 빠른 플래시, 격렬한 지직거림)를 사용하여 시청자의 주의를 강탈합니다. | 텍스트는 화면 중앙에 HUD 형태로 오버레이되며, 설명은 간결하게 '측정된 데이터'만 제시합니다. |
