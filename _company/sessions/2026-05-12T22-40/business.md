## 🚀 Utility Tool API 모듈 MVP 출시 로드맵 (3개월 플랜)

### 🎯 핵심 가설 및 목표
1.  **핵심 가설:** 사용자는 단순한 '시간 관리'가 아닌, 자신의 인지 자원 고갈(Structural Deficit)을 **학술적이고 공포스러운 시각**으로 진단받고 싶어 할 것이다.
2.  **MVP 목표 (3개월):** 유료 진단 모듈($4.99)의 성공적인 출시 및 첫 100건의 결제 전환 달성.

### 🧪 시장 분석 및 경쟁 우위 전략

| 구분 | 일반적인 생산성 앱/도구 | 셀브릿지 Utility Module (차별화 포인트) |
| :--- | :--- | :--- |
| **문제 정의** | "시간이 부족해요." / "집중력이 약해요." | "당신의 시스템에 구조적 결함(Structural Deficit)이 발생했어요." (시스템 오류 프레임) |
| **핵심 가치** | 효율성 증대, 목표 달성 | **진단 및 경고.** 사용자의 실패를 개인의 문제가 아닌 '시스템의 오작동'으로 포지셔닝하여 거부감을 낮추고 학술적 권위를 높인다. |
| **가격 책정 논리** | 기능 제한 (Feature Gate) | **정보 깊이(Depth)**와 **시간대별 진단(Timecode Specificity)** 제한. $4.99는 '전문가에게 한번 진단받아볼 가치 있는 데이터' 구매 비용으로 설정한다. |

### 💰 수익화 및 가격 책정 정당성 (Pricing Justification)

*   **가격:** **$4.99 (Diagnostic Check-up Fee)**
    *   **정당화:** $4.99는 '완벽한 해결책'을 파는 것이 아니라, '지금 당장 눈에 보이는 구조적 위험 요소 진단 리포트'를 판매하는 비용입니다. 이는 사용자가 문제의 심각성을 인지하고(Fear/Urgency), 다음 단계 (Mini-Module 유료화)로 넘어가는 **가장 낮은 마찰점**을 형성합니다.
    *   **KPI 연동:** 이 $4.99 결제는 하위 퍼널(Funnel)의 성공 지표이며, 궁극적으로 상위 구독 플랜(월별/연간)으로 전환되는 징검다리 역할을 수행합니다.

## 🗓️ 월별 로드맵 상세 계획 (3 Months MVP Roadmap)

### 💡 Phase 1: 발굴 및 핵심 진단 (Month 1)
**테마:** 문제 제기 → 최소 기능 구현
**주요 목표:** 유료 모듈의 초기 사용자 확보 및 결제 흐름 검증.

| 항목 | 내용 정의 (Feature Scope) | 마일스톤/성과물 | 수익화 포인트 |
| :--- | :--- | :--- | :--- |
| **기능 확정** | 1. **AFI (Attention Failure Index):** 핵심 지표만 표시하는 미니 버전. (진단 깊이 제한) 2. **경고 배너:** '구조적 결함 발생' 등 System Alert 문구만 노출. 3. **로그 기록:** 오늘 날짜의 기본 데이터 수집 및 시각화. | M1: 최소 기능 제품(MVP) 출시. 대시보드의 핵심 KPI 카드 세트 활성화. | **$4.99 진단 모듈 판매 시작.** (제한된 시간/지표만 분석 가능하게 함). |
| **콘텐츠 연계** | 모든 무료 콘텐츠는 '이 지표가 위험하다'고 경고하며 Mini-Module의 필요성을 유도해야 함. | PoC 영상 시리즈 론칭 및 $4.99 진단 모듈 배너 삽입 완료. |

### 💡 Phase 2: 확장 및 전환 극대화 (Month 2)
**테마:** 디테일 제공 → 결제 의지 강화
**주요 목표:** 사용자의 데이터 의존성을 높이고, 구독 모델로의 이탈 방지 장치 구축.

| 항목 | 내용 정의 (Feature Scope) | 마일스톤/성과물 | 수익화 포인트 |
| :--- | :--- | :--- | :--- |
| **기능 확정** | 1. **CSC & PFC Index 추가:** 디자이너가 설계한 복잡한 지표(시간에 따른 변화 추이)를 해금. (고도화된 데이터 분석 제공) 2. **Event Log Stream 확장:** 구체적인 '결함 원인'과 '해결책 모듈'을 제시하는 로그 출력 기능 추가. 3. **데이터 내보내기 제한:** 리포트 다운로드를 유료/구독자 전용으로 설정. | M2: 고급 분석 대시보드 완성. 사용자 데이터가 쌓이기 시작하며 시스템 의존도 증가. | **Mini-Module Pro Tier 판매 강화.** ($4.99 진단 모듈을 사용한 후, 지속적인 관리를 위한 월간 구독 유도). |
| **콘텐츠 연계** | 복잡도가 높은 롱폼 콘텐츠를 통해 '이 정도의 결함은 우리가 다룰 수 없다'는 공포감을 극대화하고, 해결책으로 Pro Tier를 제시. |

### 💡 Phase 3: 규모 확장 및 B2B 준비 (Month 3)
**테마:** 전문성 확보 → 지속적 수익 창출 구조 확립
**주요 목표:** 사용자 기반을 넓히고, 높은 객단가의 Enterprise 매출원을 발굴.

| 항목 | 내용 정의 (Feature Scope) | 마일스톤/성과물 | 수익화 포인트 |
| :--- | :--- | :--- | :--- |
| **기능 확정** | 1. **Utility Tool API 공개:** 외부 시스템이나 학습 관리 플랫폼(LMS)에 연동 가능한 API 인터페이스 개발 및 문서화. (B2B 핵심). 2. **커스터마이징 리포트:** 특정 목적(예: 시험 대비, 직무 전환)에 최적화된 구조의 보고서 생성 기능. | M3: B2B용 '시스템 통합 모듈' 공식 출시. API 키 발급 및 사용 예시 제공. | **Enterprise/LMS 라이선스 판매.** (월 단위 고가 계약). Utility Tool을 단순한 개인 도구가 아닌, 기관의 인프라로 포지셔닝. |
| **콘텐츠 연계** | 연구자(Researcher)와의 협업 세션을 통해 '학술적 학회' 컨셉으로 콘텐츠를 제작하고, B2B 파트너십 기회를 발굴하는 데 집중. |
