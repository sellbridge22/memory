# 🌌 셀브릿지: 마스터 디자인 키트 (The System Master Kit) V1.0
**(통합 시스템 경고 및 패치 모듈 세트)**

## 🎯 프로젝트 목표 및 적용 범위
본 키트는 '인지적 불안 해소(Cognitive Anxiety Relief)'라는 핵심 가치를 전달하기 위해, 학습 콘텐츠의 전 과정에 걸쳐 **구조적 결함과 긴장감**을 유지하는 시네마틱 산업 드라마 미학을 구현합니다. 모든 에셋은 4K (3840x2160) 고해상도 기준으로 제작되어야 하며, 영상 편집자는 이를 '시스템 경고'라는 단일 언어로 이해하고 적용해야 합니다.

## 🎨 디자인 시스템 가이드라인
### 1. 컬러 팔레트 및 코드 (Hex Code 기준)
| 이름 | 색상 | 용도 | 메모 |
| :--- | :--- | :--- | :--- |
| **Deep Black** (배경) | `#000000` | 기본 배경, 시스템 전반의 무대. | 깊고 압도적인 긴장감을 유지합니다. |
| **Neon Red** (경고/결함) | `#FF0033` | 오류 발생, 경고 메시지, CTA 하이라이트. | 가장 중요한 시각적 트리거입니다. 깜빡임(Blink Rate 8Hz) 필수. |
| **Cyan Blue** (정보/패치) | `#00FFFF` | 정상 데이터 흐름, 패치 성공, 시스템 정보 표시. | 네온 레드를 보완하며 '기술적 해결'의 느낌을 부여합니다. |
| **System Grey** (텍스트) | `#AAAAAA` | 보조 설명 텍스트, 비활성화 요소. | 대비를 낮춰 학술적인 무게감을 더합니다. |

### 2. 타이포그래피 가이드라인
*   **메인 헤딩/경고:** Monospace, Blocky Sans-serif 계열 (예: OCR-A 또는 Roboto Mono). 글자 간격(Letter Spacing)을 미세하게 늘려 구조적 결함의 느낌을 강조합니다.
*   **본문 텍스트:** 가독성이 높은 Sans-serif 계열 (예: Noto Sans, Inter). 경고 메시지에서는 반드시 Monospace를 사용해 시스템 출력처럼 보이게 합니다.

### 3. 필수 애니메이션 스타일
*   **Glitch Stutter:** 화면 전체에 적용되는 기본 필터. 네온 레드와 사이언 블루의 노이즈 패턴이 불규칙하게 짧게 폭발하며 전환됩니다. (Transition Point마다 의무적 적용)
*   **System Flicker:** 모든 데이터/경고 요소는 완전히 고정되어 있지 않고, 1~2Hz 범위에서 미세한 깜빡임(Flicker)을 유지하여 '시스템 불안정성'을 시각화합니다.

## 🛠️ 필수 컴포넌트 세트 (Asset Blueprint)
다음은 영상 편집자가 즉시 활용 가능한 3가지 핵심 모듈의 상세 사양입니다. 각 모듈은 독립적인 에셋으로 존재하지만, **Context Drain Bar**와 **PFC Index Meter**를 반드시 보조적으로 호출하여 통합된 느낌을 주어야 합니다.

### Component 1: 시스템 경고 타이틀 카드 (SYSTEM\_ALERT)
*   **발동 시점:** 콘텐츠의 '문제 제기' 단계 직후 또는 주요 개념적 충돌(Dissonance Alert) 발생 순간. (T+0:05 ~ T+0:13)
*   **목표:** 사용자에게 '현재 상황은 시스템적으로 위험하다'는 긴박감을 주입합니다.
*   **디자인 사양:**
    *   **배경:** Deep Black 또는 딥 레드 오버레이.
    *   **메시지:** 중앙 상단에 `[SYSTEM OVERLOAD]` 타이틀이 네온 레드로 점멸하며 등장. (Blink Rate: 8Hz)
    *   **핵심 문구:** "WARNING: Structural Defect Detected" 또는 "Cognitive Dissonance Warning".
    *   **애니메이션 상세:**
        1.  (0.0s): 화면 전체에 강한 **Glitch Stutter** 필터 적용 및 사운드 발생 (High Pitch Alarm).
        2.  (0.5s ~ 3.0s): 타이틀이 점멸하며 등장. 동시에 주변에 노이즈 그래픽 패턴이 펼쳐집니다.
        3.  (지속): **PFC Index Meter**가 네온 레드로 깜빡이며 'Critical' 영역을 가리킵니다.

### Component 2: 데이터 왜곡 이펙트 (SOURCE\_DEGRADATION)
*   **발동 시점:** 사용자가 어떤 주장을 듣거나, 특정 그래프/데이터를 분석하는 순간. (지속적 활용 가능)
*   **목표:** 제시된 정보의 '출처 신뢰도'가 낮거나 결함이 있음을 시각적으로 증명합니다.
*   **디자인 사양:**
    *   **발동 조건:** 텍스트 블록, 그래프, 이미지 위에 오버레이됩니다.
    *   **시각 효과:** 원본 콘텐츠를 마치 '데이터 패킷'처럼 취급하여 왜곡(Distortion) 및 노이즈(Noise) 필터를 적용합니다.
    *   **애니메이션 상세:**
        1.  **패턴 1 (Pixelation):** 대상 영역의 픽셀들이 짧게 떨리며 네온 레드/사이언 블루 계열로 왜곡됩니다. `[SOURCE DEGRADATION: DATA CORRUPTED]` 문구가 하단에 빠르게 스크롤 됩니다.
        2.  **패턴 2 (Waveform):** 정보가 지나가는 듯한 파형(Waveform)이 불안정하게 출렁이며, 이 와류를 통해 노이즈 패턴이 발생합니다.
        3.  **통합:** 왜곡과 동시에 **Context Drain Bar**의 감소 속도를 시각적으로 가속화하여 '정보 처리에 에너지가 소모되고 있다'는 느낌을 강조해야 합니다.

### Component 3: 패치 성공 모달 (SERVICE\_SUCCESS)
*   **발동 시점:** 최종 솔루션(PoC/유료 서비스) 제시 직전 또는 진단 과정의 마무리 단계. (T+0:45 이후)
*   **목표:** 사용자에게 '문제는 구조적 결함이며, 오직 시스템적인 개입만 가능하다'는 메시지를 확신적으로 전달합니다.
*   **디자인 사양:**
    *   **배경:** Deep Black에서 서서히 네온 블루/사이언으로 전환되는 그라데이션을 사용 (회복의 느낌).
    *   **메시지:** 중앙에 크고 안정적인 폰트로 'SYSTEM PATCH COMPLETE' 또는 'REINITIALIZING...' 메시지가 표시됩니다.
    *   **애니메이션 상세:**
        1.  (0.0s): 모든 노이즈와 경고가 사라지고 화면이 급격히 정돈되는 느낌 (Decay Rate).
        2.  (0.5s ~ 3.0s): 네온 블루 계열의 안정적인 그리드 패턴과 함께, **PFC Index Meter**가 'Baseline' 영역으로 복귀하며 녹색/사이언빛 경고등이 점멸합니다. (만족감과 동시에 경계심 유발)
        3.  (최종 CTA): 모달 하단에 크고 선명한 네온 레드 버튼 `[SERVICE REQUIRED: ACCESS SOLUTION]`를 배치하여 시선을 고정시킵니다.
